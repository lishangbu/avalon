# 四城故事编排

故事围绕四城封印灾厄展开。运行参数以正式内容目录为准，验证范围见实施状态。

## 正式入口

- [世界观](narrative-design.md)：个人冒险、人兽共生和四城合力。
- [连续主线正文](main-story-outline.md)：晨露村到最终核心的因果。
- [系统设计](quest-story-design.md)：分支、成长与资产规则。
- [任务目录](quest-catalog.md)：300项任务与章节结构。
- [近期任务展开](quest-opening.md)：开篇与诺姆的实质行动和对白。

## 章节结构

晨露村 → 诺姆 → 温蒂妮与希尔芙（任选顺序，全部核心线汇合）→ 沙拉曼达 → 联合准备（并行）→ 封印深渊 → 自由冒险。

支线不能成为未声明的主线门槛。普通主线副本可单人完成，挑战与可选副本提供额外人物装备、材料、图纸与收藏。

## 内容预算

300项是容量，不强制保留300个初稿标题。单纯领取奖励、阅读配方、开放入口需要合并到实际行动；独立目标与成果才计任务。合并后的空位以实质冒险补足，不机械拆回五步。

前期任务经验为主，后期刷怪副本经验为主。战斗、物品资源人物装备、捕捉、辅助目标按从高到低投放；以实际目标审计，不从标题声称比例达标。
