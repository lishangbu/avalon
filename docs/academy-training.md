# 学院训练

训练使用临时会话，借用人物、伙伴与物品不进入正式库存。训练完成只记录对应能力事实，任务报酬由任务事务发放。

| 课程 | 标识 | 目标 |
| --- | --- | --- |
| 全队行动 | ACADEMY_DEFENSE | 全员下令并防御预告重击 |
| 主动换位 | ACADEMY_SWAP | 选择出战与替补，战中换入 |
| 捕捉练习 | ACADEMY_CAPTURE | 查看资料、削弱并合法捕获 |
| 职业实践 | ACADEMY_PROFESSION | 完成职业目标并学习技能 |
| 技能书实践 | WORKSHOP_SKILLS | 学习与技能池操作 |
| 装备仓库实践 | WORKSHOP_GEAR | 穿戴、库存和仓库操作 |

O013使用独立的行路前替补实践。课程开放条件、回合与目标数值以academy-training.json及目录校验为准。课程不是主线任务编号。所有写命令验证地点、角色状态、请求号与资产归属；重复请求恢复原结果。
