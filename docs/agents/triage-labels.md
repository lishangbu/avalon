# 分诊标签

工程技能使用下列五个稳定分诊角色；右侧名称即为本仓库 GitHub 标签名。

| 标准角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者尚需评估的议题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由无人值守代理处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个标准角色时，必须使用表中对应的仓库标签，避免创建同义但重复的标签。
