# 连续成长下的野外压低血量窗口

幻兽与同物种野生基础形态使用相同七维成长。捕获预算提高后，不能保留野生幻兽旧生命／防御，只在捕获成功时凭空变强。本核算读取60个基础物种各自投放等级上下界，共944项人物职业及物理减伤敏感性场景。

## 人物单独普攻的代价

人物与野生幻兽同级，人物使用可穿的最高档未强化完整副本装备；10级前为初始三件。普攻固定无属性物理威力50，不按法师法攻计算。按最低伤害求打至半血所需次数，再以相同次数的最高伤害检查是否误杀。

| 人物职业 | 无额外物理减伤时，至半血的保守普攻次数 |
| --- | ---: |
| 战士 | 2～8 |
| 游侠 | 2～8 |
| 法师 | 3～17 |
| 牧师 | 3～17 |

最长样例为29级铁羽雕。所有记录中，按所计算次数普攻，即使每次均取最高波动，目标仍存活；这是静态生命不恢复、无其他伤害的窗口验证，不是要求玩家照次数盲打。

完整副本装备只是可达标尺，不代表初次探索时已收集齐全；装备更差会延长压低血量。额外10%物理减伤作为独立敏感性场景，不表示所有物种都拥有坚岩，也不覆盖所有特性。

## 用队伍职责解决压低血量效率

额外使用同级、未进化的教学利爪猫，以当前魔力上限、12耗魔水弹及真实水属性克制表核算。每轮只让猫或人物中的一个攻击，其他单位防御；根据当前目标生命，水弹最高伤害仍不能击倒且魔力足够时用水弹，否则用人物普攻。生命已不高于半血就停止压低血量，再由人物投球。

四种固定伤害边界组合（人物低／高波动×猫低／高波动）中，压低血量目标需1～5轮、最多60魔力，没有使用进化宠、额外技能书、锁血或补魔药。这里的1～5轮是上述样本结果，不宣称覆盖所有逐回合独立随机序列。

此策略用于设计核查，不是在产品里增加自动选招、捕捉风险提示或强制携带利爪猫。玩家可用其他合适的法术伙伴；队伍已失去水弹、猫等级较低或魔力不足时，仍可调整成员、技能或继续普攻。死亡后重新寻找目标，既定误杀规则不变。

## 投球概率与行动消耗

结果表同时列出同级、普通目标、对应I～V普通球、无异常、生命处于25%～50%档时的捕获率。该档生命倍率为1；目标若已低于25%，应按实际1.5倍率另算，不把表内标准化概率当作所有压低血量结果的实际概率。

倒数概率只表示目标状态固定、可无限继续投球的条件期望。投球仍消耗人物行动，失败后敌人继续行动，可能回血或击倒己方，故“压低血量动作＋期望投球次数”不是通关时间承诺，也不包含遇敌、赶路或恢复时间。精英／稀有强化球资格、越级与超球档惩罚由既定捕捉规则另行处理，本表不绕过资格。

## 证据与后续验证


仍需接入29个真实遭遇池、普通／隐藏特性、野生幻兽自疗和减速、第二只野生幻兽干扰、己方治疗与补给，以及未满装备时的连续作战。尤其会微疗的目标可能抵消压低血量伤害，本静态表不能证明其1～5轮可捕；普通击杀耗时与300小时成长目标也不能直接从此表推算。
