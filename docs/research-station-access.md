# 五站研究服务的地图与接待


[站点表](research-station-locations.csv)为五个研究站指定独立服务节点、直接相邻的上级建筑或营地、接待机构、具名负责人及已确认任务门槛。节点均为设计ID，只有学院父节点`ACADEMY`已核对现行opening.json存在；其余父节点及五个服务节点仍须进入完整地图注册，不能把本表当作已经可运行的路线配置。

## 进入路径

| 研究站 | 玩家实际步行路径 | 开放依据 |
| --- | --- | --- |
| 诺姆学院 | 学院庭院→学院研究处 | 学院原入口沿获救道路；兑换要求研究教学完成及M021完成 |
| 温蒂妮 | 城镇道路→药铺→药铺研究柜台 | M110已完成入港核验，药铺可正常接待；不要求先完成M111药材船救援 |
| 北方安置营 | 安置营道路→医护处→研究柜台 | M163救援交接后开放该服务；医护日常服务另按既定规则开放 |
| 沙拉曼达 | 工坊区道路→工坊接待处→研究柜台 | M182本身要求向米洛恩回报，完成该任务已到达接待处 |
| 联军营地 | 营地公共道路→联军研究处 | M246集结核验发生在营地，完成后开放，不要求研究区救援或统帅战 |

每个服务节点与表中parent_node之间为双向相邻移动，不添加站点间快捷传送。进入服务节点不强制执行兑换或对话，返回父节点不要求重复完成任务。道路总图仍负责父节点之间的合法连接；本轮证明服务门槛与已有任务地点相容，不宣称尚未注册的城内道路已通过全图可达性验证。

没有研究资格时可看到已到达地点的柜台与服务说明，材料兑换入口明确列出缺少的条件。11级研究教学只在学院研究处接受，未完成M021时可解释教学但不提前兑换。任务推荐等级上界不作为额外人物等级锁；幻兽进化等级也不作为兑换材料的角色等级锁。野外材料掉落不受研究资格与柜台开放门槛限制。

## 人物迁移与机构接待

- 莱娜在M246前于学院承担教学和解释，M246后主要剧情位置在联军研究处。学院研究处由无名值班员继续提供已开放教学、兑换、委托和未领取教学礼包，不能因玩家较晚学习而永久错过进化资格。
- 赫伯和米洛恩分别是药铺、工坊的具名解释者。若当前个人剧情使其暂时离开，柜台由机构接待；其未完成剧情对白不锁住已有材料服务。
- 北方柜台由伊莲所属医护机构负责，默认显示机构接待员。只有个人剧情确实把伊莲安排在当地时才显示本人；不能为开商店而复制一个永远站在安置营的伊莲。
- 无名接待员是机构入口的表现，不另占80名重要NPC预算，不承接核心角色身份确认、营救决定或其他未经授权的剧情交付。
- 同一玩家视角下莱娜不会在学院和营地同时进行同一段剧情。两个柜台的研究资格、凭证余额、教学礼包领取事实与委托实例仍是同一角色的数据。

## 柜台菜单与服务边界

按顺序展示：进化配方与野外来源、研究教学、材料补缺兑换、当前研究委托、首次教学礼包。配方详情优先展示同族野生幻兽及其实际出没区域，再展示已开放站点的补缺兑换；未开放区域说明探索条件，不提供远程传送。研究资格未解锁也可查看已发现物种的材料用途。已完成教学时不再把重复教学放在主操作位置；礼包已领取则显示领取完成，不留下可重复领取按钮。普通同族野生幻兽为材料主来源，不能把兑换展示成进化的必经购买步骤。

兑换菜单由[107项报价](evolution-wild-offers.csv)筛选当前站点，不根据材料名字猜家族。先按玩家收藏过的家族排序，再列全部已开放配方；未收藏的家族也允许兑换，以便提前准备。每项显示材料名称、用途形态、数量1、研究凭证价格、兑换后绑定、当前持有数量和缺口。普通背包与待领数量分别标明，待领不能直接当作可消耗材料。

确认页分别展示兑换份数、每份凭证价格与合计消耗；通用每份1凭证、家族每份2凭证，不能把单价显示成材料数量。兑换多份时校验数量、总价、余额和背包容量，失败不扣凭证；战斗和副本内不可远程打开柜台。材料发放沿既定背包与待领规则处理，不能因重复请求额外生成。

首次教学礼包仍只有一次领取资格，可保留到后来站点开放，按选中相邻转换发足额绑定材料：三阶段第一步2＋2、第二步4＋4，两阶段6＋6。进化可以在既定合法安全地点进行，不要求集齐材料后再回某个特定NPC办理，避免引入额外跑图锁。

## 委托交接

五个站点共享同时一个活跃研究委托实例。接受前列明合格野外区域、6场胜利和现场记录的位置，确认后才计数。已接受的委托回原站的同一机构交付，负责人迁移后由该机构接待员承接，不把任务强行迁往另一座城市。

回到其他站可查看进度、说明返程路径或主动放弃，不能异地直接交付以跳过原路线成本；放弃清除本实例未交付进度，不返还已用战斗补给。下一次接受仍产生新的委托实例，不能复用旧战报。研究资格和凭证不会因取消委托而丢失。

## 一致性与未完成项

当前野生幻兽材料生成器校验五个站点ID、NPC名录引用、开放任务引用，以及所有报价的站点与门槛一致。90次转换、68种材料、107项报价均能归入这五站，无额外收费货币或研究站编号。

仍需完成父节点到地区道路的完整邻接配置、地图坐标与往返耗时。[研究委托路线](research-commission-routes.md)已绑定记录地点内的操作和交互文案，尚需接入运行地图。此文规定接待和路径规则，不把尚未完成的300任务地图绑定宣称为已经交付。
