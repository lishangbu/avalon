# 试玩章节内容来源核对

## 核对结果

当前八物种、技能池中的十三种技能书、十二种合成碎片和全部装备模板均有重复获取来源。一次性任务奖励不作为重复来源；旧村关闭后，从诺姆城外围出发，经过仍开放的相邻道路可以抵达以下必要区域和商店。

| 内容 | 重复来源 |
|------|----------|
| 利爪猫、小岩怪、芽灵、雷蜥 | 河边及东侧树林／平原对应物种池 |
| 青岚雀、紫炎兔 | 诺姆平原随机池与八级踪迹；返村道路和城外也有分布 |
| 影尾狐 | 东侧树林、返村道路、诺姆城外围 |
| 月光蛾 | 返村道路、诺姆城外围 |
| 水弹、碎岩击、藤鞭、雷牙、风刃、火球术、暗影箭、惩击 | 对应普通物种书籍／碎片掉落；学院与城内提供已解锁商品 |
| 微疗、掩护 | 精英小岩怪书籍／碎片池；商店补购 |
| 烈焰冲击、光幕 | 精英影尾狐书籍／碎片池；D01 宝箱额外奖励 |
| 逆风 | BQ015 赠送；BQ017 后学院与诺姆城补购。没有对应碎片配方 |
| 初始、洞穴、旅途、平原、守卫装备 | 对应任务赠送与按进度开放的商店补购 |
| 巡林者装备 | D01 发起者宝箱，不列入商店补购 |

来源以稳定编号核对，显示名称以 JSON 为准。普通野生幻兽的书籍池使用物种对应的技能书和碎片；精英使用独立池，不能将精英模板中的普通物种书籍误算为精英实际掉落。

## 验证方法

新增 `ChapterSourcesTest` 三项测试，直接加载正式目录：

- 汇集任务终点事实，从诺姆城外围按 `WorldCatalog.accessible` 和双向道路搜索，关闭的建筑不能作为通路。
- 只统计挂接到可达地点的普通捕获遭遇，验证每种伙伴仍可捕获；不依赖精英或一次性教学遭遇。
- 展开普通／精英书籍池和可达商店，检查每个物种技能池及每条碎片配方。
- 检查每件装备存在可达补购或正权重宝箱来源，防止销毁后无法补回。

复验命令：`./mvnw -pl avalon-app -am -Dtest=ChapterSourcesTest -Dsurefire.failIfNoSpecifiedTests=false test`。当前完整构建包含该测试，见 [工程验证](engineering-acceptance.md)。

## 尚未证明的内容

这是最终阶段的静态来源与地图连通性检查，不证明玩家一定有足够金币、必定击败精英或能在合理时间收齐。四职业自然成长、培养与 D01 已有应用服务路径验证，真人时长和长期平衡仍需实测。

伙伴管理服务已检查副本外门禁：入本后不允许存仓或放生；放生保留来源档案、要求最新确认名单，拒绝出战／替补及锁定个体。试玩任务目前没有消耗伙伴的上交步骤，不能将未来制作上交功能记为已实现。
