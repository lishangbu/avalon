# 工程验收

执行入口见[测试流程](testing-workflow.md)，内容事实来源见[内容目录](chapter-content-sources.md)。

- 内容目录通过Schema、引用、目标与奖励校验。
- 服务端校验身份、地点、版本、前置、所有权与库存，写操作具备事务和幂等回执。
- AND、OR、XOR的选择、切换、锁定、汇合和发奖覆盖实际事务。
- 自然路线使用真实角色、战斗、资源和装备，不用注入资产替代难度。
- 浏览器覆盖桌面与移动视口的受影响流程，类型检查和构建通过。
- 目录覆盖、接口覆盖、浏览器覆盖与真人节奏分别报告。

完整故事和后期经济的剩余范围见[实施状态](implementation-progress.md)。
