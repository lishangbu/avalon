# 主线换装与补购

[90件装备表](main-equipment.csv)包含九档，每档四职业武器与六件通用散件；每名角色获得自己的武器及六个其他部位，共七件。全部优秀品质、无套装效果，名称前缀不自动产生套装。它们提供不打副本的基本换装路线，不承诺只靠任务装备就能无策略击败所有首领。

本次先采用约四至六级一次的完整散件更新，装备领取仍逐件入包或待领，不添加随机礼盒。玩家手动比较穿戴，可保留强化旧装或副本套装；不自动卸下旧装备，不退强化成本。首次赠品零卖价，可按既定确认规则销毁。63件累计赠品不是同时占63格，旧件处理和待领仍需手机流程验收。

## 属性与品质

等级L的原始属性以D01精良同槽属性B定标：`floor(B × (L+5) × 0.85 / 15)`。对学院已有非武器字段另取其原始值作为最低值，防止低数字取整让12级新装比8级任务装降低速度或法防。四职业武器分别仅增加本职业攻击，护手按当前通用装备预算保留双攻。

品质已包含在这份成品预算中，不再额外乘优秀倍率。同等级每项属性不超过既有精良副本公式；副本随机获取优势仍存在，但不作为继续主线的硬门槛。人物升级不自动增长已取得装备。

强化沿既定0～7级、每级原始属性增加5%的公式与成功率执行，失败掉级、不转移、不保底。取整按最终实际字段显示，不为保证换装强制削弱旧强化装。学院、任务和副本装备的比较都须采用实际强化及套装状态。

## 来源、价格与回收

任务实例获得即绑定、强化0、卖价0；同模板商店购入实例按已有装备规则穿戴绑定，NPC回收价为实际购买价的五分之一向下取整。来源和售价保存在实例上，不能把赠品带到店里按模板补购价回收。

单件补购价为`floor(基准价 × L / 15)`：武器120、头/手/脚60、身90、腿/饰品75。后档开放后本店保留旧档商品，不升级已买装备或重发赠品。商店只出售已完成对应发放任务的档位；失去赠品可补购，不依靠重接任务恢复。

## 结算及验证

[九份奖励定义](main-equipment-grants.json)保存候选物品、职业筛选规则与唯一回执。执行时固定本职业武器，加六个不同非武器槽，不能把四件职业武器全发。装备发放与主线现金、经验归属及完成事实同一事务提交；这里的独立回执用于防重，不能变成可以单独重领的入口。满包保存待领，不回退剧情。
