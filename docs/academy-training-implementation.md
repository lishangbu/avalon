# 学院课程接入状态

本页说明运行实现与[隔离课程规格](academy-training-design.md)的边界，不将设计例算视为已接入。

## 已实现的服务切片

- `AcademyTrainingCatalog`读取`academy-training.json`及本地Schema，启动验证指令、防御、换位、捕捉和职业课程所用伙伴、技能引用及目标；课程由正式开篇任务目录统一引导。`training.json`仅保存四职业试题数值，不包含独立地点、任务前置或金币经验奖励。
- `GET /api/battle/academy`返回服务器过滤后的可参加课程和借用伙伴；只在学院、无战斗/副本并满足前置时可用。已完成课程可重练。前端无需知道事实表达式或敌人数值。
- `POST /api/battle/academy`接受`course`、`partners`、`requestId`。BQ019按列表顺序设置两出战、两替补，第五只仅携带；其他课程传空列表。返回普通`BattleView`，后续使用原战斗回合接口。请求重放要求课程及选择完全相同。
- BQ018使用人物及两只借用伙伴、公开蓄力重击循环。必须各实际行动、人物防御后实际承伤并击败木靶；提前击败会保留“战斗胜利、练习未完成”反馈，不复活敌人或伪造防御。
- BQ019借用五只，无需拥有真实替补；主动替换后结算整轮再完成。第五只不得直接换入，原固定点名目标已退场时攻击落空，不改打换入者。
- BQ023复用四职业正式训练目标与回合引擎。完成记录`TRAINING:BQ023`并授予永久职业技能，不重复发课程经验或金币。
- 新课完成仅记`TRAINING:BQ018/BQ019/BQ023`。正式任务交谈与经验奖励仍属于任务服务，不由训练提前写`QUEST:BQxxx`。

BQ018前置`QUEST:BQ017`，BQ019/BQ023前置`TRAINING:BQ018`。角色战斗锁沿现有服务限制真实队伍与库存修改；退出或失败不把借用数据写回正式资产。

## 验证证据与待验收边界

### BQ020捕捉课接入

新增BQ020隔离捕捉课，使用11级借用人物、猫与岩怪、11级小岩怪投影。投影在生成时按45/45/10保存槽位，回合、刷新与投球不重抽；技能和基础捕捉率调用当前正式目录，I/II球仍受正式跨档衰减，没有教学必成功分支。临时库存为I球8、II球8、生命药II12、魔力药II4，II药回复200HP/40MP（沿药品设计表），只在此课允许使用。

`BattleView.academyCapture`公开本课说明、目标ID、两种球、是否已查看及已选球；槽位与特性只在实际捕获后公开。玩家查看目标公开资料、比较球档并选择后，调用`POST /api/battle/academy/{id}/capture-info`，请求`{ball:"SEAL_I"}`或II；返回最新战局。这个操作不消耗战斗回合，也不限制后续只能投选择的球。

正式回合资源桥接在本课仅访问战局临时库存与临时捕获空间。成功目标留在战局结果中，不调用真实幻兽捕获、图鉴或资源存档。通过条件为资料确认、实际掉血后合法捕获；I成功同样通过。满血捕获承认“捕获成功”但不通过削弱练习；击倒目标结束为未完成，免费重开新投影。退出不会携出任何临时资产。

新增`AcademyCaptureRulesTest`四项与`AcademyTrainingFlowTest`捕捉流程断言，已随本轮串行构建通过。课程暂沿当前正式技能/特性实现，不代表新版法物耗魔与所有特性已接入。

已执行`AcademyTrainingRulesTest`与正式训练回归：覆盖四职业指令防御、提前击杀不假通过、四选五校验、第五只非法换入及换入单位本轮不动作。执行命令为`./mvnw -pl avalon-app -am -Dtest=AcademyTrainingRulesTest,TrainingFlowTest -Dsurefire.failIfNoSpecifiedTests=false test`。
