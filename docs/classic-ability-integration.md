# 经典特性首批整合提案

[家族分配说明](classic-ability-family-candidates.csv)记录首批16项经典机制的投放理由；最终槽位统一读取[72效果、450槽位完整表](creature-complete-ability-slots.csv)，不叠加阶段表。本页保留这些机制的精确交互与取舍。

这不是已上线内容，也不代表40项经典对照已全部实现。数值采用[经典特性适配](classic-ability-adaptation.md)的阿瓦隆候选列，以下补全与现有战斗框架的连接规则。

## 免疫、吸收与保护顺序

先完成合法施放与费用支付，再确定保护转移，接着按实际承伤者检查属性免疫；免疫发生在伤害公式最低1点、护盾和接力保护消费之前。免疫结果可以为0，不强制改回1。已经发生的手动转移仍消费保护次数，但因为免疫未进入伤害阶段，不消耗接力保护、护盾或破甲标记。

免疫直接攻击时连同该命中附带的减速等效果一并免除，但不免除独立的无伤害状态技能、场地伤害、反射或剧情效果。储水和经典蓄电在每次有效的对应属性敌方攻击命中时各恢复最大生命的1/4，满血时实际恢复0；这种恢复不触发回春、滋养、生命共鸣、净羽或其他直接治疗机制。群攻中只有具有免疫特性的承伤者免疫，其他目标照常处理。

引火与食草的增益分别只保留一层，重复触发不叠加；入场时不自动带有攻击加成，触发后保持至死亡或离场。目标已死亡、捕获或退出战斗后，不能再触发吸收。友方攻击沿现有合法目标规则，不新增“用攻击技能给队友回血”的目标入口。

野生幻兽同样使用免疫与吸收；其预告、实际战斗日志可让玩家识别效果，但捕获前不显示槽位类别。选择被免疫技能不会退款或自动换成克制技能。

## 入场、离场和本轮动作

初始部署和合法换入均产生一次入场事件，断线恢复和原地重复提交不产生。先完成同次部署，再依固定位置登记入场效果，最后建立回合动作顺序；后续回合中换入产生的速度变化不能重排已锁定的本轮顺序。

威吓影响当时敌方在场存活单位，物攻×0.90；同名效果取一层，不随来源离场自动解除，在受影响目标离场或死亡时清除。后进入场的敌人不会追溯被已有威吓影响；威吓持有者再次合法换入可对当时目标施加。它是针对敌方的入场效果，副本中同一首领被三支小队威吓仍只承受一层；敌方威吓则作用于当时全部在场的玩家单位。

再生力在主动换下存活个体后恢复最大生命1/3，不超上限；不复活、不补魔，不触发治疗特性。新上场伙伴本轮仍不能行动。死亡补位、战斗结束、逃跑、捕获、村庄编队和副本外移入仓库均不触发。每次真实换下都可生效，不能为了掩盖药耗变化而擅自改成每场一次。

自然回复使用同样的主动离场事件，当前清除减速、眩晕与中毒，不清除关卡标记、技能冷却或其他未列入清除组的效果；破甲仍按通用离场规则移除，不归功于自然回复。角色本来不能执行换宠时，不能借自然回复跳过动作资格。后续异常须显式扩充清除清单，不采用“删除全部负面字段”的实现。气体抑制与复制所得效果的离场顺序见[入场和换宠契约](ability-entry-exit-contract.md)。

友情防守只作用于所属人物及另一只在场幻兽，不作用于副本其他玩家小队。若己方两只幻兽都有该特性，人物仍只获得一层0.90，两个持有者可分别被对方保护。持有者进入替补或死亡后，其来源立即失效；同次群攻的光环资格在攻击开始时锁定，不因处理目标顺序让后面的队友突然失去减伤。

## 保命、技能分类和伤害条件

结实在每份直接伤害命中前检查满血，在护盾吸收后的剩余伤害即将致死时将生命损失截为当前生命减1。无致死风险时不改变伤害，也不消耗单独次数。回到满血可再次满足条件，连续独立命中则逐份检查；1生命且最大生命大于1时不满足满血条件。持续伤害和反射不受保护。吸收先使伤害无效时不再检查结实。

技术高手按原始技能威力判断不高于60，不按加成后的数值反复判断。通用普攻50变为65；逆风40变为52，保留减速、耗魔与冷却。群攻每个目标使用同一修正，不因目标数把总威力误算作资格；未来多段技能须单独审查，当前不据此提前开放。

适应力替换本系系数；有色眼镜只替换0.75抵抗系数；过滤只替换1.25被克制系数。免疫属于更早的独立阶段，不能被有色眼镜改成正常命中。多重鳞片按每份实际命中前的工作生命检查满血，与同一群攻多份承伤规则一致。

分析按实际目标本轮是否完成有效行动逐目标判断：攻击、治疗、防御、道具和合法换下都属于有效行动；因控制跳过、目标失效或等待补位不属于。换下的原个体已不能被普通攻击选中，接替者不会继承其“已行动”记录。正在执行的本次攻击不能预先给自己登记行动完成再获得分析收益。

## 验证与剩余项

[再生力经济核算](regenerator-economy-budget.md)已覆盖7个等级节点、112组十二回合局部轮换压力。50级一次换下上限890生命，约两瓶同档药品；双再生力在适当压力下可显著省药，高伤仍可击倒。模型尚不包含人物及另一出战位置、实际敌方选目标与输出损失引起的战斗延长，不宣称完成整场经济验证。

[野生幻兽免疫应对](wild-immunity-response.md)已完成300个物种／免疫组合与145个遭遇池组合的初始技能审查。E24池所有初始攻击均为地属性，需要在公开观察免疫后从下一轮改用普攻；这项普通野生幻兽决策规则已由`WildActionPolicy`与攻击结算的公开观察记录实现，首领预告仍保持原技能，不套用临时改招。


需继续完成免疫与保命阶段参考、再生力的药耗与行动成本、16个家族实际首现区域的敌方技能覆盖、隐藏槽收益及副本免疫应对。完整设计表不能替代相应生产机制和组合测试。
