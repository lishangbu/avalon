# 首批26种新增进化形态规格

[终阶物种表](creatures-evolved-40.csv)为首批28个基础种补齐26个新增目标。与原表30行联合为56个唯一物种：28个野外基础种、28个进化终阶。既定青岚隼、紫焰灵兔仍在原表，不重复登记。本表14种在22～25级可取得，12种在30～34级可取得；均为进化取得，不加入野外遭遇表。

## 继承与职责

每行明确族群、单属性、进化来源、取得等级、图片地址、成长倍率、魔力成长、三个槽位特性、学习池和终阶标志。source中的基础种决定原始成长；growth中的inherit_then_multiply只乘一次，不能把基础种、终阶系数和当前个体属性连续乘三次。

潮爪猫保留水系恢复与支援；古木卫加强物理保护；雷角蜥、铁鬃野猪、青冠兽延续物理职责；沙翼鹰和夜影狐保留敏捷法术方向。灵泉守卫、深水藤妖、云翼鹤和银角兽增加队伍支援；岩巨人、泥岩守卫、潮甲蛛、铁甲旋龟和岩背巨兽维持耐久职责。名称中的巨、守卫或灵不改变属性、种族或可用职业。

物攻方向不代表获得物理版水弹或火球术。炎鬃巨熊仍需在已有普通攻击、物理书和火法之间选择；雷霆守卫继续使用物理雷牙。法术或物理取向由实际成长与技能共同确定，不能仅按外形推断。

A、B、H与基础种逐槽对应，本批不额外换特性名称，保证已培养个体的使用方式连续。未来路线若逐槽更换特性，仍继承槽位而非任选效果；必须单独公布映射。当前个体只生效一个槽位，不同时享有三个效果。

## 技能池

完整学习池至少包含基础种全部合法技能，避免进化后旧技能失去重学资格。initial_skills为inherit，表示实际继承该个体当前已学技能，不能按基础种初始两技能重置，也不能复原之前随机遗忘的技能。

仅12种新增终阶扩一项明确用途的辅助技能：潮爪猫、古木卫、碧水妖、灵泉守卫、云翼鹤与银角兽增加掩护资格；雷角蜥、青冠兽、深水藤妖、潮甲蛛、雷霆守卫与雷牙豹增加光幕资格。其余终阶保持原学习池，不为了七技能上限加入无关招式。

新增资格仍需要对应技能书，学习和遗忘沿全局规则；进化过程不发放、不自动学习新技能。掩护与光幕引用既定技能规则，不在本表重新定义援护范围或减伤方式。人物专属技能不因此开放给幻兽。新增形态不掉落自己的技能书；材料和书本必须从实际可进入地区取得，不能设计成必须先有终阶才能刷出终阶所需物品。

## 数值对照

[114组属性对照](evolution-stat-check.csv)覆盖全部60条路线的首次进化等级与50级。比较同等级、相同基础种成长，排除装备、临时状态和特性；速度列是基础速度，轻盈等效果另算。魔力保留原基础与每级成长，当前倍率为1，不因进化免费提高施法次数。

复算基式与现行幻兽成长一致：生命基数30×(等级＋5)，物攻、法攻、物防、法防基数20＋5×等级，速度基数20＋2×等级。基础种先乘对应成长系数；终阶从这个未取整结果再乘进化倍率，最后向下取整。不能先取整基础种结果再乘倍率，或每次登录基于旧终阶数值累乘。

对照用于发现字段顺序、重复乘算、意外降属性与魔力异常，不证明56种战斗平衡。还需比较伤害、先手变化、实际承伤、治疗效率与学习资源成本。进化在同级上提供成长收益，未进化物种可继续使用，但不承诺同级基础形态与终阶完全等强。

## 尚未交付

古木卫已绑定候选树人图片，其余25个新增终阶缺少独立形象；不复用同一基础种图片假装完成进化外观。26条新增路线的[通用和专属材料配方、数量及研究兑换来源](evolution-material-design.md)已定义，精英可选来源与实际获取成本仍待完成。图鉴首次登记和奖励沿统一框架，但总奖励预算尚需联算。

因此本表补齐物种规格，不等于26条路线已能运行。后续批次与全局剩余物种数见[设计交付清单](design-implementation-gaps.md)；本批中的缺图、材料来源和实战验证另行跟踪，不能从剩余物种数中消失。
