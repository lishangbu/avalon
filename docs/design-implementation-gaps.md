# 当前设计与运行实现差异

更新于2026-09-23。完整故事交付至前15级，另有16～50级野外成长与生活资源；任务、来源和战斗机制均以运行配置及生产代码为准。历史候选表不等于已开放内容。

## 采用依据

- 故事采用[故事大纲](main-story-outline.md)、[连续故事编排](bright-story-arcs.md)及[开篇设计](bright-opening-design.md)。

- 幻兽采用[当前选表](current-creature-design.md)及整数七维表；150形态为总体规划。
- 运行配置位于`avalon-content/src/main/resources/content/`。逐物种来源见[40形态核查](opening-content-status.csv)，运行`python3 scripts/opening-content-audit.py --strict`复核。

## 后续范围与验证边界

BQ067起主线、16～50级其余剧情与副本、其余幻兽和候选效果随后续内容推进。真人手机、4～6小时开篇体验与正式上线仍需相应记录，自动化浏览器和吞吐量均不能替代。

当前66任务自然成长由`NaturalExtendedStoryTest`负责，推荐12级多人验收由`DungeonBrowserIT`负责。

最新命令结果、奖励测量和可复验入口统一见[当前进度](implementation-progress.md)与[工程验收](engineering-acceptance.md)。已被后续实现取代的开发记录不再作为当前待办清单。
