# 1～50级城镇恢复服务

## 服务范围与费用

只有角色实际处于已开放的`RECOVERY`安全节点、已经结束战斗且不在副本内，才能使用城镇恢复。按下列范围一次结算，不按伤势、倒下人数或幻兽数量另加费用。

| 人物等级 | 全部恢复费用 | 结果 |
| --- | ---: | --- |
| 1～15 | 0金币 | 合格对象生命魔力恢复至各自当前上限，倒下者恢复 |
| 16～50 | `ceil(人物等级÷5)`金币 | 同上；按人物收费一次 |

16～20级4金币，21～25级5金币，26～30级6金币，31～35级7金币，36～40级8金币，41～45级9金币，46～50级10金币。幻兽高于或低于人物等级不另计费。报价使用实际人物等级和服务生效时的真实上限，不用队伍平均等级。

范围沿既有城镇恢复实现：人物与当前角色拥有、未放归且未处于市场托管的全部伙伴，包括首发、替补、携带位及本人仓库。运行依据是`BattleCommandService.recover`调用`PartyFactory.create(owner,true)`，后者读取`CreatureRepository.owned`；当前查询包含仓库。锁定个体仍可接受照护，不把锁定当作禁止治疗。原捕获者已经出售的伙伴、放归个体、市场托管个体及他人伙伴均不在范围内。目录中的“全部恢复”须如实显示覆盖范围，不能写成只治疗两只首发。

全部合格对象已经满生命魔力时，按钮显示“状态已恢复”，不扣钱；教学要求确认使用服务时仍可形成教学结果，不生成经济奖励。部分对象有缺口时显示总价，用户确认后才能付费。新上限由装备、等级及物种当前数据计算，不能按旧上限多回生命；治疗不改变装备、技能、编队、特性、进化或经验。

## 金币不足时的免费基础休整

16级后，金币低于本次全部恢复报价时提供“基础休整（免费）”。不消耗药品或材料，不需生活技能，不设置现实等待、日次数或玩家持续在线要求。具体结果分别对每个合格对象计算：

```
新生命 = min(生命上限, max(原生命, ceil(生命上限 × 0.50)))
新魔力 = min(魔力上限, max(原魔力, ceil(魔力上限 × 0.25)))
```

倒下者同样可恢复到50%生命。高于阈值者不被降低；重复点击只是再次保证阈值，不会逐次增加25%或50%。例如生命上限301、当前0，休整后151；魔力上限81、当前0，休整后21。当前250生命、50魔力保持250／50。零魔力上限仍为0。

这项服务保证可以重新出发，不承诺半血低魔直接打赢任意首领。玩家可走已开放道路进行较低压力的普通战斗获得金币，再选择完整恢复；商店和其他玩法不得以“至少保留治疗费”为由限制消费。经济模型应计算缺钱路径的实际战斗与往返，不把基础休整当作付费全恢复使用。若拥有足够金币，显示正常收费入口，不把本项默认为随时免费的恢复替代品。

## 页面与结算

服务页展示：当前金币、按人物等级计算的费用、将恢复的人物与伙伴数量（仓库单列数量）、各自缺失值；移动到普通任务医护现场不自动弹出付费服务。照护莉娅或伤员的任务不是治疗玩家队伍的隐藏入口。

确认请求在角色锁内重新校验地点、战斗／副本状态、金币、归属及资源上限。扣钱与全部对象资源更新一起提交，重试同一次请求不重复收费；任何对象保存失败全部回滚。交易、存取和恢复串行确定本次对象集合，不能先预览自己拥有的伙伴，再把已经卖出的伙伴治疗到新主人的账户。

基础休整也重新核验金币不足；预览以后获得足额金币时，返回新的报价请玩家重新选择，不自动扣钱。已经满足免费阈值时可返回“已达到本次休整状态”，不发道具、经验或货币。重复请求不能绕过“不累加”的计算。

恢复令本人的战前准备确认失效，需要重新准备；战斗状态及冷却仍沿统一战后清理规则，未结束战斗不许调用本接口消除持续伤害。不能通过刷新、跳过演出或切换安全节点直接回满。

## 可达路径与副本边界

- 村庄遇袭前：广场→幻兽中心。二次袭击后的基础服务改由学院庭院→学院疗养处承接；M109返乡安置后村庄入口重新开放。
- 诺姆：城镇公共道路→幻兽中心。温蒂妮：港务所→收容所内疗养柜台；M110后开放，发生码头冲突时机构仍接待。
- 希尔芙：山口→城内疗养柜台；边境另可沿关道→安置营→医护区。不得把检查哨所、研究柜台或普通伤员任务全部设为恢复点。
- 沙拉曼达：广场→疗养处；联军：营地→联军医护处；终局：已开放的黑棘前沿营。途中的无服务任务医护点不自动等价。

这些是现有相邻节点路径，不是传送。地图示意坐标不等于分钟，真实往返时间与300小时目标仍待可运行场景测量。

副本入口与已解锁休整点继续使用副本专属免费休整，按本次锁定队伍范围处理，不收城镇费、不改编队、不补药、不接通仓库。副本中的玩家不能远程利用本人的仓库治疗或城镇基础休整。退出后必须先完成副本退出结算并实际抵达可用城镇节点，才能使用城镇服务。

## 验收要求

费用检查15／16、20／21、45／46与50级边界；满状态不扣费、金币差1与恰好足额、原值高于阈值、奇数上限、倒下对象、0魔力上限、仓库与市场托管对象、重复请求与外层回滚都要覆盖。地点检查包括村庄关闭与重开、NPC迁移后机构接待、没有`RECOVERY`的普通护理地点、正在战斗与副本中被拒绝。设计测试必须把实际付费恢复和免费基础休整的金币、生命、魔力分别计账；不能将当前全免费运行结果冒充新收费平衡结果。
