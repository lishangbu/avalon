# 采集补给续航

2026-09-22。`GatheringEnduranceTest` 使用正式幻兽成长、药效和自动补给规划，逐轮模拟一小时有效采集，保留恢复上限造成的药效损失。四个物种为 `CLAW_CAT`、`SPROUT`、`THUNDER_LIZARD` 与 `GALE_SPARROW`，各使用6／15／30／50级及五档资源，共80组。[逐组报告](../outputs/life/gathering-endurance.json)包含资源上限、目标与完成轮数、药剂数量、浪费药效和最终资源。

每组满资源开始，选择同档生命药与魔力药各99瓶。全部样本均在额度内完成目标；逐轮保持至少1生命和非负魔法，起始资源＋实际恢复－浪费－采集消耗与最终存量严格相等。

| 采集档位 | 一小时生命药消耗范围 | 一小时魔力药消耗范围 |
| --- | ---: | ---: |
| 木 | 11～14 | 29～40 |
| 铜 | 15～20 | 30～45 |
| 铁 | 12～20 | 25～37 |
| 银 | 12～29 | 25～47 |
| 金 | 11～34 | 24～62 |

范围同时包含不同等级造成的每轮时间差与资源上限差，不能仅据此评价物种优劣。50级四物种采集金档均完成600轮，消耗12瓶生命药和24瓶魔力药；较低等级伙伴使用金档药会有上限溢出，药剂名称相同不代表实际得到的恢复量相同。页面已补充溢出提示。

药剂直接药草需求也已核对：木档2份，其余档3份；同档进阶药草节点每轮产2份，制造一瓶药直接需要1／2轮采药。直接采药消耗低于对应药剂标称恢复量，但这不证明完整补给链自给：仍有另一种资源、工具补造、鱼油、作物和药效溢出的成本。

本模拟刻意隔离资源续航，不处理工具报废、背包满、原料获取和离线，也不宣称能连续挂机一小时。完整经济成本应结合[制造资源总账](manufacturing-balance.md)、种植并行与钓鱼实际成功率继续核算；本轮没有调整药效。
