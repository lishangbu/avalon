# 生活技能升级可达性

2026-09-22。`LifeProgressionTest` 读取正式采集、制造、种植、钓鱼目录，使用实际半点熟练度规则逐次结算，覆盖十种技能的90次升级，并检查10级内容和满级封顶。它与 `LifeSkillRulesTest`、`LifeProductionCatalogTest` 一起通过；[逐级结果](../outputs/life/life-progression.json)保留每阶段选择的内容、成功次数及溢出熟练度。

每级均有适龄内容，没有因低级内容衰减而无法继续升级的空档。工具与辅料的可达性另由目录测试检查；这里假定通过合作取得材料与工具，并能进入资源地图，不代表一个三专业角色能够自给所有材料。

| 技能 | 1→10累计成功次数 |
| --- | ---: |
| 采矿／伐木／采药／狩猎，各自 | 65,408 |
| 工匠／皮匠，各自 | 3,634 |
| 制药 | 7,551 |
| 烹饪 | 18,175 |
| 种植 | 14,963格收获 |
| 钓鱼 | 29,076 |

这条路线每级选择单次熟练度最高的适龄内容，并保留升级时溢出的熟练度；没有按材料成本或耗时优化。种植一格作物算一次，实际可并行种植6～24格，不能将次数直接当作生长轮数。工具报废、钓鱼失败、补给、交易、赶路和收集制造材料均未折算。

采集固定每次1点，因此升级操作次数严格翻倍，单项满级需要约109～182小时有效采集时间（每轮6～10秒，未含中断和补给）。其他技能的适龄奖励不同，经验门槛翻倍不会自动保证每级实际耗时翻倍。当前检查只证明升级可达，完整成长节奏仍须结合材料投入、生长并行及小游戏成功率核算；不能将该报告当作耗时平衡已经验收。

## 种植并行生长节奏

新增 `LifeProgressionTest.farmingGrowthTimeAccountsForParallelPlotsAndMidHarvestPromotion`，读取正式作物奖励、种子价格与生长时间。每轮选择当前适龄作物中每小时熟练度最高者，同效率选短周期，整田同步播种浇水，成熟后立即逐格收获；若其中一格触发升级，剩余格即时按新等级衰减。见[18阶段报告](../outputs/life/farming-progression.json)。

| 升级阶段 | 6格生长小时 | 24格生长小时 |
| --- | ---: | ---: |
| 1→2 | 2 | 0.5 |
| 2→3 | 4 | 1 |
| 3→4 | 7 | 1.75 |
| 4→5 | 15 | 4 |
| 5→6 | 28 | 7 |
| 6→7 | 57 | 15 |
| 7→8 | 113.75 | 28.25 |
| 8→9 | 228 | 57 |
| 9→10 | 455 | 113.75 |
| 累计 | 909.75 | 228.25 |

24格约9.51天，6格约37.91天；这是生长可离线、但每轮及时收获重种的理想排程，不是连续在线时长，也不是保证现实天数。两个方案分别需2727／682次整田种植周期，种子累计325296／325536金币，未扣成品出售收入、未加工具补造；24格另需1800金币扩建。短周期选择偏向最快升级，不代表最少点击或最适合夜间离线的排程。

结果证明当前种植逐级生长耗时总体接近翻倍，取整与升级途中衰减会产生偏差。总周期偏长期养成，已向用户提出保留或整体缩短的可选确认，答复前保留原有数值；不将模型通过写成真人体验已经验收。

## 钓鱼响应与成长时间

`LifeProgressionTest` 新增三种响应间隔×九个升级阶段×256种固定轨迹，共6912局正式规则模拟。控制器仅使用上次已确认状态的鱼区位置，不预测未来轨迹；选择适龄最高奖励鱼种与最低档鱼竿，升级按真实半点规则保留溢出。见[钓鱼逐级报告](../outputs/life/fishing-progression.json)。

| 控制器响应间隔 | 各级成功样本 | 1→10小游戏时间 | 鱼饵金币 |
| --- | --- | ---: | ---: |
| 100毫秒 | 每级256／256 | 80.77小时 | 58152 |
| 250毫秒 | 每级256／256 | 80.89小时 | 58152 |
| 500毫秒 | 每级251～256／256 | 102.19小时 | 见逐级报告 |

原速度下500毫秒在部分阶段没有成功样本，说明慢操作容错不足。已将浮标每50毫秒位移从0.025降至0.015，并将鱼区两段摆动频率从0.65＋难度×0.045／1.8降至0.4＋难度×0.025／1.2。轨迹幅度、熟练度奖励、工具增益、10～20秒时限及断线规则保持原配置。

修正后每级500毫秒样本至少251／256成功，测试要求100毫秒全成功、所有响应情景至少95%成功；原不操作逃逸及时间防加速测试仍需同时通过。100／250毫秒模型共需29076次成功钓获，不含抛竿间隔、购饵、背包、转场及鱼竿补造。响应间隔是控制器采样频率，不是等价的真实网络延迟或人的反应速度。

本次已依据失败样本改进操作容错，但不将模型成功率当作真人成功率。真实移动端连续游玩负担仍须实际试玩。

补充十档难度（包含10级鱼）的固定输入验收：256种轨迹×10档×一直按住／完全松开，共5120局，即使满级技能和金鱼竿也全部逃逸；500毫秒正常跟踪另2560局，各档均达到至少95%成功的门槛。`FishingRulesTest` 原快速跟踪用例也改为只读取已确认鱼区，移除提前读取未来轨迹的测试捷径。日志见`outputs/life/fishing-input-balance-tests.log`。
