# 当前实施状态

## 任务内容

正式目录包含 300 个任务、327 个步骤：开篇 15 项，四城各 60 项，联合终章 30 项，主线后 15 项；主线 145 项、支线 155 项。
目标分类为战斗 111 项、物品资源 106 项、幻兽 43 项、辅助 40 项。混合任务按最高优先级归类，详见[目标审计](quest-objective-audit.md)。

任务支持 AND、OR、XOR 分支、实例进度、显式接取、交付、放弃和幂等回执。
普通幻兽委托检查接取后的真实捕获；高价值幻兽展示检查当前拥有，接受仓库及其他合法来源，不消耗伙伴。
任务提供明确的人物装备，制造和副本均能产出完整装备；副本也提供独立装备效果及特殊图纸，基础制造随专业等级自动学习。

## 内容与结构

36 份任务链维护规则、步骤、分支、奖励和对白；11 份副本文件维护定义、奖励和宝箱。任务链与副本自动发现。
当前共有 77 份内容 JSON 和 39 份共享 Schema，JSON 是唯一维护来源。
数据库由 db/schema.sql 定义当前结构，通过 Liquibase 入口初始化空库；Hibernate 校验实体结构。
图鉴发现与真实获得同事务登记；读取不补建发现或发放奖励。

## 成长规则

两城、火山和联合外围普通巡逻经验倍率 100、金币倍率 1；残留区经验倍率 100、金币倍率 2。
前期任务提供主要成长，后期依靠正式战斗与副本继续成长。
成长预算由 scripts/audit-story-growth.mjs 复算；估算不包含完整补给、战败、旅行和真人操作成本。

## 验证范围

内容结构、引用、目标、对白、分支、接取交付、回执和事务具有自动化验证。
四职业开篇、两城不同顺序、火山、联合终章及部分主线后内容具有自然路线验证；浏览器覆盖桌面和手机的开篇与分支流程。
空库初始化与真实 JAR 启动通过隔离 PostgreSQL 和 HTTP 验收。

300 项任务的目录覆盖不等于逐项真人试玩。完整专业成长、全部支线、后期制造投入、长期经济和真实操作节奏仍需持续试玩与调优。
