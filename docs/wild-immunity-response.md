# 普通野生幻兽对属性免疫的应对

本规则配套[经典特性首批整合](classic-ability-integration.md)。保留飘浮、引火、储水、蓄电和食草的真实免疫，不给普通野生幻兽额外授予跨属性技能，也不削弱捕获前后的同种特性。

## 当前技能覆盖


| 免疫特性 | 初始攻击全被该属性免疫挡住的物种数 | 受影响单次抽取权重最高的遭遇池 |
| --- | ---: | --- |
| 飘浮 | 16 | E24：100% |
| 引火 | 5 | E11：55% |
| 储水 | 9 | E09：85% |
| 蓄电 | 6 | E12：45% |
| 食草 | 4 | E21：55% |

这里的“全部无效”仅指已掌握的攻击技能；所有普通野生幻兽仍有通用无属性物理普攻，威力50、耗魔0，不占技能格。五种属性免疫均不能免疫该普攻。表中权重是单次物种抽取，不是双怪整场无伤概率，也没有假定玩家在所有地区都已经获得对应特性伙伴。

E24说明了必须修正敌方决策的原因：即使两个敌人的已掌握攻击均为地属性，仍应能在观察免疫后采用普攻，而不是一直消耗魔力攻击飘浮目标。现有`WildActionPolicy`只按治疗、保护、减速、爆发、基础攻击顺序选择，没有免疫观察记录；本设计尚未写入该运行实现。

## 可观察信息原则

普通野生幻兽的选择仍只读取上一次已完成回合的战局和公开战斗结果，不读取玩家本轮指令、生成槽位、未触发特性或尚未展示的进化后配置。

实际结算明确产生“某个体免疫某属性直接攻击”或“吸收某属性攻击”事件时，记住**目标个体＋攻击属性**，不记录它是A、B还是隐藏槽。普通0伤害不能自动推断免疫：护盾全吸收、无效目标、攻击落空和场景保护都不属于免疫证据。目标满血导致吸收实际回血0，仍有明确免疫事件，可以记住。

同一普通遭遇的敌方成员共享已公开观察，模拟它们看到了同场战斗。玩家下一场遭遇的其他野生幻兽不继承该记忆。观察保存于本场战斗状态，重连不清空；玩家幻兽换下再上场保留个体身份，因此不能靠换位让野生幻兽重新忘记已观察的免疫。

普通换位不清除观察。气体存在时，选招暂不使用已知特性免疫和毒疗受益记录过滤攻击，但原记录保留；气体解除后恢复使用。该回合已经锁定的攻击不因气体随后出现或消失临时改招。

正常命中只有在公开确认“未被气体压制、未通过破格绕过免疫”的条件下，才能撤销该个体对应攻击属性的免疫记录；其他属性不受影响。事件是明确通过免疫阶段的直接命中，不以实际损血是否大于0代替。护盾吸收、落空、无效目标不提供免疫或失去免疫证据；气体期间正常受伤及破格打穿免疫也不撤销记录。

复制导致临时效果改变时，不因读取内部字段而自动改写野生幻兽认知；沿之后公开结果更新。中毒转恢复事件即使实际回血0也记录受益；仅在没有气体压制时观察到正常毒伤，才撤销毒疗受益记录。气体期间毒伤不证明原毒疗已经消失。

## 下一轮的选招规则

1. 按既定规则选目标，保留魔力与冷却检查。观察记忆不让野生幻兽偷偷改选玩家未提交的替补，也不提前取消已经公开的本轮攻击。
2. 自疗与保护低血友方的优先级不变，它们不因攻击被免疫而消失。保护和恢复本来就可能让本轮没有进攻，这是合法决策。
3. 对选定目标，从减速攻击、爆发攻击和基础攻击候选中排除已经明确观察为无效的属性。带减速的直接攻击如果被该属性免疫，也不能为了附带减速继续使用；独立状态技能另按自己的合法性处理。
4. 在剩余已掌握技能中沿原有优先顺序选择，不额外获取学习池招式。如果没有合法的攻击技能，使用无属性物理普攻攻击原目标。
5. 本轮中才观察到的新免疫从下一轮决策生效。本轮另一个已经锁定的敌人动作仍正常执行，即使同样被免疫；不能在玩家提交后改招。

这些规则只避免重复无效行动，不让普通野生幻兽计算全队最优解或精确识破玩家战术。法术野生幻兽退回物理普攻时，使用自身真实物攻；不临时改用法攻或获得灵爪。因而免疫依然能显著降低受到的压力，只是不保证所有战斗都可无限无伤拖延。

## 保护转移与目标身份

如果攻击原目标A，却由B通过掩护代接并免疫，只登记B的免疫，不能误记A免疫。下一轮普通野生幻兽仍按原规则选择目标；它不因此预测B一定会再次掩护，也不读取本轮保护指令。下次实际选中B时，才利用针对B的已知记录过滤攻击属性。

保护转移结束后才判定免疫，已发生的转移仍消费保护次数。没有成功命中或目标中途退出时不产生免疫观察。捕捉不走这套攻击选招过滤；玩家仍可以直接投球，捕获概率不因免疫特性提高或降低。

## 首领与后续验收

首领属性覆盖须按[当前副本目录](dungeons.md)逐场确定，再验证免疫特性的用途与剩余威胁。当前没有足以证明当前副本属性玩法平衡的完整战斗验收。

首领采用各自已公开的行为循环，不套用普通野生幻兽的即时备选规则。特性免疫可以化解某个预告招式，首领不能在施放瞬间把属性改成无属性。若某场战斗全部有效威胁都被一种免疫消除，应在内容设计阶段审查其其他招式、目标或队友，而不是在运行时偷偷忽略免疫。普通野生幻兽覆盖表与首领静态登记均不证明副本完整战斗已经通过。
