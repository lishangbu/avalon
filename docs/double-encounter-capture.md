# 双怪捕捉与行动交互

29个实际遭遇池中，27个提供玩家主动选择的双怪入口；另两个仍只生成单怪，不随机升级难度。双怪按同池权重独立有放回抽取，允许同种两只，但个体ID、等级、槽位、技能冷却、生命魔力与结算分别保存。

## 实际组合覆盖


| 交互资格 | 涉及双怪池数 | 最高出现概率的池 |
| --- | ---: | --- |
| 至少一只有微疗 | 15 | E14：91% |
| 两只都有微疗 | 15 | E14：49% |
| 至少一只有掩护 | 22 | E16：100% |
| 两只都有掩护 | 22 | E16：100% |
| 一只可自疗、另一只可掩护 | 11 | E05：49.5% |
| 至少一只有逆风 | 13 | E23：100% |

概率描述“生成的组合具备此技能”，不等于每轮必定施放。生命、冷却、魔力与条件优先级决定实际选择。E14、E16、E05、E23作为后续完整双怪战的重点，不因其机制复杂就删除组合或隐藏双怪选项。

## 指令选择与失效

野生幻兽在玩家提交前，按当前已保存的战局决定指令：合法自疗优先，其次掩护其他不高于35%生命的友方，再检查减速、低血增威力攻击和基础攻击。无法支付或仍在冷却的技能先排除，最后可普攻；不偷看玩家本轮投球或攻击意图。

进入执行阶段后，目标生命和有效性会改变。已选自疗在此前尚未行动但被捕获时不会执行；已选掩护的对象被捕获后不能临时改为攻击人物。单体动作指向死亡或被捕获个体时落空，不重新抽选同名另一只；施放前目标已无效不扣该技能魔力。玩家已提交的单体攻击也遵守该规则，不因捕获成功就自动改打另一只。

正常攻击、治疗、掩护等各自仍只占一个单位的一次行动，治疗与捕获都不能复活。单位换入、状态到期和普通／隐藏特性按既有规则计算，本页不新增一次额外行动。

## 明确的交互结果

| 回合情形 | 应有结果 |
| --- | --- |
| A与B都低血且均可微疗 | 各自优先自疗，不互相治疗，也不因有掩护就跳过自疗优先级 |
| A低血自疗，B选择掩护A | 两个动作都合法；B的掩护不取消A治疗，A后来回血不回溯取消已经生效的本轮保护 |
| A与B都低血、均可掩护但无可用自疗 | 可以互相掩护；一次伤害最多转移一次，不在A与B之间循环 |
| B已掩护A，人物向A投球 | 球仍尝试捕获A，不被B代接；捕获率使用投球执行时A的生命和状态 |
| B已掩护A，B在友方攻击前被捕获 | B不再是有效保护者，该攻击按A自身防御与状态结算 |
| 人物先捕获A，幻兽已选择单体攻击A | 幻兽动作落空，不自动攻击B，也不把已捕获A打死 |
| 捕获A成功，B仍未行动 | B仍可执行自己的有效动作，战斗不因少一只目标自动结束 |
| 人物投球失败，随后A自疗 | 本次概率不追溯重算；下次投球按新的生命计算 |
| A先自疗，随后人物投球 | 本次立即使用回血后的生命计算，不冻结提交时概率 |
| 玩家使用群攻同时命中A、B | 两者均按技能正常承伤，目标可能被误杀；不因玩家想捕捉而自动排除某一只 |
| 人物被减速 | 仅后续重新排序的回合改变先后手；本轮已经锁定的行动顺序不因途中减速重排 |
| 捕获一只、击败另一只 | 捕获个体无击杀经验／金币／掉落；击败个体单独产生合法战利品，不能整场双倍或重复发放 |

掩护只转移符合要求的直接单体攻击；不接群攻、不转移封印球。转移后的伤害按实际保护者防御、减伤和特性计算，原目标的防御指令不跟着转移。被捕获个体不成为本场新增出战单位，不领取本场击杀经验。

## 捕捉路径与代价

玩家可以直接满血投球、先压低目标血量、先击败另一只、分别捕获两只，或撤退／认输。没有“必须清掉其他敌人才能投球”的限制，也不强制使用控制或高档强化球处理普通双怪。

选择双怪增加遇到目标物种的机会，也增加同时受击、压血被掩护、投球后被攻击的压力。重复两只同种可以保留一个捕获目标、先处理另一个，但必须通过个体标识手动选中，不能用物种名合并血量或行为。界面沿用每个个体的生命、状态和行动战报，不增加捕捉风险提示或系统代选策略。

捕获后剩余战斗的实际保存与最终持有结果继续遵循既定捕获持久化规则；此处不借组合调整增加失败退款、免费复活或重新生成个体。

## 验证范围

池权重、物种引用、初始技能引用、生成等级与313项有序组合已静态核对。自疗优先级、目标有效性、封印球独立分支与保护者有效性已对照现有WildActionPolicy、BattleEngine和DirectAttackResolver；上表仍需在新成长数据接入后逐项集成验证，不能把规则描述计作已通过的战斗测试。

尚需在重点池模拟实际生命、魔力、技能冷却、其他特性、治疗溢出与连续投球，记录四职业存活、球药消耗和结束回合。当前未得出27池均可稳定双怪捕获或与300小时成长目标相符的结论。
