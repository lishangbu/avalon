# 高地与工坊任务对白

对应[任务包](bright-quests-21-30.md)BQ101～BQ180与[人物设定](bright-story-cast.md)，共80项五态短对白。两条旅行线可交替完成，BQ172才要求两线汇合；工坊对白不假定玩家已经去过高地，高地对白也不提前引用灯会。

现场文字按实际动作节点触发，完成文字只在全部服务端判据成立后显示。战后句子不能在开战前播放；未完成只说明当前真实缺项，不抹除已提交的其他动作。任务资源与正式养成资源分开，对白不额外要求特定幻兽、职业、消费或组队副本。

重访不重发奖励、不重演修缮与放归。过去异常写在调查回顾中，当前场景优先使用最新世界状态，避免风暴结束后仍声称旧异常正在发生。每行是可独立呈现的短文本，不把五态一次全部弹出。

奥伦首次在观星台，BQ116实际到测风石台，现场观测后返回观星台；BQ117由风车匠接待。米菈营地行程中不同时出现在学院，BQ172才回院参与汇合。塔莎与铆钉在各自工作地点接待，灯会聚餐才按活动状态来到广场；普通服务另有人值守。异地行动使用玩家或现场旁白，不让NPC隔空说话。
