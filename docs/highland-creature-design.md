# 31～40级高地与工坊生态

等级口径：[当前150形态选表](current-creature-design.md)及其采用CSV为当前数值依据；本文保留地区、职责与剧情说明，尚未同步的等级叙述不得用于配置导入。

[16行物种规格](creatures-highland.csv)增加8个野外基础种和8个45～50级终阶，联合已有表为92种、46条进化路线。全目录进度见[设计交付清单](design-implementation-gaps.md)。分区预算不变，本批8个基础种填入31～40级，其终阶占41～50级8个名额，不将其同时算作野外新物种。

## 外形与职责

墓穴食尸兽延续已核实的亡灵兽形素材，承担暗属性的物理追击与保护；它与亡灵领主军队分开，出现于返村旧墓地外围不意味着把村民新墓改成敌军据点。铁羽雕用物防换取较低法防，白翼蛇偏高速风法，独角豹偏物理速度。暮光蝶依靠暗攻与减速配合，苔眼灵承担木水恢复选择。荆棘苗提供植物物理防守，巡逻偶提供地系机械承伤。

每只仍只有一个族群与一个属性。白翼蛇归龙族，不因有翅膀同时再计羽族；墓穴食尸兽归亡灵族，不因兽形同时再计兽族。巡逻偶是旧巡路独立活动的野外单位，与城市机械居民NPC分开，不把整个机械族设成失控敌人。

铁羽雕、独角豹等并非所有成长都比沙羽鹰、雷斑豹更高。跨属性攻击继续按实际技能计算，独角豹初始雷牙不享有风系一致加成；玩家要用风法需另学风刃，成长取向使其与法术白翼蛇不同。高等级物种的吸引力来自属性、技能与速度取舍，不靠一律增加成长系数。

六个基础种使用已交付的语义图片地址；荆棘苗和巡逻偶暂缺图。巡逻偶没有借用待确认是否机械的铜甲卫，也不将bsymg维修机械强行改成攻击单位。八个终阶均需独立形象，基础图放大不算完成进化素材。

## 遭遇与道路

[E18～E22五个遭遇池](encounters-highland.csv)覆盖8个基础种，每池权重合计100，双怪独立有放回抽取。旧物种跨区提高遭遇等级不额外占用物种名额，不重抽已生成个体的特性槽位。隐藏仍在捕获后揭示，不因新族群新增捕捉风险提示。

返村旧墓地外围从村外安葬地的旧林路进入，M107完成安葬后可调查，和后段M217军事征用墓地不是同一处。高地峭壁风口从希尔芙山口支路进入；林缘深处承接路标勘查；古林荆棘坡从高地猎棚往西延伸；工坊外旧巡路在M173恢复横向驿路后开放。它们均是主路线相邻生态点，不通过捕捉目标来反向解锁自己的唯一入口。

剧情预算中的31～40级不是硬等级锁。部分玩家到达时可能高于该区间，仍沿既定等级差经验与捕捉修正；不能为了刚好符合表格要求人物退级。40级及以下使用封印球IV的等级范围，41～43级按既定越档规则或选择V，具体商店和掉落需继续在球类投放配置中绑定。

## 特性、技能和进化

本批复用已有20种效果，不增加独占特性。守护物种都有掩护资格；暮光蝶可用逆风为夜袭准备，但不是同次攻击自带免费减速与增伤。苔眼灵的滋养或回春提供不同情境治疗收益，不把元素族自动设为免疫所有控制。

物种表明确初始两技能与完整书池，终阶保留旧书池和实际已学技能，不自动学习、恢复已遗忘技能或改成新个体。每条路线保持原族群、属性及A/B/H逐槽映射，全部终阶仅通过进化取得。

八条配方与材料已加入统一目录：通用1＋专属1、整套18研究凭证、零额外金币、满足条件必成功。材料在WORKSHOP_RESEARCH按配方开放，沿既定教学、地区与绑定规则。38级荆棘苗不是一出现就能进化，需培养到50级；后段物种仍需完成真实成长过程。

## 验收与未完成项

联合核对92种唯一ID、46条进化目标与专属配方、初始技能属于书池、全槽位继承、图片地址、五池权重及任务前置。仍需补齐缺图、实际战斗能力比较、等级球来源和物品掉落，以及全目录跨物种比较；不能把本轮候选视为已写入运行配置。
