# 阿瓦隆游戏设计

阿瓦隆是一款以幻兽伙伴、人物装备和回合制战斗为核心的区域冒险游戏。玩家独自推进四城故事，公共世界支持交易、PVP和可选合作。人物与幻兽成长上限为50级。

## 冒险与任务

晨露村 → 诺姆 → 温蒂妮与希尔芙（顺序自由）→ 沙拉曼达 → 联合行动与封印深渊 → 自由冒险。人类开发遗址破坏相连封印，四城共同修复危机，玩家深入遗址击败灾厄核心。

正式目录300项任务：145主线、155支线。战斗为最主要行动，其次是人物装备、物品和资源，再次是捕捉或拥有幻兽，少量到访、对话、等级与调查。任务支持AND并行、OR任选、XOR互斥及公共汇合。详见[任务系统](quest-system.md)、[故事规则](quest-story-design.md)、[任务目录](quest-catalog.md)。

## 人物与伙伴

四种人物职业使用各自装备与技能。幻兽与人类自然共生，捕捉、培养、进化、战斗与生产是正常生活。高价值展示任务只检查拥有，包含仓库中的个体，不消耗伙伴。具体交付任务明确提示个体与消费后果。

战斗使用人物与伙伴指令、技能、药剂、防御及换位。敌人预告支持玩家选择防御与目标。捕捉按实际目标、封印球和当前状态判定，失败正常消耗，不承诺单球成功。借用训练资源不进入正式资产，见[学院训练](academy-training.md)。

## 装备与成长

任务提供明确的保底人物装备。制造和副本都提供完整装备，基础配方随制造等级自动开放；副本另提供独特装备效果、外观与部分图纸。普通主线可单人完成，高难度内容提供额外追求。前期任务主导升级，后期以刷怪、副本和制造成长为主。

经验、金币、掉落、任务奖励与捕获均通过正式事务结算；回执防止重复发放。等级、职业、部位、所有权和库存由服务端验证。具体数值只以[正式内容来源](chapter-content-sources.md)为准。

## 生产与公共世界

自动采集按周期扣伙伴生命与魔力，并判定空采和工具损坏；成功产出立即入库。伙伴不足或工具耗尽停止，可恢复后返回继续。生产规则见[生活专业](life-professions.md)。

允许PVP的普通区域无免战即可被攻击；免战牌提供期限保护。PVP失败按正常复活处理，既得采集物品保留。采集单人可完成，主线不强制真人护卫、PVP获胜或组队。

市场、库存、仓库、好友和聊天使用独立服务。任务不改变物品所有权或越过正式资产命令。地图移动沿相邻道路，任务、招募和副本入口不提供隐式传送。
