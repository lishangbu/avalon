# 开篇与诺姆任务

更新于2026-10-19。以下75项是首批内容稿，目标数量是策划初值，经验与金币需结合现有成长表复算。只有实施记录明确标出的条目已进入运行目录，其他地点、首领、物品均需正式注册；不能把工作名作为有效配置引用。

## 开篇十五项

所有开篇任务为主线。奖励与交付直接包含在任务内，不另建“领取奖励”空任务。开篇不承载灾厄说明，不设固定同行团。

| O003 趁手的行装 | 领取并实际穿戴职业基础武器、身体与脚部装备 | 把这些穿好再出门。药品和封印球也给你备了一份。 | 明确基础人物装备与首次补给 |

| O013 编队实战 | 在短实践中完成1场包含替补安排的战斗 | 想试试替补？这里有一场短练习，打完就继续上路。 | 实践资源隔离，必要技能引导，不变成长考试 |

| 任务 | 独立行动与目标 | 对白及成果 |
| --- | --- | --- |
| N001 矿口的报酬 | 胜利1场矿口遭遇，正式开启矿道委托 | 矿口已经不安全了。先清掉这一批，里面的活另算报酬。 |
| N002 岩穴兽群 | 接取后击败6个岩穴威胁 | 这批兽群总往旧道聚。先把入口守住。 |

| N015 停用试验 | AND：交付1件替代部件、关闭旧装置、完成停用后的验证战 | 先换掉维持运转的部件，再停用旧装置。 |
