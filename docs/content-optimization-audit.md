# Content 优化验收

更新于2026-09-23，覆盖领域结构、物品分类与固有属性合并、读取校验、业务调用及维护文档。

| 要求 | 当前实现与证据 |
| --- | --- |
| 按领域组织 | Java分为world、quest、item、creature、battle、life；共用读取与校验留在根包 |
| 物品单一来源 | 404项定义统一进入`items.json`的一个`items`数组；显式填写分类和场景范围；料理、工具、封印球、技能书、装备属性和生活回收价随物品维护 |
| 关系各自维护 | 配方、商品及购买价、学习池、掉落、装备套装引用物品编号，不重复固有属性 |
| 描述随领域维护 | 物种、技能、特性说明随所属配置；`ItemDescriptions`派生药效及工具说明；旧描述、料理、封印球独立配置及其读取入口已删除 |
| 严格校验 | Schema拒绝缺失分类、属性错配、未知字段和旧装备数组；Java校验重复编号、引用及组合规则 |
| 场景隔离 | 学院药品不能进入正式库存或普通药品清单；料理不因存在恢复字段进入战斗药品清单 |
| 统一查询规则 | 背包分类不猜编号；工具两级一档要求由配方与工具派生；地点与任务接取复用开放条件；目录及嵌套配置保持只读 |
| 行为保持 | 对照迁移基线核对122件装备、50种工具、20种料理、17本技能书、10种封印球、230条配方及267项生活回收价；原编号、数值、购买价与学院药效一致 |
