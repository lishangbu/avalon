# 阿瓦隆世界观与叙事规则

本文记录已确认的明亮奇幻方向，是剧情设计的当前依据。[基础故事大纲](main-story-outline.md)是据此编写的首版审阅稿，具体事件尚待审阅；300项任务、对白和运行配置尚未据此重编。

## 世界与生活

阿瓦隆是值得生活、探索和守护的世界。温馨日常为主，偶尔热血史诗。居民经营店铺、学习手艺、举办节庆，与幻兽共同生活；冒险也是为了认识朋友、发现风景和培养伙伴。

魔法常见但并非万能。魔法灯、传讯水晶、工坊机械和幻兽运输进入日常生活，通信、治疗与远行受到距离、资源和技术限制。居民仍需要手艺、劳动与合作，不靠魔法随意复活死者或消除一切困难。开篇不由古代装置失效驱动。

保留十一族分类，族群不决定善恶、阵营、可捕捉性或战斗加成。机械族是世界的一部分，不承担解释世界全部秘密的职责。敌对士兵、强盗和人物首领按身份称呼。

幻兽有自己的性情，封印球承载人与幻兽的契约。削弱、捕捉、培养与进化沿用既定玩法，通过照护、露营和共同冒险表现感情；暂不增加饥饿、服从度等负担。主线不强制拥有指定稀有物种或隐藏特性。

观察所得的线索直接写在对应NPC、路标、记录簿或设施资料中，供玩家随时阅读，不拆成多个观察按钮。信息应帮助玩家作出选择或理解故事；是否展开、阅读或刷新不计为任务行动。

## 玩家与指引者

玩家从普通冒险者成长为传奇，不拥有救世血统、开局预言或保证成功的天赋。玩家发现问题、提出办法、作出决定并完成决定性行动。NPC贡献知识和协作，不替玩家完成结局。

“指引者”是理解不同伙伴、找到平息灾厄之路并亲自行动的人。首次平息灾厄后获得称号，不是开局指导其他英雄的职位，也不赋予无限力量。

人物与幻兽共同战斗，不增加固定的人类剧情战斗同伴。村中好友、学院同学、导师、商人和居民反复出现，各有自己的生活目标，关系不只限于发布委托。

个人故事以玩家为主角，公共世界容纳其他冒险者。关键场景与成果按个人进度呈现，不在公共叙事中宣称每位玩家都是排他的唯一救世主。

## 城市与连续叙事

四城以贸易、学院交流、节庆与探险往来为常态。城市不是依次完成的独立章节，人物和事件跨地区延续，旅程允许回访。

| 地点 | 日常气质 | 冒险方向 |
| --- | --- | --- |
| 晨露村 | 园圃、邻里、远行与归来 | 伙伴结契、近郊探索、庆典 |
| 诺姆城 | 市集、学院往来、手艺交流 | 平原生态、地下洞穴 |
| 温蒂妮城 | 河口港湾、沿河街市、航海节 | 海岛、潮汐、水域幻兽 |
| 希尔芙城 | 高地风车、信使、观星 | 迁徙通道、山地与空中遗迹 |
| 沙拉曼达城 | 工坊、温泉、灯火庆典 | 火山生态、矿脉与锻造探索 |

元素意象不限定居民种族或当地全部幻兽属性。学院持续欢迎玩家回来学习、交流和展示伙伴；首次实践短小、使用隔离资源，整条主线不是长期考试。

## 世界冲突与势力

十次世界灾厄覆盖长期创作规划，首发1～50级完整平息第一次。居民开局不知道准确次数；资料片与灾厄不强制一一对应，也不因此增加既定资料片数量。

灾厄共享世界历史与规则，成因各异，包括自然失衡、古老生命苏醒、文明冲突和主动破坏。不将全部归于一个幕后黑手，也不要求每次破坏规模递增。每次结束后有真实安定期，不在庆功后立即宣布下一场末日。

第一次为魔力潮汐失衡：自然周期因部分势力过度取用魔法资源而失衡，早期表现为花期错乱、迁徙和异常风雨，后期形成跨地区风暴。地方反派各有目的，一位主要野心家后期企图借机控制四城，加剧危机；他不是所有地方问题的幕后主使。

玩家先击败利用灾厄的敌人，再深入风暴，与卷入失衡的古老幻兽交战并恢复生态平衡。它有生态职责，并非邪神；战斗为修复创造机会，最终让它清醒并回归栖息地。不强制捕捉或击杀，不靠NPC过场替玩家完成平息。

## 日常、危险与成果

日常故事独立成立：走失幼兽可能只是贪玩，开店困难可能来自经验不足，庆典不必暗藏阴谋。少量异常逐步汇合，其他事情继续属于普通生活，不要求所有人物参加决战、所有小事都是伏笔。

人物允许缺点、竞争、误会和争执；幽默来自生活与伙伴反应，不靠羞辱弱者。允许受伤、撤退、告别与失败，重大后果主要通过共同修复承接；不以毁村、友方死亡与残酷迫害作为常用催泪手段。反派可被击败或死亡，表现克制，不要求全部原谅。

战败按既定损失规则处理，叙事表现为撤退、获救或整备。下线、捕捉幻兽和参加日常活动不会触发现实时间的毁城惩罚。现场紧迫不等于整个成长阶段都在倒计时。

道路开放、生态恢复、设施改善和城市合作是玩家可见的成果，后续不无条件取消胜利。个人主线可以独立完成，合作副本不作为结局门槛。

## 基础主线的收束

灾后四城恢复生活，晨露村始终是能够返回的家。玩家获得指引者称号，与伙伴参加庆典，继续探索、培养和副本冒险。结尾不插入新反派宣言或下一次灾厄倒计时。

## 内容规模与实施边界

保留1～50级、约300项主线、十二副本和幻兽培养框架。任务按完整小故事组织，不拆句凑数；约300小时成长目标独立核算，不靠冗长对白与重复往返拖长。
