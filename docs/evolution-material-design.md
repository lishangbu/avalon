# 进化研究委托与材料结算

材料、配方、掉落率与报价统一见[野生幻兽掉落主方案](evolution-wild-material-design.md)，研究站只提供教学和补缺兑换。当前68种材料、90次转换，同家族两次进化共享专属材料，全部路线都有普通野生幻兽来源；不再要求以研究凭证作为主要获取方式。

## 可重复研究委托

下面是独立研究委托，不占300项主线名额。每次接受后，在对应已开放普通野外区域取得6次胜利，再完成一处现场记录，交回同站获得1枚绑定研究凭证。六次按完整战局计数，双怪战仍算一次；不要求捕捉、隐藏特性、携带对应幻兽或击败其进化形态。任务接受前的战报不追溯计数。

五站具体池、现场记录位置与状态规则统一见[研究委托路线](research-commission-routes.md)及[配置表](research-commissions.csv)。接取时至少有一个合格池和记录位置已随主线开放；未开放的后续区域不会因接委托而解锁。

合格区域名单由配置明确列出，不因地点名字包含“河”或“矿”就自动计入。区域普通遭遇仍需补齐后段敌人配置，但委托不引用未开放副本、研究区内部或未来资料片。人物可以继续做低级研究委托攒通用凭证，沿既定无每日兑换上限规则，不为了防刷擅自加上限。

同一角色同时只有一个此类采样委托实例。每场合格胜利只计入该实例一次，场景记录也绑定实例；完成、凭证发放和实例关闭同一事务。取消后清除未交付计数，不发凭证；重新接受产生新实例，旧战报不能重放刷进度。断线保留当前实例成果。

委托只额外发凭证，不再叠加任务经验、金币、技能书或强化石。普通战斗本身仍按既定规则给经验和掉落；后续经济核算要计入这些收益，不能把研究成本视作全部无收益耗时。不可拿主线一次性战斗、训练战、决斗或重放战报充数。

## 绑定、礼包与进化结算

普通野生幻兽掉落材料不绑定，可交易；研究兑换和教学赠礼绑定。使用任何绑定材料会绑定进化后的个体，全部使用未绑定材料不额外绑定，原本已绑定个体不会解绑。

研究教学完成后获得一次礼包领取资格，可保留到后续站点开放；领取与教学完成分别记录。礼包按选中相邻转换提供足额材料：第一步2＋2、第二步4＋4或一次进化6＋6，不赠技能书、不自动进化。已领取存档不重新赠送，背包满沿待领规则处理，重复请求不能多领。

进化提交核验角色与个体归属、当前位置、非战斗状态、个体保护限制、前置教学、来源物种、等级、实际选择的材料实例及绑定属性。扣材料、更新物种、继承槽位技能、资源截断、图鉴首次登记与回执原子提交。失败不扣材料，成功重试返回同一结果，不再次耗材或套成长倍率。

## 确定来源与待完成项

全部60个家族都有普通野生幻兽材料来源，研究凭证可补缺。五站地图接待、报价和门槛见[站点规则](research-station-access.md)。前沿委托R_FRONTIER_ECOLOGY由FRONTIER_RESEARCH提供，在已开放E27完成6场普通胜利及一次现场记录，沿同一实例规则，不新增额外奖励。

研究过程中的正常掉落、经验和金币照常结算，不能同时按完整刷材料成本和完整兑换成本重复计算培养时长。尚需具体记录点地图注册、真实战斗与走路时间、材料交易供给及精英奖励复算。
