# 四城冒险与封印灾厄：故事及任务系统设计

更新：2026-10-20。状态：设计基线已应用于运行内容；全故事自然流程验收仍在进行。

正式目录包含300项任务、327个步骤，使用O/N/U/S/F/J/E编号。四职业自然路线已通过N025，战士已完成双城、火山、联合终章及主线后试炼和稀有收藏；最新改动的复测范围与经济验证见[实施状态](implementation-progress.md)。

本稿规定当前故事、任务与成长规则。完整内容见[任务目录](quest-catalog.md)。

## 一、创作定位

单人版区域奇幻冒险：玩家独自旅行、接受委托、战斗、获取人物装备、捕捉幻兽、深入副本，从普通训练师逐步成为四城信任的前线冒险者。个人故事可以单人完成；公共世界仍容纳其他玩家、交易、PVP和可选合作，不把“单人叙事”解释为删除多人系统。

不设置固定同行团、竞争对手、统一四城考试、救世血统或开局预言。不设置敌对阵营、声望阵营及幕后邪恶组织。城镇机构是提供服务、知识和协作的角色，不是玩家必须选边的势力。

采用王道成长、地方冒险、史诗收尾。日常语言直接，任务行动明确；允许危险、失败与关键场面的紧张，也保留安稳城镇和轻松支线。NPC围绕所在地的危机、生活与委托参与玩家旅程，港口人物提供交通、入口与必要委托。每项任务应有独立行动和成果，串联对白、观察与移动服务于具体目标。

人类与幻兽自然共生，捕捉、培养、战斗和协助生产都是正常生活。不引入契约伦理、捕捉道德审判、饥饿或服从管理。普通战斗不需要都承担世界状态变化，合理的讨伐、材料和成长委托可以独立成立。

## 二、共同危机与终局

古代封印压制着有实体核心的灾厄。人类开采、考古和遗迹开发造成首次破损；出土装置被用于各地生活和生产后，持续牵动相连封印，扩大破损。参与者最初不了解完整后果，发现真相后共同补救。

灾厄通过裂损遗址、危险环境、衍生怪物、失控守卫和部分幻兽狂化表现。灾厄怪物不可捕捉；受影响的普通幻兽可在解除异常后按正常规则捕捉。普通野生幻兽仍正常分布，绝大多数日常遭遇无需解释成灾厄。

最终副本为“封印深渊”，运行ID为J_ABYSS。五个连续阶段包含通路与怪群，以及外围镇守者、灾厄造物、灾厄核心三个主要首领，检验续航、目标处理和综合战斗能力，参数见[副本目录](dungeons.md)。普通难度支持单人完成主线；可选副本提供更优装备、专属装备、材料和图纸，不影响理解结局。

玩家击败并消灭本次复苏的灾厄核心，持续扩散停止。四城承担外围救援、物资和通路工作，玩家承担关键深入行动。结局不立即预告下一次世界末日。残留敌人、遗迹和高等级地区提供后续冒险；重复副本是玩法重访，不叙述为核心无限复活。

## 三、世界结构与成长

沿用晨露村、诺姆城、温蒂妮城、希尔芙城、沙拉曼达城。功能区称呼仅供设计，不替代正式地名。复用准确的地点ID，新增地点先核对正式目录，中文润色不强制改ID。

| 阶段 | 内容与成果 | 成长职责 |
| --- | --- | --- |
| 晨露村开篇 | 获得伙伴与基础人物装备，完成初次野外委托，踏上旅途 | 任务主导；教学短、可实际操作 |
| 诺姆城固定第一章 | 从矿区讨伐与物资委托进入旧矿遗址，发现封印碎片与出土装置有关 | 任务经验为主，开放基础制造与副本追求 |
| 温蒂妮城、希尔芙城 | 第一城后均可进入，顺序任选；分别查明水域遗址与高地封印节点 | 任务与刷怪并重，逐渐提高战斗成长占比 |
| 沙拉曼达城 | 中间两城核心线汇合后开放核心主线，查清装置与总封印连接方式 | 刷怪、副本成长为主，任务提供解锁及明确奖励 |
| 四城联合与终章 | 完成可并行准备目标，开启最终副本，消灭核心 | 不要求高难度装备，不要求PVP或真人组队 |
| 主线后 | 高等级野外、精英、挑战副本、制造、稀有幻兽与收藏 | 自由刷取，不反复接同类任务才能获得收益 |

继承当前1～50级成长容量作为设计边界，具体章节推荐等级和经验缺口在平衡表测算，不机械平均分级。前期任务保证顺畅推进；后期升级允许且预期依靠刷怪、副本。剧情前置与等级条件分开：任务完成不会自动保证达到下一难度。用实际战斗次数、资源成本和装备条件验收后期投入，不能用对白或往返拉长时长。

中间两城互不要求对方的完成事实。任选先后不会错过必要剧情、奖励和封印线索；汇合任务根据已完成内容呈现对白。已开放城市允许回访。

## 四、任务规模、分类与节奏

正式配置包含300个一次性任务：开篇15、每城60（25主线+35支线）、联合终章30、主线后15；其中主线145、支线155。四城本身240项。任务数量不代替实质行动和成果，也不能用纯领奖或到访步骤机械凑数。

正式分类为MAIN、SIDE，内容标签与目标类型独立。主要目标数量依次为战斗、物品资源及人物装备、捕捉与拥有幻兽、对话移动等级调查等辅助目标。每项任务只计一次，混合目标的统计规则与当前结果见[目标审计](quest-objective-audit.md)；不以标签或奖励种类冒充实际目标，也不把数量比例等同于游玩时间比例。

每城以3～6项的短链为主体，5条五项主线组成区域长线，7条五项支线提供独立冒险；这是目录骨架，不要求所有任务永远正好五步。每城2～3场首领或重大事件，1个主线副本、1～2个可选副本；首领和副本是任务中的内容，不额外重复统计为任务数。已接入副本见[当前副本目录](dungeons.md)，配置接入与自然通关分别验收。

一次性任务负责故事、首次奖励与解锁；重复活动负责刷怪、精英、采集和副本。每日、每周与环任务已有框架可以保留，本轮不把周期任务作为核心成长要求。

## 五、目标与资产语义

| 目标 | 达成依据 | 消耗规则 |
| --- | --- | --- |
| 战斗 | 合法参与的击败、指定遭遇胜利或首领结果 | 战斗消耗按战斗系统；捕获不自动算击杀 |
| 物品收集 | 明确选用当前持有或接取后累计获得 | 领取奖励不等于交付；扣除独立声明 |
| 人物装备 | 道具的一种，可通过奖励、掉落、制造获得 | 展示、持有、装备到槽位与上交分别表达 |
| 捕捉 | 任务有效期间实际成功捕捉指定幻兽 | 幻兽归玩家；历史持有不冒充新捕捉 |
| 幻兽展示 | 到指定NPC主动确认，检查当前拥有的符合条件个体，含仓库 | 不限制合法获得途径，不强制出战，不扣除 |
| 幻兽交付 | 玩家选择具体符合条件的个体并确认 | 从所有权中移除；与展示按钮、提示明确区分 |
| 辅助目标 | 真实移动、交谈确认、等级或有实际判断的调查 | 阅读资料不制造观察事实，不强迫逐页打勾 |

高价值幻兽优先用于展示，避免收走玩家资产。高价值不等于不可捕捉；少量剧情个体可单独限制。交付不默认挑选主力、稀有个体或高投入个体，确认前展示身份和不可逆后果。

一次行为可以推进多个已接取且符合条件的任务；一份物品或同一个体不能重复消耗。行为计数、持有判断、永久事实不能混用。支线接取不限量，追踪仅突出一条主线和一条自选支线，不暂停其他任务。

## 六、多分支任务

| 结构 | 用途 | 完成规则 |
| --- | --- | --- |
| AND并行 | 同时准备物资、清除威胁、调查节点 | 所有必要目标完成；顺序自由 |
| OR任选 | 打通通道或收集材料修复另一条路 | 任一路满足即可汇合，不要求两条都做 |
| XOR互斥 | 有实际后果的支线选择 | 明确确认后锁定路线，未选路线跳过 |
| 条件开放与汇合 | 所选路线结束后进入公共步骤 | 判断所选路线及公共必要目标，不要求不可选节点 |

主线允许不同方法和并行准备，最终汇合到同一明确胜利；支线可有局部不同结局和奖励。不把关键主线奖励或必要功能永久锁在某个选择后。不可逆选择明确说明失去的路线及奖励方向；一般方法选择在不可逆动作发生前可更换。

设计例：矿道封堵有“战胜洞中守卫”和“上交支撑材料”两条方法，完成任一路即可开放同一通路，首次完成以角色事务锁确定，不重复发通路奖励。终章四份物资是可并行的AND汇合，汇交后依次推进外围清理与入口定位；互斥通路只需完成所选分支。

路线奖励按节点领取，公共奖励仅一次；必须定义换方法时已消耗资产及已领奖励，不允许重复领取准备物资。已确认互斥选择刷新、重连、放弃重接后保留。分支不能绕过接取资格、地点、库存、幻兽所有权与战斗参与检查。

当前分支运行时已由正式事务集成测试验证：互斥路线选择后只完成所选路线并进入公共汇合；SWITCHABLE方法在路线完成前允许改选，完成后锁定；工坊两条路线分别消费所选材料、保留未选材料并进入公共汇合。`QuestRuntimeIntegrationTest`的111项回归通过。该证据覆盖任务运行时与持久化事务，不等于所有300项任务都已逐条人工验收，也不等于浏览器端完整操作验收。幻兽展示、指定个体交付、并发切换和跨刷新恢复仍按下方实施测试计划分别核对。

任务列表只显示当前可见路线、已选路线、下一动作及汇合缺项，隐藏未开放的未来剧情。地图对当前追踪目标提供真实道路指引，不传送玩家。

## 七、装备与制造循环

人物装备属于道具。任务提供明确保底装备；更好装备来自掉落和制造。品质建议普通、精良、稀有、传说/剧情级，具体映射现有品质配置后确定，品质不代替等级与装备槽位。

基础制造配方随对应制造等级自动学会，可以制造完整装备；进阶制造使用图纸与稀有材料，同样产出完整装备。副本可以直接掉落完整装备，也可以掉落部分特殊装备图纸，不要求所有装备都先拿图纸。基础制造达到普通副本水平，高级制造接近高难度装备；副本专属独立装备保留不可制造的特殊被动、套装或外观，不能用同一图纸复制其专属效果。

主线普通难度不以高难度专属装备为门槛。基础属性固定，差异以少量可控词条和固定效果形成；人物属性为主、少量幻兽协同。图纸使用稳定掉落或累计保底，数值另表。成品可转移，高阶材料和穿戴条件按进度控制；不在本稿增加普通装备耐久，采集工具损坏独立处理。

## 八、自动采集与PVP

进入采集状态后自动按结算周期采集。周期秒数受采集等级影响，每次按规则消耗幻兽生命与魔法，判定资源获取和工具损坏；不是等整个挂机过程结束后才一次性发资源。成功周期所得立即入库，可能出现无产出周期。状态不足停止，不能无限透支；具体数值与已有采集规则对表。

普通允许PVP区域中，没有免战保护即可被攻击，不要求采集者先主动开启争夺。免战牌保护角色与采集，有消耗和固定时长；主动攻击、进入明确禁用免战的高危区或参与争夺时解除，进入前提示。城镇服务区与其他区域的攻击资格依现行PVP规则核验，不能把“普通区域可攻击”扩张为所有地点无条件可攻击。

采集单人可完成，不强制真人护卫或组队。参与采集的幻兽不能同时出战，受袭时采集结束，幻兽召回及出战状态按普通PVP规则处理。失败回复活点，不额外叠加采集专属惩罚；此前已入库物品保留，未完成周期不发资源。物品不够时返回采集点继续，不清空累计持有量。

普通稀有点位冷却，高价值点位可随世界事件开放。主线需要进入可PVP区域时提供免战牌或非PVP替代路径；禁用免战的强制争夺内容不得成为主线唯一途径。
