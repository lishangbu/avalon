# 领域文档使用规则

## 开始探索前

- 阅读仓库根目录的 `CONTEXT.md`。
- 阅读与当前改动相关的 `docs/adr/` ADR。
- 如果未来出现 `CONTEXT-MAP.md`，按其中索引读取相关上下文，而不是假定所有领域共用一份词汇表。

## 布局

本仓库当前采用单一上下文布局：根目录 `CONTEXT.md` 定义稳定领域语言，`docs/adr/` 保存系统级架构决策。

## 使用稳定词汇

议题标题、测试名、设计文档和代码注释应使用 `CONTEXT.md` 定义的术语，不能以被明确禁止的同义词替代。若需要的新概念尚未定义，应记录为领域建模缺口，而不是随意创造不同名称。

## ADR 冲突

任何建议或实现一旦与现有 ADR 冲突，必须在变更说明中显式指出冲突及理由；不能静默覆盖已记录的架构决策。
