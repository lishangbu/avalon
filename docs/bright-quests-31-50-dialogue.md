# 31～50级任务对白

对齐[任务判据与地点](bright-quests-31-50.md)，覆盖BQ181～BQ300。下表每行依次为接取、现场、未完成、完成与重访文本；现场句在对应行动阶段显示，完成句只在服务端判据成立后显示。玩家可跳过演出查看摘要，但不能跳过实际观察、移动、战斗和疏导。重访不重新发奖或重置世界。

引号内可由明确说话者说出；无说话者为现场叙述。人物按当前任务实际到场，不能在远方即时替玩家见证。任务地点阅读别名沿任务表映射到规范ID，不据对白新增传送。以下是设计文案，尚未接入运行。
