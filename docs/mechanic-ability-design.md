# 机制型特性扩展

[经典特性适配清单](classic-ability-adaptation.md)记录40个代表机制与依赖。本页负责自定义机制的精确规则；同名与扩展效果的身份以[当前72效果清单](complete-ability-interaction-matrix.csv)为准，槽位读取[当前完整表](creature-complete-ability-slots.csv)。

[12种共享机制](mechanic-ability-candidates.csv)与[家族分配说明](mechanic-ability-family-candidates.csv)记录这些机制的设计依据。最终450槽位已并入当前完整表，不另维护32效果的阶段版本。

设计规则不等于已运行；实际范围见[当前差异](design-implementation-gaps.md)。生成仍是A45%／B45%／H10%，进化保留槽位，特性不占七技能上限。

## 机制与代价

| 特性 | 具体效果 | 构筑用途与限制 |
| --- | --- | --- |
| 引雷 | 代接同队其他单位受到的敌方雷系单体直接攻击，该份伤害×0.75；每回合一次 | 雷蜥可以保护水系伙伴；自己被直接选中没有该减伤，不接群攻 |
| 蓄电 | 受到雷系直接攻击并实际损失生命后存一层机会，下次雷系耗魔攻击免费；每场最多兑现两次 | 提供承伤后的资源反击，不免疫雷伤，不绕过冷却 |
| 共生 | 直接治疗另一只所属出战伙伴后，按实际治疗量25%恢复自身 | 利爪猫可维持双宠生命；治疗人物、自己和溢出部分不触发 |
| 蜕壳 | 首次被敌方直接伤害打至半血且存活时，解除减速，速度×1.25、双防×0.90持续本场 | 承伤后改变节奏，快起来也更脆，换下再入场不重置 |
| 灵爪 | 普攻改用法攻对物防，仍为无属性物理威力50、零耗魔 | 法宠获得物理补刀选择，不享受本系，不变成法术伤害 |
| 强行 | 使用附带减速的直接攻击时，移除减速，威力＋40、耗魔−2，最低1 | 当前逆风变为80威力／8魔力，换取输出效率但失去控制与捕获异常加成 |
| 接力守护 | 主动换下时，接替者下一次直接承伤×0.75，最晚下一回合末失效；每个体每场一次 | 小岩怪即使不做终局主坦，也能支援换宠；不免除换怪行动成本 |
| 净羽 | 直接治疗存活友方后解除其减速；每个体每回合一次 | 白羽鹤提供治疗和速度恢复，不解除眩晕、中毒等其他状态 |
| 破甲 | 物理单体攻击造成生命损失后留一层破绽，所属小队下次物理单体攻击忽略10%物防 | 早期獠牙野猪可帮助后期物理主力；下一回合末到期，不叠层 |
| 反震 | 受到敌方物理直接攻击并损失生命后，向攻击者反射实际损血10%，上限自身等级×2；每回合一次 | 荆棘伙伴针对物理敌人；法术、持续伤害、护盾全吸收不触发 |
| 蓄水 | 承受水系直接攻击并损失生命后，回复实际损血5%的魔力，每回合不超过魔力上限10% | 水系恢复宠可借敌方攻击续航，仍受伤，回复不超过缺失魔力 |
| 破阵 | 耗魔单体直接攻击不被掩护、援护或引雷转移，但额外耗魔2 | 针对保护型组合；普攻、群攻、捕获不受影响，费用不足不能施放 |

同一个体仅一个特性，没有共生同时叠加回春、强行同时叠加乘风的情况；队友之间可以组合。普通槽拥有引雷、共生、灵爪等完整机制，隐藏槽不垄断构筑价值。32种是当前测试规模，不是以后每只新宠必须增加特性的数量指标。

## 共享结算规则

跨机制的完整先后顺序、群攻工作状态、换宠／死亡／重连保留表及同归于尽判定，统一见[特性结算契约](ability-resolution-contract.md)。下面是各机制的局部规则；局部参考测试不代表跨机制契约已完成运行验证。

**所属范围。** 人物及其两只出战幻兽为同一小队，不能自动影响副本中其他玩家。普通双怪视为同一敌方小队。共生的受益目标仅另一只伙伴，不能治疗人物后回自己；引雷可保护所属人物或伙伴。

**转移优先级。** 有效手动援护／掩护先于自动引雷。一段直接伤害最多转移一次，转移后按实际承伤者属性计算，不继续寻找该承伤者身上的其他保护。多个引雷候选按本轮已经锁定的行动顺序选首个有效者；实际代接即消耗本回合一次额度，即使护盾最终吸收全部伤害也不退回。破阵绕过这条转移链，不改变原目标是否可被选择。

同一目标存在多个有效手动保护时，按保护实际生效登记顺序选择首个；未被选择的保护不消费。破阵绕过保护时也不消费手动保护或引雷次数。引雷持有者通过手动掩护代接时使用手动规则，不额外获得引雷的0.75系数，也不消耗引雷额度。群攻仍允许战士援护转移被保护者的一份伤害，但不触发引雷或幻兽掩护；同次群攻先锁定各份转移，再计算并扣除伤害，不能让扣血先后顺序改变已经锁定的代接。

**准备与次数。** 蓄电最多一层，被打多次不叠加。只在合法雷系攻击实际施放时消费，不因技能冷却、目标失效或无法行动而消费；原本零耗魔普攻不适用。兑现两次后本场不再储存。蜕壳和接力守护次数绑定个体，换宠、断线恢复、复活不重置；仅新战斗重新初始化。蓄电层在进入替补时清除，已用次数仍保留。

**换宠窗口。** 接力守护仅主动换下存活个体并有合法接替者时触发。被击倒后的补位、战斗外编队不触发。接替者本轮依旧不能行动，保护至本轮及下一轮的首次直接承伤，触发后消失；不能通过反复交换刷保护。同名接力保护不叠加，已有时只保留较晚到期时间。

接力保护在实际直接命中算伤前消费，护盾全吸收仍会消费；持续伤害、反射和捕捉不消费。保护只跟随获得效果的个体，进入替补或死亡即移除，不能转交第三只幻兽或保存到再次入场。破阵只绕过伤害转移，不绕过接力保护、普通减伤或护盾。接替者若持有引雷并自动代接，两种不同来源的减伤相乘，即0.75×0.75＝0.5625，统一在最终伤害取整；此时同时消耗引雷的本回合额度和接力的单次保护。单个个体仍只有一个自身特性，接力保护来源是已换下的队友。

**治疗与派生效果。** 共生只用对伙伴实际恢复的生命计算，自身恢复是派生恢复，不再触发共生、回春、滋养、净羽等直接治疗特性。净羽在合法治疗结算后触发，即使生命已经满值仍可清除减速，但仍支付技能完整费用并遵守冷却，不能治疗死亡目标。净羽不改变本轮锁定的顺序。

**破绽。** 破甲标记绑定被攻击目标及施加者所属小队，不转给其他玩家使用。旧层在下次有效物理单体命中时消费，即使之后全被护盾吸收也已消费；本次若仍实际造成生命损失并具备破甲，再登记新层。不因一次群攻给所有敌人挂标记，也不增强法术分类的奥术射击。物防忽略后最低为1，统一在最终伤害公式内取整。

先确定转移后的实际承伤者，再消费该承伤者身上对应小队的破绽；原目标的标记保留至消费、到期或离场。承伤者死亡不登记新层，死亡或进入替补时清除已有标记。施加者被反射击倒而承伤者存活时，已完成命中仍可登记破绽供队友使用。每个小队的标记独立，不能借其他队伍的攻击刷新或消费。

**技能变换。** 强行只改本次带减速攻击的威力、耗魔和附带减速，保留原属性、伤害分类、目标范围及冷却。逆风仍为冷却2，不能当成无冷却的80威力基础攻击来核算持续输出；失去减速后，也失去原减速为后续行动创造的收益。灵爪只变换通用普攻的攻击属性来源，不改变物理减伤、物防、破甲消费资格或无属性分类。两者均不修改技能书数据及下一次施放的原始模板。

**反射与补魔。** 实际损血不超过该次受击前剩余生命，不能用过量伤害虚增效果。反震伤害向下取整，可为0，不受本系、克制或进攻特性放大，也不触发另一轮反震、蓄电、蓄水或受击特性；普通护盾仍可吸收。原持有者因这一击倒下仍结算已经触发的反射，原攻击者因此倒下不撤回其已经造成的伤害。蓄水在自己倒下时不再补魔，不改变死亡状态。

**死亡与再次受控。** 蓄电不能因致死攻击获得充能，死亡会清除待用充能；复活不恢复已消耗的两次免费额度。蜕壳在首次满足条件时清除减速，之后仍可重新被减速，不能因再次降至半血重复净化。其速度与双防修正取决于本场已触发标记，不能通过换宠或复活重复乘算。

**直接伤害的处理顺序。** 先确认合法目标和完整技能费用，再确定实际承伤者；以实际承伤者的标记、防御和减伤计算伤害，护盾吸收后扣除生命，再结算受击反应。反射使用独立固定伤害路径，仅处理护盾和生命扣除，不重新进入直接受击触发链。攻击者被反射击倒仍允许登记这次已经造成伤害的破甲标记，但不追加新的行动；后续多段攻击是否继续需由多段技能自身规则明确，不从本条推导。捕捉不是直接伤害，不进入保护转移、破甲或反震流程。

**捕获与野生幻兽。** 野生幻兽也使用真实生成槽位的同一效果，不为了捕捉方便禁用反震、自疗或引雷。反射可能击倒正在压低血量的一方，也可能杀死捕获目标；没有自动保命。野生幻兽默认AI不主动换宠或通用防御，因此接力守护、蓄势等在该场野外战斗中不触发可以是正确结果，不额外给予免费动作。

## 初步量级核查

- 共生有效治疗120时，自身最多恢复30；目标只缺20则自身最多恢复5。不会按理论治疗120反复制造恢复。
- 30级反震持有者承受实际损血500时反射50；损血900时受等级上限限制为60。护盾全挡时为0。
- 魔力上限200的蓄水个体承受500水伤，原应回复25，受单回合上限限制最多回复20；当前只缺8则只回8。
- 强行逆风80／8对普通风刃100／12：每次攻击较弱，每魔力威力较高；没有减速，不能同时获得原本的状态收益。
- 灵爪以法攻200对物防100，在20级无其他修正下普攻伤害250；没有本系加成，不等于水弹或暗影箭的威力100伤害。

这些是规则算例，不是综合平衡验证。接力保护、引雷和破甲与人物技能的组合，以及蓄电是否能明显降低高难度药耗，仍需实际多回合比较。

## 队伍构筑与槽位取舍

机制的目标是改变搭配和操作。下列组合是战术设计，不代表已验证胜率；参与者仍只有人物和两只出战伙伴，替补进入遵守正常换宠行动成本。

| 组合 | 玩家需要做的选择 | 敌方应对与局限 |
| --- | --- | --- |
| 引雷雷蜥＋水系输出伙伴 | 面对敌方雷系单体攻击时保留雷蜥在场，承担保护角色 | 非雷攻击、群攻、每回合第二次雷击及破阵均可突破；雷蜥必须承受真实伤害 |
| 共生利爪猫＋承伤伙伴 | 用微疗救队友，同时修复猫自身；根据双方缺血决定治疗目标 | 治疗人物不回自己；集火猫、阻止其行动或制造瞬间致死伤害都能限制续航 |
| 破甲獠牙野猪＋后期物理主力 | 让野猪先行动挂破绽，主力后行动消费；队伍速度与人物攻击顺序都重要 | 人物抢先消费破绽可能浪费主力收益；法术不受益，保护转移后按实际承伤目标处理 |
| 接力守护小岩怪＋脆弱输出替补 | 预判危险回合主动换下岩怪，为接替者留下单次保护 | 接替者当轮不能行动；小伤害可以先消耗保护，每场不能反复刷新 |
| 乘风青岚雀＋能先施加减速的队友 | 由队友提供减速，雀使用风系攻击；控制与输出分工 | 没有有效减速就没有加成；强行持有者的逆风已经移除减速，不能同时担当该组合的减速来源 |
| 净羽白羽鹤＋依赖速度的主力 | 治疗同时清除减速，为下一轮恢复行动节奏 | 不重排当前回合，不解除眩晕；在无减速的战斗中节制或回春可能更适用 |

破甲组合只忽略10%物防，并不承诺补偿旧宠与新宠的全部成长差距。旧宠的价值应通过整队收益核查，不能仅凭“有辅助特性”宣称一定值得保留。引雷等针对机制的价值可集中在特定首领，而非要求每只早期幻兽都适用于所有后期战斗。

[破甲整队核算](breach-party-budget.md)已比较120种六回合静态输出情形。当前10%在10～30级接近或超过替换队伍，40～50级约落后4%～6%；50级野猪的粗略物理／魔法耐久只有替换宠约58%。因此暂保留10%，不因高等级纯输出差距直接上调至20%，也不将该结果解释为旧宠已获终局通用位置。

普通槽与隐藏槽使用场景比较：

- 利爪猫：A活力偏开场承伤，B共生偏双宠共同失血，H回春偏救治半血目标。单个目标危急与全队分摊伤害是不同需求。
- 青岚雀：A轻盈争取先手，B强行改变逆风用途，H乘风依赖已存在的减速。B不能保留同一次攻击的减速收益。
- 白羽鹤：A净羽处理减速，B节制降低每次治疗成本，H回春增强低血线救治。无减速时净羽可能不触发，但不是失效设计。
- 风系破阵伙伴：隐藏槽应对伤害转移，普通槽保留速度或残血追击。在无转移目标时，破阵的额外耗魔是实际代价。

每种特性必须具有可识别的触发场景、可执行的行动手段和明确结算顺序；不要求每场都触发。界面先展示一句核心效果，详情再展示次数、有效目标和失效条件。战斗日志应指明引雷代接者、蓄电免费施法、破甲施加与消费、接力保护消耗及净羽解除减速，帮助玩家把收益归因到特性。捕获前的野生幻兽不显示特性槽位或隐藏标记，但已经实际发生的战斗效果正常记录，不承诺无法由效果推断特性。

技能在学习池中不表示生成时就会；强行等可依赖后来学到的合法技能，学习仍消费技能书并受遗忘规则影响。进化不免费补技能。此次没有新增物种、职业、天气、装备附魔或独立特性技能槽。

候选槽位表不能直接作为运行配置；新增效果必须补齐状态、触发顺序与对应回归，并检查旧宠价值及完整双怪交互。
