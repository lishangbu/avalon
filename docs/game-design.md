# 当前游戏规则概览

阿瓦隆是以地图任务、人物装备、幻兽伙伴和回合制战斗为核心的浏览器游戏。人物上限50级，四种固定职业为战士、游侠、法师和牧师；技能来自职业基础规则与训练完成事实，没有可分配职业树。

## 冒险

正式任务覆盖开篇、诺姆、温蒂妮、希尔芙、沙拉曼达、联合行动及主线后内容。温蒂妮与希尔芙主线顺序可选择。具体前置、地点、战斗和奖励读取[正式内容](chapter-content-sources.md)，任务编号不是执行顺序。

地图移动沿服务端道路验证，剧情事实控制区域开放。任务需要显式接取；战斗、现场回收、物品交付和到访分别记录，读取页面不自动发放资产。见[任务规则](quest-system.md)。

## 人物与幻兽

人物和伙伴共同参战，最多两只出战、两只替补。随身容量随人物等级增长，仓库独立管理。幻兽捕获、学习、遗忘、编队与进化走正式命令，图鉴记录永久发现。物种、学习池、进化和特性以content/creatures目录为准。

人物通过装备、强化、等级和职业技能成长；幻兽受人物等级约束。战斗包含技能、防御、药剂、捕捉、换位和首领预告；训练借用的临时资源不进入正式库存。

## 生产与公共世界

采集、制造、种植和钓鱼见[生活专业](life-professions.md)。商店采购补充缺少专业的材料与工具，交易提供另一种合法来源。服务端核验资产归属、绑定、库存、金币、地点及活动占用。

副本有单人封印室及合作挑战，见[副本目录](dungeons.md)。好友、私聊、世界聊天和系统通知见[聊天](chat.md)。

当前配置范围、专项覆盖和未验收部分见[实施状态](implementation-progress.md)。完整长期经济、全支线与真人体验不能由目录数量或自动化耗时推断。
