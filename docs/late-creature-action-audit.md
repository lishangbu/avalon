# 后期伙伴技能与行动阈值核算


## 明确的测试条件

全部50级，攻击目标生命1650、物防法防270、属性中性。使用本系威力80、耗魔8、冷却0的单体技能，属性一致乘1.2；地系采用碎岩击，其余按水弹、火球术、暗影箭、惩击，逐条验证技能池资格。攻击和受击均最后取整。

受击另设独立满血场景：敌方50级、攻击270、威力80、无属性一致加成；分别连续物理或法术攻击，不治疗、不防御、不代接。活力和明净只在每次命中前仍满血时生效，坚岩与灵肤按类别生效；守护不对自身直接受击提供减伤。沉稳在没有防御指令的本场景不生效。

这些是不同目的的独立场景，不是将攻击、治疗和承伤结果拼成一场同时发生的战斗。恒定三种波动用于边界检查，不表示每次攻击共享同一随机数。列出的攻击次数仅普通条件有效；凝神触发须先花一次防御行动，猛火需要低血、夜袭需要目标已有减速，触发伤害不换算成无代价的持续输出。

微疗按法攻恢复，耗魔8、冷却1。恢复1000点缺失生命的连续施法数只考虑普通治疗，实际有效恢复最后一次截断，最早在第1、3、5等回合施放；目标期间不再受伤。回春另外列出对低于或等于半血目标的单次治疗，不假设每次持续触发。没有微疗学习资格的伙伴不会获得治疗数值。

深影鳗的微疗从当前310提升到341，使恢复1000生命由4次降至3次，魔力32降至24，最早完成从第7回合变为第5回合。晶冠龙283→326虽然提高治疗，却仍差一点达到三次恢复1000的阈值，因此不能将所有法攻提升都宣传为少一次行动。

夜冠鸦A槽轻盈后的速度179，早期夜影狐为166；两者都能抢在速度150的目标前行动，对速度170目标才出现先后手差异。A槽没有凝神或夜袭，三者不能叠加。熔甲龙速度84，对比紫焰灵兔132，较强承伤和火球伤害仍以明显慢速及缺失治疗资格为代价。

## 结论与剩余验证

八组候选已经有可计算的优势与弱点，特别是恢复次数、混合承伤与先手阈值；这比统一增加一档属性更能解释后期捕获价值。但单体阈值不证明完整队伍平衡。

后续需把具体副本的敌方速度、连续预告伤害、光幕/掩护行动、治疗溢出和魔力补给纳入逐轮路线。早期可用不等于同样快，后期增强也不意味着可以无视机制；在完成这些比较前，不把本候选当作已完成的整体数值平衡。
