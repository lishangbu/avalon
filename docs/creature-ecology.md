# 幻兽素材与地区生态规划

当前基础版规划至50级，幻兽设计规模为150形态、60家族，其中包含90项相邻进化转换。
数值、特性、学习池、遭遇及材料的采用文件统一见[当前幻兽内容清单](current-creature-design.md)。
这些是设计交付范围，不等于服务器已经开放全部物种；实际运行范围见[实现进度](implementation-progress.md)。

## 素材来源与交付

本地 ol 素材的来源路径、SHA256、尺寸和透明通道记录在[素材映射](creature-assets.csv)，
实际前端资源及缺图情况见[图片交付](creature-asset-delivery.md)。原始文件保留用于追溯，
来源目录中的水、火、风、地、雷不自动决定阿瓦隆属性，来源文件名也不直接作为物种名称或编号。

[bsymg动画目录审阅](bsymg-asset-review.md)区分单体候选、待提取图集及尚未审阅内容。
图像数量、重复动画帧和实体条目不能直接相加作为可培养物种数量。
未核对图像的形态仅能标记为文字设计，不能宣称资产就绪。

## 地区投放原则

所有投放须符合50级范围及[当前采用表](current-creature-design.json)，不另维护一份地区数量配额。
普通基础种、进化形态和首领用途分别管理：地图首次出现、可捕获入口、技能书和进化材料均需实际配置。
跨区重复出现不增加图鉴物种数；大型稀有兽与龙类的获取时点由成长和队伍职责决定，
不因素材可用就全部投放到开篇。

利爪猫使用CLAW_CAT对应形象。小岩怪、芽灵、雷蜥、青岚雀、紫炎兔、影尾狐和月光蛾
不能因为另一张图片相似就直接替换外形或物种身份。
恶魔与机械等族群属于世界生态，不能按来源图像推断整个族群敌对。
NPC或首领形象不自动计入可捕获物种，职业称谓也不作为种族。

## 每个形态的交付要求

每个形态须有稳定编号、中文名、家族与进化阶段、图像来源、族群、属性、
首次等级和地图、遭遇权重、基础捕捉率、整数七维基础值、初始技能、技能书池、
A/B/H槽位、相邻进化目标、配方材料来源和图鉴归属。

普通槽位允许相同特性，隐藏特性强调场景用途；45%/45%/10%的槽位在生成时确定，
捕获保存该个体，进化继承槽位。形态之间可以共享特性和技能，不按形态数量强制设计独有机制。

主线不强制捕获某个稀有概率物种。封印球每档覆盖10级，捕捉等级差和技能遗忘沿正式规则。
交易、提交、锁定、初始伙伴保护和副本队伍保护不因物种扩充绕过。

## 验证边界

设计表结构校验、运行目录接入、实际战斗与图片审阅分别验收。
150形态清单不能替代逐形态的技能执行、完整进化链、地图可达性和经济验证。
图片生成目前暂停，缺图状态如实保留，不能用素材总数或相似图复用声称全部完成。
