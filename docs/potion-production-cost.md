# 药剂原料与时间账本

2026-09-22。`PotionProductionCostTest` 展开正式十种药剂及鱼油配方到药草、鱼、作物，分别计算单瓶与99瓶批量。钓鱼成功率按100%／75%／50%三个假设做敏感性分析，共60行，见报告（按测试流程生成）。这些成功率不是真人测量。

批量共享原料与收获余量：99瓶金档药需要297份药草，在每轮2份的节点需要149轮，而不是将单瓶向上取整后的2轮乘99。每格产4份的作物需要50格收获，末格余下2份。

以下为99瓶、50级采集伙伴、钓鱼成功率假设75%的结果：

| 项目 | 基础魔力药 | 金档生命药 | 金档魔力药 |
| --- | ---: | ---: | ---: |
| 采药有效秒数 | 594 | 894 | 894 |
| 需要鱼数 | 0 | 99 | 99 |
| 期望抛竿次数 | 0 | 132 | 132 |
| 钓鱼有效秒数范围 | 0 | 1650～2640 | 1650～2640 |
| 鱼饵金币 | 0 | 264 | 264 |
| 播种格数 | 50 | 99 | 50 |
| 种子金币 | 400 | 1980 | 2000 |
| 6格农田生长时间 | 9小时 | 4小时15分 | 9小时 |
| 24格农田生长时间 | 3小时 | 1小时15分 | 3小时 |

成功钓鱼按正式10～20秒窗口、失败按20秒超时处理；主动提前放弃或网络中断不属于该假设。鱼种由玩家选择，鱼油采用同产物按配方编号排序的首个来源，未另加随机抽中鱼种的等待。

农田假设每轮成熟立即收获、重种，无操作间隔。报告的 `plotSeconds` 是总农田占用；6格／24格时间是并行生长轮数，不是把每格时间串行相加。生长可与采集钓鱼重叠，因此也不能把农田时间直接加进在线工时。种子与鱼饵金币保持独立，不杜撰金币兑换时间的比例。

这次补齐了药剂直接原料和并行生长账目。工具补造、为采药再次补药的递归消耗、路程、种植操作间隔和扩地费用仍未进入该报告；不能把此表称为最终完整成本。现有装备工具递归成本见[制造核算](manufacturing-balance.md)，实际恢复上限及药效损失见[采集续航](gathering-endurance.md)。
