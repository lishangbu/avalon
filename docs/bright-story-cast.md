# 主要人物与第一次灾厄的因果

依据[世界观](narrative-design.md)和[故事大纲](main-story-outline.md)细化，作为后续任务编排基准；角色未全部进入运行配置。新增人物不自动替换已有服务NPC，正式绑定需核对唯一ID与地点。

## 反复出现的熟人

| 人物 | 身份与自己的目标 | 性格、局限与玩家关系 | 独立成果及后续作用 |
| --- | --- | --- | --- |
| 阿德 | 晨露村村长，希望年轻人能远行也能回家 | 记性好、爱叮嘱，不掌握外界秘密 | 庆典如期举行；保持家乡日常接待，不远程发布全世界命令 |
| 布鲁诺 | 修理武器与农具的匠人，想带出可靠学徒 | 嘴硬，承认自己不懂魔法生态 | 木剑信物与修理教学；后来替返乡旅人保养装备 |
| 梅莎 | 幻兽中心管理员，照料待结契个体 | 温和但要求认真负责，不以稀有度评价感情 | 第一位伙伴、日常照护；归来时根据玩家实际伙伴反馈 |
| 特林 | 小站与村庄之间的信使，想独立跑长途 | 热心且容易抢着答应，不成为固定战斗同伴 | 学会安排送信路线；后期负责已验证路线的信息传递 |
| 克林 | 学院院长，支持把观察带回课堂 | 博学但会承认没有证据，不能一眼识破灾厄 | 批准跨地区观察合作；不代替玩家制定结局 |
| 费恩 | 学院实践导师，希望学生能够独立判断 | 严谨，有些冷幽默，不要求唯一正确队伍 | 完成短实训即认可远行资格，后期以同行研究者方式交流 |
| 米菈 | 同期学员，想画一本自己的旅行图册 | 观察细致、方向感一般，不永远充当被救者 | 独自完成一段测绘，后来与玩家交换记录；不加入可控队伍 |
| 罗温 | 诺姆杂货店经营者，想把小店重新开起来 | 手艺好但不善备货，问题与阴谋无关 | 玩家帮他找到合理供货与商品安排，店面真实营业 |
| 莎琳 | 温蒂妮船工，想让旧帆船重新参加航海节 | 直爽，不擅长说漂亮话，重视乘员安全 | 航海节顺利出航，后期按船只能力承担外围运送 |
| 佩罗 | 港城幼兽照护员，想减少迁徙时的误入事故 | 耐心，偶尔过分保护，愿意接受新观察 | 幼兽回到群体，回流事件时提供习性记录，不提供万能答案 |
| 伊芙 | 希尔芙信使，维护高地邮路 | 独立、守约，不为剧情随意冒险 | 新信路开通；危机中主动关闭不安全的线路 |
| 奥伦 | 高地观星者，记录季节与风向 | 不善交际但乐于分享，不会预言命运 | 与玩家共同区分正常周期与异常偏移 |
| 塔莎 | 沙拉曼达工坊负责人，希望学徒安全出师 | 务实，会质疑空泛停工要求，也接受可行方案 | 改造用料与排放流程，保障日常生产，不把全城写成贪婪者 |
| 铆钉 | 机械族温泉设施维护员，喜欢研究声音 | 认真、爱收藏普通小铃铛，无古代核心使命 | 修好公共设施，参加灯火庆典；族群自然融入生活 |

上述14人是反复出现的核心熟人，不以增加到80人为近期交付目标；其他接待人物按具体故事需要增加，不凭空占名额。玩家可拒绝闲聊但不因此失去主线奖励，不用友好度数值锁剧情。

## 主要对手：塞维恩

塞维恩是恶魔族的远征领主，经营北方要塞和私人护路队。他希望以资源、道路和武力迫使四城接受自己的统治。最初以高价护送与独占契约出场，中段强占采集地，后段封锁通道并利用风暴制造依赖。恶魔族居民、商人和反对者不因此与他同阵营。

他有真实的运输与组织能力，因此威胁不是靠NPC集体失智成立。弱点是将生活与生态都当成可以控制的资源：他知道采集增加异常，却相信可以在失控前夺得足够力量。他不是潮汐的创造者，也没有策划所有地方盗匪活动。

玩家至少三次看到他的具体影响：不公平的独占要求、被封的迁徙道路、强制采集的扩张；不是在终局第一次听见名字。最终主线击败并拘捕他，护路队被解除组织能力。拘捕为本次具体创作选择，不要求额外审判任务链；资料片不使其越狱抹掉本次成果。

## 古老幻兽：岚潮龙

岚潮龙是随季节迁行的古老龙族幻兽，不是神明或玩家的血统守护者。它在山地气流与海域潮汐交汇时迁移，身体周围的魔力流动帮助疏导自然积累；它并非唯一维持世界的生命，世界不会因它短暂停留就立即崩溃。

平常人只见过远处身影与迁徙痕迹。前期不直接公布终局身份：港城的旧航行记录、高地的季节观察及玩家的现场发现共同解释它的路线。记录有可核验日期和地点，不以神秘预言证明玩家被选中。

过量采集造成局部流动失衡，封锁与惊扰阻断迁徙，岚潮龙反复尝试穿越异常区，进一步卷入风暴。它没有邪恶人格或可被打掉的黑暗分身。最终挑战的胜利条件是击退危险攻势并完成疏导行动，使其恢复自主行动；清醒后离开，不发放可捕获同一个体。

外形与最终属性、技能、数值待正式战斗设计，不因为名字含岚与潮就临时引入双属性系统。图片暂停不妨碍剧情与机制规格推进。

## 必须成立的因果链

| 观察或行动 | 获得的判断 | 玩家下一步与结果 |
| --- | --- | --- |
| 近郊花期和迁徙提前 | 异常可能局部发生，尚不能宣称灾厄 | 记录并继续普通旅行 |
| 港城回流与内陆观察在时间上吻合 | 不同地点可能共享周期问题 | 玩家主动提出跨地区核查 |
| 高地风向、工坊取用及生态变化对应 | 过量取用和受阻迁徙放大失衡 | 试行一处减采与通道修复，观察改善 |
| 塞维恩拒绝减采并扩张封锁 | 需要制止具体阻碍者 | 玩家夺回通道，四城各自完成实际协作 |
| 对手失败后风暴仍持续 | 存量失衡和岚潮龙受困仍须处理 | 玩家进入中心执行疏导，不否认此前胜利 |
| 潮汐恢复、岚潮龙正常迁行 | 本次灾厄已经结束 | 完成有限修复，回到生活，获得指引者称号 |

试行改善不能靠一次点击宣称验证：至少包含操作前记录、实际行动、操作后可观察变化，并指出一处改善不等于全世界恢复。核心行动无需指定物种或付费物品，不能让NPC提交成果而玩家只收信。
