# 阿瓦隆1～50级基础故事大纲

本文为依据[已确认世界观](narrative-design.md)编写的首版审阅稿。方向已确认，下述具体事件、人物行动与高潮衔接供审阅，尚未重编300项任务或接入运行。段落只用于阅读组织，不是玩家可见章节或等级门槛。

## 从晨露村出发

晨露村正在准备庆典。玩家向往远方，却还没有真正独自旅行过。村长阿德请玩家取回寄存在布鲁诺店里的木剑：它是介绍信物，证明玩家愿意承担照顾伙伴的责任，不限定玩家必须使用剑。梅莎介绍利爪猫，让玩家与第一位伙伴结契。

庆典准备带来第一段冒险。玩家沿河寻找被小岩怪搬走的装饰石，学习观察、捕捉和编队；在村外洞穴应对阻碍商路的幻兽，学会预判攻击与照顾全队。并非每只野生幻兽都怀有恶意，但危险需要认真应对。第一场胜利让庆典物资按时送到，玩家当晚就能和伙伴坐进宴席。

村长交给玩家前往诺姆学院的介绍。告别没有袭村和家人失踪，村民只是叮嘱小心，欢迎随时回来。途中，玩家帮助小站照料疲惫的驮兽，发现今年迁徙比往常提前一点；当地人不会立刻把它解释成末日。

## 学会独自旅行

学院里有人准备远行，有人第一次认识自己的伙伴，也有人把药瓶和颜料放错位置而闹笑话。玩家通过短实践学习队伍指令、替补、属性、封印球、技能书、装备和物品管理。课程使用临时资源，不损伤真实伙伴，也不要求教学消费稀有物品。

最后一次实践要求玩家自己选择队伍、准备补给，完成一段野外调查。导师提供必要帮助，不替玩家解决问题。玩家带回实际成果，取得独立冒险资格；这个成就当场得到认可，后续旅程不再由学院逐项布置。

在诺姆城，玩家帮助一位店主重新开张，结识往返港城的商人，参与恢复被落石堵住的探险小路。有些任务只是普通生活问题。园圃花期错乱与洞穴幻兽改变活动范围，则成为少量值得记住的异常。

## 港城的航海节

玩家前往温蒂妮，最初为了见识海域幻兽与航海节。船工、药材商和沿河摊主各有忙碌的生活。玩家准备出航、探索近岸洞穴、照顾误入港湾的幼兽，也与偷运资源的盗匪发生冲突。

航海节并非注定被毁的舞台。主要活动顺利举行，玩家与熟悉的人共同完成一次航行。随后的一次探索中，本该顺潮离开的幻兽群困在异常回流里。玩家观察路线、打开障碍，应对惊慌的强大个体，促成迁徙，第一次明显改变一片地区的生态状态。

港口与诺姆的记录表明，异常不只出现在海边。玩家主动带着发现回访学院，与导师和当地观察者核对，不是突然从信使那里接到拯救世界的命令。判断仍有疑点，需要亲自继续探索。

## 风中的来信与工坊的灯火

希尔芙的信使、观星者和迁徙通道看护者成为新朋友。修复风车、护送信路、帮助年轻幻兽越过山口，都有独立的结果。露营与旧友来信让玩家感到旅行积累的联系。高地气流异常与港城回流逐渐对应起来，形成关于魔力潮汐的解释。

沙拉曼达提供另一面证据：魔法资源取用过量的地区，地热、植被和幻兽活动互相影响。城市并非集体贪婪，许多工匠依靠可持续生产生活。玩家帮助调整受影响的工坊、调查违规采集，也能参加灯火庆典、体验温泉和认识机械族居民。

几条地方故事可交替推进。玩家回港城处理航路，到高地完成生态调查，再回诺姆交流成果；四城不是依次交钥匙的关卡。自己的伙伴与实际见闻，常能补上某位专家看不到的部分。

## 被利用的潮汐

恶魔族远征领主塞维恩，此前通过资源争夺与道路冲突逐渐进入故事，开始以保护为名控制航路和采集地。他知道异常，却把它当作迫使四城依附自己的机会。各地盗匪并不全听命于他，也存在独立逐利者和竞争对手。具体人物动机见[主要人物与因果](bright-story-cast.md)。

玩家证实集中取用与封锁加剧失衡，主动提出恢复资源循环、开放迁徙通道的办法。四城担心停工、运输和居民安置，需要具体方案。玩家依靠已开通的道路、生态观察和人际信任促成合作，而不是凭一次演说获得全部支持。

行动前仍允许完成地方故事，不设现实倒计时。进入具体行动后，玩家与伙伴夺回通道、阻止强制采集，深入据点击败塞维恩并交由当地守卫拘押。他失去控制四城的能力，玩家的胜利成立；但魔力潮汐不会因为一个人倒下就立即恢复。

## 进入风暴的人

失衡汇聚为跨地区风暴。古老幻兽岚潮龙原本随自然周期迁行，帮助魔力在不同生态间流转，如今也被异常潮汐卷入，受惊并扰动周边。它不是惩罚世人的神，也不是必须杀死才有奖励的邪物。名字不决定最终战斗属性，不因此新增双属性规则。

四城承担运输、安置、医疗与外围恢复。熟人按各自能力参与，有人只是照常开店，为归来的人准备热饭。玩家提出深入风暴、为恢复自然流转打开窗口的方案，并亲自带队执行。关键手段来自观察、实际行动与普通可获得的队伍能力，不要求某只稀有幻兽。

最终战斗要应对失控攻击、保护队伍、辨识潮汐变化并执行恢复行动。战斗与操作共同推进成功，不在胜利后交给导师施法收尾。玩家与伙伴坚持到自然流转恢复，古老幻兽逐渐清醒，沿重新开放的路径回归栖息地。

第一次灾厄得到完整平息。后来的普通风雨和野外危险，不作为此次胜利尚未成立的借口。

## 仍然可以回家的远行者

玩家完成几项有终点的修复，看到航路恢复、工坊营业、迁徙重归正常。学院与四城以“指引者”称呼玩家，是认可其找到道路并亲自走完，不是宣布接下来还有九场末日考试。

故事回到晨露村。村民想听旅行趣事，梅莎认出曾送出的伙伴，玩家也能介绍后来结识的新成员。庆典多了远方朋友，但没有所有人排队歌颂英雄的仪式。玩家与伙伴坐下来吃饭，谈起第一次出门时还不懂的事。

世界继续开放，可以探索、培养幻兽、挑战副本，或回熟悉的地方看看。结尾不出现新反派宣言，也不宣布下次灾厄日期。这次旅程有真实结果，也有继续生活的余地。

## 十二副本的故事位置

以下是场景题材与职责候选，不是最终名称或D编号映射。等级、经验、装备和道路需随重编核对；每个副本仍须具体人物、首领性格与机制，不全靠水晶机关解决战斗。

| 场景题材 | 独立故事与冲突 | 主线关系 |
| --- | --- | --- |
| 林间兽栏 | 阻止盗猎，挑战看守与驯兽师 | 前期伙伴主题 |
| 废弃矿场 | 争夺采掘权的矿头封住出口 | 诺姆地方冒险 |
| 幽灵庄园 | 徘徊者、旧约与不肯离开的主人 | 神秘故事，不把亡灵全部写成恶人 |
| 海盗城堡 | 港湾掠夺者与各有专长的头目 | 商旅与航海生活 |
| 潮汐洞窟 | 异常回流中的巢域争夺 | 潮汐影响的可选深化 |
| 山口旧堡 | 占据信路的佣兵与堡主 | 希尔芙地方冲突 |
| 空中遗迹 | 危险生态、坍塌道路与探索者 | 独立探索 |
| 地热工坊 | 失控生产与拒绝停工的负责人 | 沙拉曼达生产矛盾 |
| 火山巢穴 | 巢群争斗波及山麓道路 | 强大幻兽的生态故事 |
| 秘密采集场 | 野心家的精锐和过量取用设施 | 核心冲突支线 |
| 风暴边缘 | 异常天气阻断救援和迁徙 | 合作行动 |
| 北方要塞 | 地方军官、守卫与据点统领 | 敌方势力挑战，不复活主线反派 |

主线有自己的完整行动链，任何合作副本都不成为观看结局或取得指引者称号的门槛。
