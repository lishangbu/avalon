# 移动端生活操作验证

2026-09-23。本轮执行浏览器可复验部分；未连接实体手机，锁屏、真实触感和真人操作时长仍待设备记录。

## 已改进的操作

- 钓鱼检测浏览器离线事件后清除按住状态、禁用按住按钮和抛竿，并明确提示本局停止及鱼饵不返还。重连向服务端确认结束；快速重连也不能撤销已经发生的离线结束请求。
- 制造材料汇总同时显示本批需要、已选、可用库存及未绑定数量；无需展开上百个来源逐项寻找缺料原因。绑定材料仍须由玩家明确选择。

## 可复验范围

`LifeSkillsBrowserIT`使用独立打包进程，桌面和手机视口使用同一组真实接口：

- 真实触摸按住／松开，钓获及刷新后鱼获保留。
- 输入响应在途时快速切后台再返回，当前局仍结束。
- 下一局首个输入不继承上一局按住状态。
- 浏览器离线超过2.5秒，操作按钮禁用；联网后当前局结束，鱼饵实际消耗而已有鱼获保留。
- 288个材料来源的制造流程：库存192份铜矿，其中99份未绑定；快捷填入仍准确保留绑定确认，制造后刷新保留成品。

`LifeCooperationTest`沿真实业务命令执行采集→恢复→移动→合并挂单→另一账号购买→设施制造及补造链，操作账来自本次测试。
这是服务器集成流程，不是两名真人的完整页面操作录像；模型的每命令2秒不记录为真人实际耗时。

实体手机步骤与返回记录见[真机验收](life-mobile-check.md)。须补齐设备、系统、浏览器、网络和版本后，才能核验锁屏、系统回收网页、Wi-Fi与移动网络切换及10局钓鱼手感；暂不修改配方数值。
