# 联合行动与终章

J001至J030承接四城成果。四城物资筹备可并行完成，汇交后依次清理外围、定位入口，再深入封印深渊。

联合准备认可自行采集、制造、交易和采购的普通物资，不要求玩家同时学习多个制造专业。沙拉曼达生活用品提供药草、木级加工成品、银矿、银级部件与试剂，价格高于自行采集制造的材料成本。采购照常扣金币，交付照常消耗物品；缺少专业不会阻断单人主线。温蒂妮先行的完整主线路线已通过正常采购、材料消费和终章自然验收。

封印深渊有五段战斗：外围镇守、深处兽群、灾厄造物、核心通路兽群和灾厄核心。休整、阶段任务接取、战斗提交、奖励及离场均走正式事务。

玩家击败本次复苏的核心后停止扩散，四城继续修复。结局奖励、现场成果与节点交接按任务前置结算，不预告新的世界末日。

E001至E015提供主线后的自由挑战、装备制造和收藏。重复副本作为玩法重访，不叙述为核心不断复活。高难度不阻碍主线结局。

目录、阶段事务及J030完整自然终局已通过定向验收；各城完整支线、主线后制造与长期经济仍待验收。

外围普通巡逻与其他高阶区域使用相同的100倍基础经验收益，金币倍率仍为1。按正式公式估算，36级到40级约需48～50场胜利；任务与副本奖励可抵扣部分场数。该估算不代表实际战斗通过。
