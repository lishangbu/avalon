# 后期治疗与魔力容量边界


## 规则与样本

治疗术法攻×2、耗魔12、冷却0；微疗法攻×1、耗魔8、冷却1。微疗最快第1、3、5……轮施放，冷却跳过一个完整后续回合，不能把冷却1当作每轮可用。治疗不复活、不暴击、有效量不超过缺失生命，战斗不自动回魔。

人物魔力沿候选长期公式，牧师50＋5L。幻兽魔力按其基础物种配置及进化绝对倍率计算，法攻也是先计算未取整基础成长再乘终阶倍率。未加入三阶段候选或额外隐藏特性，不将学习池资格等同于每只个体已经学会微疗。

牧师分别列初始装总量标尺与D10未强化七件散件；幻兽列等级门槛允许且学习池包含微疗的形态。所有单位假设开始时满魔力，仅治疗、不使用其他耗魔技能、不被控制、不被迫防御或换出。因此结果是可供后续模型使用的上限，而非实战保证。

## 可用治疗与行动代价

47级初始装牧师一次治疗510，魔力285，最多23次治疗。24回合全程每轮治疗需要288魔力，缺3；36回合全程治疗需要432，缺147，V魔力药每瓶88，因此纯资源下限分别1瓶、2瓶。这是假设能在缺魔前由合法行动补到且不溢出的下限；牧师自己用药会占用一次人物行动，不能仍记该轮治疗术。外部补药也占用施药者真实行动，不能视为免费。

47级利爪猫一次微疗255，魔力228。24回合最多12次、名义总治疗3060、剩余魔力132；36回合最多18次、名义4590、剩84。这里只说明微疗自身不易在这些轮数耗尽魔力；冷却空档用水弹也会耗魔，不能把剩余魔力重复分配给无限进攻。

三人每人带一只仍学会微疗的利爪猫、另一出战宠自由，是可获取来源的参考构筑，不是强制组队资格。24回合三只猫合计名义治疗9180，实际会被目标分布、溢出、速度、死亡、防御和换宠减少。20种职业组成表按0～3位牧师分别增加11730名义治疗，同时这些牧师用于输出的行动减少；不得仅按总治疗量为职业排强弱。

## 对持续帮助者经济的影响

目前不能把“各耗2瓶生命/魔力药”的压力输入当作每次真实消耗。三只猫的治疗容量表明，一些队伍可以通过幻兽治疗减少生命药；但这样也消耗幻兽输出行动，可能拉长战斗并增加承伤。无牧师队伍不一定药品更多，也不一定不需要药，必须将输出与承伤联算。

D12最低等级赤羽鸟防御后接马尔克单体重击需要行动前至少1006生命。微疗255或V生命药440能补多少缺口，取决于已有生命、治疗者实际行动顺序及目标是否仍存活；不能先让目标被击倒，再用本轮稍后的治疗抵扣伤害。人物行动和两只幻兽行动分别记账，不能借总量加和制造不存在的同时施法。

## 下一步联合模型的输入边界

逐轮模型必须保存每名单位HP/MP、冷却、速度、合法行动、目标、阵型及预告，先执行指令顺序再算有效治疗与溢出；明确起始装备、实际已学技能、资源和可用替补。战后休整仅在副本明定节点生效，不能在每场前默认满资源。升级与进化也不能被用作免费治疗。

本次不调整药价或参与金币，因为尚未测得真实净消耗。治疗容量、敌方单次伤害和期望掉落分别已具备可复算输入，但三者尚未构成完整可通关、可持续获利的证明。
