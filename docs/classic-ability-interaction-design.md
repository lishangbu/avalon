# 破格与复制的效果边界

本页规定破格与复制的精确作用范围。最终槽位读取[72效果、450槽位完整表](creature-complete-ability-slots.csv)：巨钳幼虫家族B槽为破格，月光蛾家族B槽为复制。实际运行采用范围见[当前差异](design-implementation-gaps.md)。

接触效果的忽略与复制资格统一见[完整交互矩阵](complete-ability-interaction-matrix.csv)。新增硬爪、铁拳、铁刺均可复制且不被破格忽略，本页的16类忽略范围保持不变。

## 破格：本次直接攻击的防御特性忽略

普攻及技能直接攻击都适用，不额外收费，不改变伤害属性、攻击类别、目标数、原始威力及冷却。只在自己的本次攻击上下文内忽略[显式矩阵](complete-ability-interaction-matrix.csv)中的16类效果，不移除对手特性，也不影响队友后续攻击。

| 忽略组 | 特性 | 本次攻击的处理 |
| --- | --- | --- |
| 属性免疫或吸收 | 飘浮、引火、储水、蓄电、食草 | 正常进入属性与伤害计算，不免疫、不吸收、不产生该次吸收增益 |
| 直接减伤 | 坚岩、灵肤、明净、完好防护、多重鳞片 | 跳过对应乘数 |
| 克制修正 | 过滤 | 恢复正常被克制系数1.25，不能无视目标基础属性抵抗 |
| 保命 | 结实 | 不截断致死直接伤害 |
| 队友光环 | 友情防守 | 对这次攻击的各份额忽略光环，无论来源是目标本人还是队友 |
| 保护时减伤 | 守护 | 保护转移照常，代接伤害不再享受守护减免 |
| 防御强化 | 沉稳 | 通用防御仍有效，系数恢复0.70而非0.65 |
| 自动雷击代接 | 引雷 | 本次攻击不选择引雷转移，不消耗其本轮次数 |

手动掩护、战士援护与合法目标规则照常；手动代接后按实际承伤者检查矩阵。因此破格不能保证打到原目标，破阵仍具有独立用途：破阵额外付费跳过保护转移，破格不跳过手动保护。

**保留的内容：**护盾、魔力护盾、技能减伤、场景减伤、已生效的接力保护、基础防御、属性克制及抵抗、状态和关卡标记。此前特性产生的既存状态也不被倒扣：威吓的物攻下降、食草或引火的已获得增益、蜕壳的能力修正、加速层数照常影响其之后的合法行为。

反震、水脉回流、雷能充蓄、蜕壳属于实际损血后的反应，本方案不忽略。破格打穿直接减伤后仍可能受到反震，也可能帮助对手充能或触发半血变化。自然回复、再生力和治疗类特性不属于本次攻击的忽略范围。

群攻逐实际承伤者应用同一矩阵，不用“忽略全场特性”的开关影响并发状态。捕捉、持续伤害、反射及剧情事件不获得破格；不会因此提高捕捉率、取消封印球档位或关闭野生幻兽能力。

## 复制：每次入场取得一个临时效果

开场或合法换入时，在当时存活、在场的敌方幻兽或普通幻兽中等概率选择一个可复制目标，取得其当前效果；不复制人物职业被动、首领独有机制、关卡光环，也不从替补读取特性。目标按个体计权，相同效果出现两只就有两个候选，不先按效果去重。

当前[完整矩阵](complete-ability-interaction-matrix.csv)中70类可复制，复制自身与化学变化气体不可复制。原生效果为复制的个体即使当前已取得其他效果，也不成为另一复制者的目标，避免嵌套引用。没有合格目标时，本次入场保持复制但无附加效果，不在之后每回合重新尝试；再次真实换入才重新选择，须支付正常换宠行动成本。

复制结果在服务端本次入场事件中抽取并保存。重连、查看面板和重试请求均返回同一结果；不能靠刷新重抽。结果在离场或死亡时解除，复活按战斗既定入场事件重新判定；不改A/B/H槽、物种、技能池或已学技能。

复制不继承对方的能力值、层数、充能、已用次数、冷却和击倒账本，也不把技能一起学会。月光蛾复制技术高手可强化通用普攻，复制引火但没有火攻击时只能获得免火价值；不为了让每次结果都强而额外送技能。复制破格可在自己的攻击中使用其规则。

## 入场、离场与次数

同批入场先登记全部个体并确定气体来源；被抑制时不发动其他入场效果或抽选复制。无抑制时先应用原生非复制入场效果，再以当时合法敌方集合确定全部复制结果；随后按稳定战斗位置顺序执行复制所得的入场效果及反应，最后确定首轮动作顺序。复制威吓会正常施加一次威吓并可触发不服输或好胜，但不会引发第二轮复制。后来出现的新特性不能追溯改写已经抽定的结果。完整事件顺序和16项验收场景见[入场和换宠契约](ability-entry-exit-contract.md)。

复制期间使用取得的一个效果，原复制特性不并行再次触发；对外仍标明是临时效果。主动换下时先按当前效果结算再生力、自然回复或接力守护，再清除临时效果。死亡退出不触发这些主动离场奖励。

次数限制属于“个体＋效果＋战局”或“个体＋效果＋回合”，不能因复制结束重置。比如复制雷能充蓄已兑现两次，再次复制回来仍无本场免费次数；接力守护已用后同场不能再送一层；反震同回合换回不刷新次数。蜕壳已触发事实保留，同场重新复制该效果恢复其已触发的能力修正，但不再次净化或叠乘。没有该临时效果时不继续享受其能力修正。

充能、加速层数、引火等本就应离场清除的状态照常清除；击倒身份账本与已用次数按原效果保留。已经赠给队友的接力保护及施加给敌人的威吓依原生命周期继续存在，不因来源恢复复制而撤销。

## 信息与野生幻兽公平

日志只报告实际发生的行为，例如“月光蛾复制了储水”，不显示对方原生A/B/H槽或“隐藏特性”标签。可观察的特性行为本就会提供推断线索；准确槽位仍在捕获后揭示。普通野生幻兽不得在选招时读取未公开的槽位，免疫观察规则继续适用。

野生幻兽同样拥有真实生成的破格或复制。被捕获时保存原生槽位，不把临时复制结果作为永久特性；下一场重新执行原生复制。没有适合复制的目标是正常结果，不给野生幻兽补一个默认防御特性。

## 验收


组合验收仍须覆盖：破格打吸收、破格打手动保护与引雷、忽略外部友情防守、保留已发放接力保护、反震反杀、复制威吓触发反击、复制再生力离场、复制次数不重置、捕获保留原槽、复制结果重连一致。矩阵完整不等于运行战斗已验证，也不证明两种新槽位与原隐藏槽强度平衡。
