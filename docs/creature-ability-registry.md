# 特性效果与槽位清单

[20种效果表](creature-ability-rules.csv)统一记录特性触发时点、条件、操作与数值；[450项槽位表](creature-ability-slots.csv)覆盖150种形态的A／B／H。这里整理已设计效果，没有为每个物种新增专属特性，也没有增加第四槽位。

每个个体生成时按45%／45%／10%选择一个槽位，只应用该槽的一个特性。A与B允许同名，仍是两个生成槽位；不能因为同名而把45%误算成两个独立增益。捕获后揭示个体槽位，进化保留A／B／H身份并读取目标形态同槽效果。


## 结算边界

- 活力、明净在每段受击前检查是否满血；不能把第一段的满血状态沿用至整场。坚岩只减物理，灵肤只减法术，守护只减实际代接部分。
- 沉稳把普通防御倍率0.70替换为0.65，不叠乘两次。轻盈在速度结算时生效，不使普通技能越过高优先级技能。
- 聚炎、水性、顺风、猛火、雷怒、乘风、夜袭和追猎只增强相应直接攻击；持续伤害、治疗、固定机制伤害不自动继承倍率。需要减速的效果检查已生效状态，不追溯使用同次攻击新施加的减速。
- 滋养、回春增强直接治疗；药品、持续恢复、复活与护盾不受影响。节制每次合法直接治疗减费1，最低1，不按治疗目标数重复减费。
- 蓄势、凝神须实际执行通用防御后才能记录一次机会；下一次实际行动若类型符合则增强，否则消耗机会。连续防御仅重新记录，不叠层；眩晕导致未行动、无效请求不消耗。换入替补、倒下与战斗结束清除。

同一个体普通和隐藏特性不叠加。回春低血时比滋养多增治疗、其他时候无增幅；守护代接时受益，自己普通受击没有坚岩的效果。隐藏保持场景价值，不因生成率10%而统一提高七维或伤害。

## 对当前捕获核算的修正

自疗模型已改为逐个A／B／H槽位读取，不再只用“无加成／回春”两个简化版本。滋养的1.05治疗、回春的1.15、节制的7魔力微疗及轻盈速度均按适用槽位处理；其他只影响伤害的效果，在无人继续造成伤害的条件模型中不触发。

14个初始有微疗的物种共1296项条件期望记录；最长期望仍为约4.17球，但这不代表所有槽位行为相同。初始满魔、持续投球、玩家不倒下仍是模型假设，不能作为完整双怪生存验证。

下一步完整回合模型须读同一效果表和槽位表，并为各触发点提供真实执行语义；仅存在CSV字段不代表程序已经实现全部特性。尤其野生幻兽默认不主动通用防御，蓄势／凝神未触发可以是正确结果，不能为了让普通槽有收益额外插入免费防御。
