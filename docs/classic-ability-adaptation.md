# 经典特性的机制适配

首批16项的[家族分配与精确交互](classic-ability-integration.md)已单独展开；最终数据统一读取[当前72效果、450槽位选表](current-creature-design.md)。运行采用范围见[当前进度与交付边界](implementation-progress.md)，设计表不代表全部开放或完成平衡验证。

目标是让阿瓦隆具有入场压制、属性免疫、吸收、换宠续航、技能重构及特性对抗等丰富玩法。当前32种候选不是数量上限，也不是宝可梦特性的完整复刻。本表先审查40个代表条目，后续继续按机制补全；“经典”没有固定官方名单，不能把此表称为原作全部特性。

原作列仅概括机制识别点，不作为特定世代的精确规则。阿瓦隆列全部是本项目的设计候选，数值用于后续比较，不表示已被原32种规则、450个槽位或运行配置采用。继承槽位与45%／45%／10%生成概率不因扩展效果而改变。

## 可优先细化的16项

这些机制不要求先建立天气、携带道具或完整能力等级体系，但仍需入场事件、免疫阶段等实际支持。“可优先细化”不等于现有执行器开关一开就能使用。

| 原作特性 | 原作机制识别点 | 阿瓦隆候选效果 | 必须验证的取舍 |
| --- | --- | --- | --- |
| 威吓 | 入场降低对手攻击 | 入场使敌方在场单位物攻×0.90，持续至目标离场；同名不叠加 | 再次入场可对新目标生效，但不能反复叠成零攻击；副本作用范围单独定义 |
| 飘浮 | 地面属性免疫 | 免疫地属性直接攻击及该命中附带状态 | 不等于免疫所有地面场景伤害；首领应有其他合法攻击选择 |
| 引火 | 火属性吸收并强化火招式 | 火系直接攻击不造成伤害；触发后自己的火系直接伤害×1.20，离场清除，不叠层 | 强于单纯火伤加成的场景必须有非火敌人和技能选择制衡 |
| 储水 | 水属性吸收回血 | 水系直接攻击伤害及其附带状态无效，每次合法命中恢复最大生命的1/4，向下取整 | 满血不获额外资源；不能默认允许友方攻击制造免费恢复 |
| 蓄电 | 电属性吸收回血 | 与储水同结构，对应雷属性 | 与现有“受雷伤后免费施法”方案冲突，需择一或更名 |
| 食草 | 草属性免疫并提升攻击 | 木系直接攻击无效；触发后物攻×1.15，离场清除，不叠层 | 不免疫名字带草木的所有技能，也不额外免疫无属性束缚 |
| 结实 | 满血承受致死攻击后存活 | 单份直接伤害命中前满血时，最多损失当前生命减1；可以在重新回满后再次触发 | 不是每场一次的普通护盾；持续伤害、反射和后续独立命中可击倒 |
| 再生力 | 退场回复生命 | 存活且主动换下时恢复最大生命的1/3，向下取整；正常换宠占行动 | 不设草率的一场一次限制；必须测算延长战斗反复恢复的药耗与拖延收益 |
| 自然回复 | 退场解除异常 | 主动换下后解除明确列入清除组的负面状态 | 减速可纳入；剧情诅咒、关卡标记和冷却不能笼统清除 |
| 技术高手 | 强化低威力招式 | 技能原始威力不高于60的直接攻击威力×1.30；通用普攻也适用 | 会增强零魔普攻和群攻，必须同时核查法宠补刀与群伤效率 |
| 适应力 | 增强属性一致加成 | 本系系数由1.20替换为1.35，不与旧1.20再次相乘 | 不影响无属性普攻、治疗、固定伤害 |
| 有色眼镜 | 改善抵抗目标伤害 | 原本0.75的抵抗系数改为1.00，不解除属性免疫 | 泛用输出与专门配招之间的收益比较 |
| 过滤 | 减轻克制伤害 | 原本1.25的被克制系数改为1.10 | 保留克制关系，不直接改成无弱点 |
| 多重鳞片 | 满血减伤 | 命中前满血时直接伤害×0.50，每份单独检查 | 与现有活力满血×0.90重叠，不能随意分给相同预算物种后视作等价槽位 |
| 友情防守 | 减少队友承伤 | 自己在场且存活时，所属人物与另一出战宠的直接承伤×0.90；不保护自己，同名取最高 | 与援护、引雷区别明确：不转移伤害；不能跨玩家无限叠加 |
| 分析 | 后手攻击收益 | 实际行动时目标本轮已经完成一次有效行动，则本次直接伤害×1.15 | 无效指令、失去行动、刚换入不能视作已行动；逐目标判定 |

这些机制的原作概览参考[特性索引](https://pokemondb.net/ability)。免疫及吸收细节另外核对[飘浮](https://pokemondb.net/ability/levitate)、[引火](https://pokemondb.net/ability/flash-fire)、[储水](https://pokemondb.net/ability/water-absorb)；满血存活与换下恢复分别核对[结实](https://pokemondb.net/ability/sturdy)、[再生力](https://pokemondb.net/ability/regenerator)。上表比例和持续规则以阿瓦隆列为本项目提案，不宣称等于原作数值。

## 需先补齐动作、状态或特性操作的14项

战中与攻击机制分别见[战中成长](classic-growth-ability-design.md)、[特性对抗](classic-ability-interaction-design.md)、[接触](contact-ability-design.md)、[多段](multihit-ability-design.md)、[中毒](poison-ability-design.md)及[强行](sheer-force-design.md)。这些专项维护规则，数据只采用当前完整选表。

| 特性 | 核心方向 | 阿瓦隆需要先完成的条件 |
| --- | --- | --- |
| 强行 | 放弃附带效果提高伤害 | 给技能标明可移除的附带效果，决定是否替换目前仅对减速加40威力、减2耗魔的自定义方案 |
| 硬爪 | 接触攻击强化 | 增加显式接触标记，不能按物理／法术分类猜测 |
| 铁拳 | 拳类攻击强化 | 技能标签及足够的拳类学习池，不能只有特性没有可学招式 |
| 铁刺 | 接触反伤 | 明确接触事件与固定反伤路径；不把目前反震的所有物理受击触发当作相同机制 |
| 连续攻击 | 多段攻击强化 | 多段次数、每段命中、保命、护盾、附带效果及攻击者中途死亡规则 |
| 毅力 | 异常状态转进攻收益 | 明确异常清单与异常自身代价，避免只有免费加成 |
| 毒疗 | 中毒转恢复 | 完整中毒结算及免疫／净化关系；不能将现有减速冒充中毒 |
| 同步 | 异常反馈 | 可反馈异常白名单、免疫检查和禁止递归传播 |
| 自信过度 | 击倒后提升攻击 | 击杀归属、持续时间与叠层上限；禁止借召唤物刷无界增益 |
| 好胜 | 能力被降后反击成长 | 区分敌方降能力、自己技能代价及场地效果，统一能力修正顺序 |
| 不服输 | 能力被降后的物理反击 | 与好胜共享触发模型，避免每个效果单独写不同触发定义 |
| 加速 | 回合结束提高速度 | 上限与离场恢复规则、下一回合排序及反复拖延的收益 |
| 破格 | 忽略特定防御特性 | 逐效果列可忽略清单，只对本次技能有效；不能等同于目前绕过保护转移的破阵 |
| 复制 | 入场复制对手特性 | 原槽不变、临时效果引用、不可复制清单及离场还原；不能复制复合特性产生无限层 |

分类参考[特性索引](https://pokemondb.net/ability)；附带效果与特性忽略需分别依据[强行规则](https://pokemondb.net/ability/sheer-force)、[破格规则](https://pokemondb.net/ability/mold-breaker)进一步逐项适配。这里不把原作完整能力等级、命中率或接触体系默认为阿瓦隆已有功能。

## 需环境或全场机制配套的10项

环境机制见[晴雨天气](weather-ability-design.md)、[沙暴与雪天](sand-snow-weather-design.md)、[场地](terrain-ability-design.md)及[气体抑制](ability-suppression-design.md)。当前完整候选为72效果；环境状态统一执行与全队平衡仍需对应验证。

| 特性 | 阿瓦隆适配方向 | 依赖 |
| --- | --- | --- |
| 日照 | 入场设置晴天 | 天气持续时间、覆盖顺序、火水影响 |
| 降雨 | 入场设置雨天 | 同上，禁止天气发动无限递归 |
| 扬沙 | 入场设置沙暴 | 逐回合伤害、豁免与全队负面影响 |
| 降雪 | 入场设置雪天 | 阿瓦隆无冰属性，必须设计独立有意义的雪天，不能照搬冰系增益 |
| 悠游自如 | 雨天速度收益 | 天气及下一轮排序 |
| 叶绿素 | 晴天速度收益 | 同上，与火系输出形成不同队伍路线 |
| 拨雪 | 雪天速度收益 | 先证明雪天体系值得加入 |
| 电气制造 | 入场设置雷电场地 | 场地与天气是否并存、作用对象与覆盖规则 |
| 青草制造 | 入场设置生机场地 | 恢复归属、在场／离地资格与多场地互斥 |
| 化学变化气体 | 在场压制其他特性 | 暂停而非删除；离场恢复、免疫消失及多压制源结算 |

环境与全场特性分类参考[特性索引](https://pokemondb.net/ability)；当前设计包含晴雨、沙雪、场地及气体抑制，具体投放读取完整选表，不表示全图与首领已完成联合验证。

## 与现有32种候选的关系

[中毒构筑方案](poison-ability-design.md)规定毅力、毒疗、同步的异常清单、施加来源及净化规则；运行中毒机制见`PoisonPolicy`。[强行方案](sheer-force-design.md)登记23项技能策略，只移除逆风减速或毒液中毒并增伤；自定义舍控强攻保持独立身份。

不能把40个条目直接加到32上宣称拥有72种特性：其中存在替代、重叠和同名不同机制。

| 现有方案 | 对照问题 | 整理方式 |
| --- | --- | --- |
| 蓄电：承伤后免费施法 | 原作蓄电属于属性吸收回复 | 经典吸收方案与现有充能方案分别保留提案身份；若同时采用，旧机制改名为雷能充蓄等清晰名称 |
| 蓄水：承伤补魔 | 与原作储水的免伤回血不同 | 建议自定义效果改名为水脉回流；不能只差一个近义字让玩家猜含义 |
| 共生：治疗队友后恢复自己 | 原作共生围绕携带道具传递 | 自定义治疗机制建议更名为生命共鸣；道具传递另等携带道具系统 |
| 蜕壳：半血提速降防并净化 | 不等于原作蜕皮的状态恢复机制 | 维持清楚的半血触发说明；若引入蜕皮，必须作为另一种独立效果 |
| 强行：减速技能威力＋40、耗魔−2 | 与原作按合格附带效果提升伤害不同 | 优先讨论统一采用按比例增伤，或给旧特性更名；两种算法不共用同一效果ID |
| 活力：满血减伤 | 与原作活力的进攻／命中取舍不同 | 若采用原作活力，现有满血保护另行更名，不修改旧存档槽位身份 |
| 守护与友情防守 | 一个仅代接时生效，一个给队友提供减伤 | 保留为不同构筑，不把友情防守写成守护的隐藏升级 |
| 破阵与破格 | 一个绕过保护转移，一个忽略指定防御特性 | 名称、技能说明与结算入口必须区分 |

共生与蜕皮的差异分别核对[Symbiosis](https://pokemondb.net/ability/symbiosis)、[Shed Skin](https://pokemondb.net/ability/shed-skin)。本次只记录建议名称，不批量修改旧候选及既有测试，避免尚未完成机制选择便造成同一名称对应两种规则。

## 引入顺序与验收

首先完成16项直接候选的交互和物种适配，重点是免疫／吸收、结实、再生力和入场效果；其次补足与已存在技能真正相关的接触、多段、异常和特性对抗；环境组按地图与副本玩法需要推进。每个家族仍可共享效果，普通A、B允许相同，隐藏槽不垄断强机制。

免疫是真正免疫，不为了保持每个旧首领都能造成伤害而统一降格为减伤。正确的内容处理是检查敌人的合法攻击集合、配套伙伴、阶段目标和玩家代价；必要时调整首领技能组合并保留清楚预告。不可让所有首领暗中无视免疫，也不能给所有免疫特性统一添加每场一次限制来回避设计。

野生幻兽与捕获后的同种个体共用效果。结实导致目标剩1生命属于特性本身，不是捕捉系统替玩家保命；没有结实的目标仍可被误杀，不追加捕捉风险提示。再生力只能通过真实战斗内主动换宠触发，不能在村庄反复切换编队回血。

首批16项已形成家族投放与交互提案。尚缺：机制数值验证、普通／隐藏槽实战比较、免疫和再生力经济核算、整合方案正式定稿、经典清单进一步补全。本文不是“全部原作特性已复刻”的验收证明。
