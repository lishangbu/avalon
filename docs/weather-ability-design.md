# 晴雨天气与队伍构筑

首批天气采用晴天、雨天两种，晴雨不造成额外回合末伤害，也不新增属性。适用于普通战斗及多人副本的同一场战斗；地图美术上的晴雨不自动等于有数值效果的战斗天气。

## 四项特性

| 特性 | 普通槽投放 | 效果 |
| --- | --- | --- |
| 日照 | 紫炎兔家族A，替换聚炎 | 合法入场时设置晴天 |
| 降雨 | 清泉灵家族B，替换滋养 | 合法入场时设置雨天 |
| 悠游自如 | 蓝鳍鱼家族A，替换轻盈 | 雨天中速度×1.30 |
| 叶绿素 | 芽灵家族B，替换滋养 | 晴天中速度×1.30 |

一个个体仍只有一个生效特性，蓝鳍鱼不能同时拥有悠游自如和适应力。晴天会提高敌方火系伤害，雨天会提高敌方水系伤害，天气发动者必须承担共享环境的风险。速度收益不增加行动次数或缩短冷却。

天气效果与槽位统一采用[当前72效果完整表](current-creature-design.md)。四项均可复制，破格不忽略；天气是全场状态，不能因一次破格攻击给攻击者局部改成另一种天气。

## 天气数值

| 天气 | 火系直接伤害 | 水系直接伤害 | 其他直接伤害 | 对应速度特性 |
| --- | ---: | ---: | ---: | ---: |
| 无 | 1.00 | 1.00 | 1.00 | 不加成 |
| 晴天 | 1.20 | 0.80 | 1.00 | 叶绿素1.30 |
| 雨天 | 0.80 | 1.20 | 1.00 | 悠游自如1.30 |

天气乘数进入直接伤害完整乘法链，最终一次取整。适用于物理、法术、单体、群体和多段中的对应元素，不影响治疗、反射、中毒、吸收回复、技能费用或捕获率。属性免疫仍为0，不因晴天把引火免疫改为减伤。

天气不提高中毒威力，不增强毒疗，不让微疗在雨天额外回复。以火系本系克制攻击为例，晴天的三项系数为1.20×1.25×1.20＝1.80；这不是最终伤害上限，其他合法条件仍按各自规则计算，需继续检查首领爆发与药耗。

## 设置、覆盖和持续时间

每场战斗只有一个天气槽，保存类型、来源个体、设置事件及到期回合；多人副本所有队伍与敌人共用。不同天气直接覆盖，相同天气重设到期时间，不叠加强度、不延长为十回合。来源换下或死亡不提前结束天气，天气不会追随来源转移到另一场战斗。

第R轮设置，持续至R+4轮结束，共含当前轮五个回合末；开场入场按R=1处理。新天气即刻影响其后实际执行的攻击，本轮已经排好的行动顺序不重排。持续时间按战斗回合推进，不按现实秒数；断线不暂停，也不重新给五轮。整场结束清除，不在两场副本战斗之间继承。

同批初始入场先按不含新天气增益的有效速度从高到低排列，速度相同按稳定战斗位置；依次执行天气入场事件，最后一次成功设置生效。这里使用一次固定顺序，不因中途下雨使悠游自如加速就重新排列剩余事件。后续同轮换宠按已锁定换宠行动顺序处理，后执行者覆盖先执行者。

天气不因“自己刚覆盖别人的天气”触发对方重新入场，没有自动天气争夺循环。真实再次换入可重新设置，但仍占换宠行动，接替者本轮不能再攻击。不额外设置每场一次次数，也不免除换宠风险。

天气到期后恢复无天气，当前不配置会自动恢复的地区永久天气。今后某首领需锁定环境，必须在预告和战斗规则中公开声明可覆盖与否；本方案不给所有首领默认免疫玩家天气。

## 顺序与临时复制

初始原生天气先按入场顺序设置，再处理复制抽选及取得的入场效果；复制日照或降雨可覆盖前面的天气。完成全部入场效果后，用最终天气计算首轮正式动作顺序。复制所得天气到期规则与原生完全相同，不因临时特性恢复为复制而立即撤销。

一次攻击开始时锁定当前天气供本次全部目标和段数使用。受击引发的新效果不能回溯改变已锁定攻击。下一次独立攻击重新读取天气。回合末持续伤害及恢复先结算，再处理加速等回合末状态，最后使到期天气失效，再按剩余状态计算下一轮排序。

速度统一从未受临时效果影响的基础速度派生：先处理需独立取整的既定轻盈，再乘天气速度、临时能力层数和减速系数；同一特性不能重复参与两次。仅有悠游自如且基础速度120时，雨天156；同时减速20%时排序值124.8，不为排序额外向下取整。当前一个体不能原生同时拥有加速与悠游自如，公式兼容不代表已存在该组合。

## 野生幻兽与UI

野生幻兽按真实生成槽位发动同样天气，不额外降低效果。晴雨设置为公开战斗事件，只说明来源与天气，不显示A/B/H身份。复制、捕获和脱战仍保存原生槽位，不把天气写入捕获个体成长。

战斗页在公共状态区显示“晴天／雨天、剩余回合及火水效果”，各单位面板显示派生速度，战报记录设置、覆盖和结束。显示倒计时必须与实际到期回合一致，不按动画播放时间减少。玩家提交指令时可见当前天气，但后续合法换入仍可能改变环境，不提供未来结果保证。
