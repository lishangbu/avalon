# 物法行动收益与补给效率

采用[当前威力与耗魔](skill-mana-candidates.csv)：基础物理80／6，基础法术100／12。纯法术主职的基础形态魔力基础值提高到160，终阶按地区170～210；防止基础法术费用提高后，仅把满级法宠的上限补足，却让未进化法宠明显缺魔。

满魔储备所支持的总输出接近，但法术集中在更少行动内完成，物理消耗更省。这是同攻防实验的结果，不代表所有真实物种对位都接近；真实法攻、物攻、防御、特性、速度和技能池仍决定胜负。

## 药品保持固定回复的理由与代价

固定回复药确实偏向物理持续攻击效率。同攻防条件下，每一点魔力的法术伤害为物理的62.5%，即法术用双倍资源换25%单次增伤。V药回复88，每次补给的持续输出预算物理7744、法术4840；这包含剩余魔力的连续价值，不表示一瓶能立即独立打出小数次攻击。

该差异暂作为玩法取舍保留：物理适合长时间省药，法术在行动窗口和多目标机会中更有价值。不能为了使每瓶药完全等价就给法宠自动多回复，也不调整既定药品价格来掩盖职业差异。若实际连续任务导致法宠经济不可维持，再同时校准敌方生命、自然掉药、职业恢复和药品；当前不宣称经济问题已经解决。

## 高费法术的收益边界

- 疾风刃威力120、18魔力，比风刃单次高20%、费用高50%，冷却1，定位为额外爆发选择，不是无脑替换基础技能。
- 烈焰冲击威力100或150、18魔力、冷却2；未触发时比基础火球更耗魔而不更强，目标半血以下获得50%单次提升，仍需正确选择时机。
- 烈焰风暴每目标60、24魔力、最多3目标，单目标弱于火球；三个目标总威力180，花两次火球的魔力在一次行动内提供群体压力，总威力略低于两次火球200。不能把同时打到三个目标当作每场必然成立。

没有新增法术专属暴击、必中或隐藏减伤穿透，也不改物理技能的元素克制待遇。跨系学习同样按所学技能付费，纯物理宠学习水弹需12魔力，无法享受6魔力物理费用。
