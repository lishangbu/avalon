现有主线资料由设施与NPC直接展示，不再要求逐条点击观察。选择、摆放价签、战斗、领取、交接及照护仍为真实操作；航行阶段的必经地点由移动记录，旧存档回执和奖励不重发。

BQ067～074港湾团聚已接入正式任务与阶段对白，莎琳引介佩罗，照护站与浅滩双向步行可达。完成清网、正式战斗、引导与交接后，开放16～17级浅滩野战；15级可进入，战败与撤退回免费恢复的照护站。团聚不消费或赠送玩家幻兽资产。

日常运行`scripts/simulate-natural.sh`，在隔离服务中从新号完成74步骤并自然达到16级；每回合、经验、课程、捕捉及交易均走正式HTTP。默认完整路线13.588秒，可选30步至15级119.673秒；两条路线均通过，0次浏览器操作。后者对比上一批页面与HTTP混合流程约快3.74倍，双路线命令含编译与启动约2分35秒。页面和后端自然成长入口独立保留。执行方法及逐场证据见[任务系统验收](quest-system-validation.md)。
