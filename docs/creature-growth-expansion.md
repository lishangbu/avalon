# 野外物种进化与共享特性

## 覆盖与数量

基础版所有可捕捉的野外基础物种都提供至少一条能在50级内达成的进化路线。终阶暂只通过进化获得，不进入野外捕捉池；不可捕捉的剧情敌人、首领不套用这个要求。这是有限的成长链，不要求终阶继续无限进化。进化可延后，不强制替换玩家幻兽。

120种图鉴预算调整为60个野外基础种＋60个进化形态。隐藏槽位、闪光、精英与跨区重复投放不增加物种数量。五档投放数量以[50级物种范围](creature-level-50-scope.md)为准。每个基础种先保证一条完整路线，再考虑额外分支或三阶段，不从未分配的名额中无限加种。

[进化方向表](evolution-roster.csv)覆盖全部60个野外基础种；[配方](evolution-recipes.csv)与各物种CSV同步记录进化门槛。任务教学仍为人物11级，青岚雀与紫炎兔仍为幻兽20级进化，其余路线22～50级分布。原始文件按主题分组，不按文件名推断当前等级。缺失图片、培养成本及战斗平衡仍待完成。

## 成长与继承

新增方向采用以下初始测试倍率，字段顺序为生命／魔力／物攻／法攻／物防／法防／速度。倍率作用于原物种成长得到的对应属性，沿现行进化计算与取整，不再额外乘第二份物种系数。

| 模板 | 倍率 |
| --- | --- |
| PHYSICAL | 1.10／1.00／1.15／1.00／1.05／1.05／1.00 |
| MAGIC | 1.10／1.00／1.00／1.15／1.05／1.05／1.00 |
| GUARD | 1.10／1.00／1.05／1.00／1.10／1.10／1.00 |
| SUPPORT | 1.10／1.00／1.00／1.05／1.05／1.10／1.05 |
| SWIFT_MAGIC | 1.10／1.00／1.00／1.10／1.05／1.05／1.05 |
| EXISTING_FIRE、EXISTING_WIND | 沿既定紫焰灵兔、青岚隼倍率 |

倍率总增量相近只用于约束候选幅度，不证明实际价值相等。需要结合原种属性、技能池、先手阈值和续航验证，不按相同总和宣称平衡。

所有路线保持A→A、B→B、H→H；不是同时继承三个特性。进化继承已学技能，新增学习资格仍消耗技能书且遵守遗忘规则，不因进化自动塞技能。当前生命、魔力依既定资源规则处理，不通过进化自动复活或反复补满。新终阶的属性与种族默认继承基础种，不凭名字偷偷增加双属性。

## 特性扩充

旧候选30行仅有4种普通特性，且全部A/B相同。新设计保留既有11种效果，增加9种共享普通特性，形成20种可复用效果；不为每只幻兽强行创作三种独占特性。A/B仍允许相同，此批为比较构筑先安排不同的B槽，后续验证可以保留确有必要的重复。

生成权重仍为45%／45%／10%，槽位在野生幻兽生成时确定，捕捉后揭示。已有八种基础物种的A与H不变，B候选见物种表。运行配置和存档没有随设计表自动改动。

| 新特性 | 初始测试规则 |
| --- | --- |
| 水性 | 自身水属性直接伤害乘1.05；不影响治疗、持续伤害或固定机制伤害。 |
| 滋养 | 自身施放的直接治疗量乘1.05；不增加药品、持续恢复、护盾或复活效果。 |
| 灵肤 | 自身承受的法术直接伤害乘0.90，含实际代接部分；不减持续或场地伤害。 |
| 沉稳 | 使用通用防御指令时，直接伤害的防御倍率从0.70改为0.65；是替换，不再额外乘一次0.70。 |
| 蓄势 | 实际执行通用防御后，紧接着的下一次实际行动若为物理直接攻击，该行动伤害乘1.10；其他行动消耗机会但不受益。 |
| 凝神 | 与蓄势相同，但只增强法术直接攻击。 |
| 顺风 | 本次攻击开始时自身没有有效减速，风属性直接伤害乘1.05；不产生加速或额外行动。 |
| 节制 | 实际施放直接治疗技能时，魔力费用减少1，最低仍为1；不影响药品、人物技能或其他辅助指令。 |
| 追猎 | 攻击开始时目标生命不高于上限一半，物理直接伤害乘1.10；按目标检查，多段沿用该行动开始时判定。 |

蓄势和凝神最多记录一次机会，连续防御只重新记录，不能叠层；进入替补、倒下或战斗结束清除，不能从上一场预存。未能行动的眩晕不等于实际行动，不消耗机会；无效请求也不改变状态。防御再攻击占用两次行动，不能把增益理解为额外免费输出。

同一个体只有当前槽位的一个特性，普通与隐藏不叠加。每个特性的倍率在对应结算点乘一次，最终取整沿现有公式。群攻逐目标检查条件，不让一个目标触发后增强所有目标；同次攻击新增的减速不追溯触发。节制按一次技能施放扣一次费用，不能按治疗目标数重复减费。

隐藏仍强调场景价值：例如回春在低血救援时比滋养强，其他时候无加成；守护只在实际代接时有收益，不取代坚岩或灵肤的日常承伤。10%生成率不作为普遍强化隐藏特性的理由。后续分配须检查个体能否通过自己的技能池或队友配合触发，避免无效隐藏。

## 实施边界

当前已形成覆盖规则、初期路线方向、共享特性规则及26种新增终阶规格，不是全部进化已经上线。26个新增终阶已有[材料配方与研究兑换来源](evolution-material-design.md)，仍需可选精英来源、图鉴奖励预算与缺失素材；后段野外基础种及其进化继续逐只设计，最新数量见[设计交付清单](design-implementation-gaps.md)。基础种与终阶图片必须能够辨识变化，不仅放大同一张图就算完成。
