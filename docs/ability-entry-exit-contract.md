# 入场、换宠与特性生命周期契约

适用[当前72效果选表](current-creature-design.md)。本文确定执行顺序与验收预期，不引入额外出战位、免费换宠、复活技能或副本编队修改。玩家主动换宠仍消耗既定行动，新上场伙伴本轮不能追加行动；死亡补位与复活是否允许，先由对应战斗或技能规则决定。

## 同一战场的身份与事件

战斗固定位置由服务端建立，包含阵营、玩家小队与槽位；个体身份不随换位、复活、复制或重连改变。特性次数与击倒账本按个体保存，不能放在位置上供下一只继承，也不能换位置后清零。出战之外的随身幻兽与仓库幻兽不参与来源集合。

每次位置变更有唯一事件身份，记录原因、原个体、新个体、战斗回合、动作顺序及复制结果。相同事件重试返回原结果，不再治疗、净化、抽选或设置天气。相同事件身份携带不同命令参数拒绝；断线恢复读取已提交状态，不构造新的入场事件。

涉及多人时锁定的是同一场战斗的事件顺序，不允许各小队独立提交相互矛盾的气体、天气或场地。计算期间使用工作状态，所有位置、生命、异常、环境、账本与事件回执一起提交；中途失败不留下半次换宠。这里规定所需原子性，不指定额外分布式系统或热更新版本。

## 初始出战与同批增援

1. 先确认整批合法参战个体、原生特性与固定位置，登记整批在场状态。原生气体的有效性只依存活、在场与原生效果，不依发动速度。
2. 从全战场生成气体来源集合。若非空，本批其他特性均不发动入场效果；也不抽选复制目标。不生成待气体解除后补发的事件。
3. 无气体时，锁定本批原生非复制入场效果顺序：按本批处理前的有效速度从高到低，同速按固定位置。开战时无既存天气；后续增援可计入批次开始时的既存天气。过程中产生的新天气、威吓或反应不重排此批顺序。
4. 逐一执行原生入场效果及其即时反应。威吓只作用于当时存活在场敌人；只有实际新增下降才触发不服输或好胜。同名威吓已有一层时不重复触发反击。
5. 原生阶段结束后，为本批可发动的复制者锁定合法敌方候选集合。排除原生复制者、气体、人物职业被动与首领独有机制；按个体等概率，不按效果去重。全部抽选结果先记录，再按复制者固定位置执行所得入场效果，不递归复制。
6. 最后形成行动所用状态。开战及主动换宠阶段结束后，按最终有效速度形成普通行动队列；该队列锁定后不再因行动阶段的增援或状态变化重排。主动换入也不凭入场效果取得额外动作。两次排序的区别见[完整回合契约](battle-round-contract.md)。

气体不改变已经存在的天气或场地。来源死亡或退出后，原本被压制的入场特性不补发动；常驻乘数仅从下次读取时恢复。

## 主动换宠的原子顺序

1. 校验行动资格、同小队、原个体存活在场、新个体存活且为合法替补、两者不同。队伍锁定限制及眩晕等行动限制先按既定战斗规则检查，失败不触发离场效果。
2. 锁定变更前全场气体集合，以此判断换下者当前效果是否可触发。复制再生力或自然回复时使用已复制的效果，不先恢复原生复制。
3. 执行合法主动离场收益：再生力回复最大生命的三分之一并截断，自然回复清除减速、眩晕、中毒；接力守护沿自身次数及受益目标规则。气体抑制时上述收益不发生，之后不能补领。
4. 清除规定随离场失效的状态和临时复制效果，保留个体次数与击倒账本；一次性替换出战位置。原生特性槽不变，不消耗或重抽A/B/H。
5. 依据替换后全战场重算气体集合，再执行新个体的入场规则。旧气体是最后来源且换入天气宠时，新天气可以发动；旧再生力在无气体状态换下、随后气体宠换入时，已结算的回血不撤销。
6. 提交状态与事件回执，消耗正常换宠行动。新个体不继承该位置原个体尚未执行的攻击指令。

同一轮多名玩家主动换宠按阶段开始锁定的换宠队列逐次执行，每次都是完整位置变更；它们不是客户端自行合并的“同时换宠”。例如第一名先换入气体，会影响第二名随后换下再生力的恢复资格。换宠队列按此阶段开始速度、同速随机排定，不受客户端提交先后影响；全体换宠完成后再排普通技能行动。

## 非主动离场与复活

当前已配置的技能与药品没有战斗内复活入口。牧师恢复系的复活属于后续技能预留，不能把下面的兼容规则当成已经投放复活术。当前实际恢复途径是战斗外既定设施与休整；剧情训练的临时满状态在新战斗初始化前完成，不在战斗中反复发入场收益。

### 回合开始的手动补位

出战幻兽倒下后，本轮内不立即补位、不追加行动；下轮开始允许玩家免费选择自己的健康替补。它与主动换宠不同：免费补入者可以在本轮正常提交技能。人物倒下仍可指挥幻兽，额外携带位、新捕获幻兽及别人的替补不合格。

补位选择和该小队本轮指令一起提交，不新增第二个倒计时，不自动选宠。收齐提交或截止后，服务器先统一校验本轮所有合法补位，再将整批新个体登记在场，确定气体来源，处理原生与复制入场效果，最后按最终公开状态形成动作顺序。同批慢速气体也会压制快速天气，不能按玩家请求到达顺序决定先发动谁。已提交招式不因这一步变化而替玩家重新选招。

倒下个体不触发主动离场恢复和接力守护，新个体不继承旧位置的护盾、异常、充能、层数或个人限次。补入者使用自己的生命魔力与剩余状态，自己已有的本场限次账本保留。它虽能本轮攻击，但属于本轮刚入场，不获取加速的当轮末新层数。

敌方已经全灭时先按整个玩家方是否存在存活参战成员或合格替补判定结果，不为了补位发动天气再多跑一轮；双方都无可战斗成员时失败。敌方仍存活而玩家仅余替补时进入下一轮补位窗口。副本该轮截止仍无人补位，按既定失败收束；不让未选择的替补无限拖住战斗。

以下复活条目只定义未来接入边界；不会据此新增技能、收费或自动补位。

| 原因 | 主动离场收益 | 特性状态处理 | 后续入场 |
| --- | --- | --- | --- |
| 死亡 | 不触发再生力、自然回复、接力守护 | 清除死亡规定的层数、充能与复制结果；保留本场次数与击倒身份 | 仅合法补位或复活事件可触发 |
| 捕获成功 | 不触发 | 移除野生幻兽战斗身份，清理临时状态；保存原生槽与合法永久资料 | 新一场按保存的原生效果处理 |
| 逃跑或战斗结束 | 不触发 | 清除整场临时状态，不能结算一次额外离场回血 | 下一场是新的战斗 |
| 战斗外编队、存取仓库 | 不触发 | 不制造战斗内入场事件 | 开战时统一登记 |
| 同场重连 | 不触发 | 保留已提交状态与回执 | 不视为新入场 |

复活到替补位置不会提供气体、友情防守或发动天气；之后合法换入才入场。若既定技能明确复活并在场，则以真正恢复在场身份为一次入场，复制可重新抽选，气体重新成为来源。被压制则不发动其他入场效果。复活不重置本场限次账本，且不获得加速的当轮末新增层数资格。

## 与直接攻击的边界

一次群攻的全部伤害份额使用同一段开始的气体与友情防守资格，不能按目标遍历顺序变动。气体被第一份伤害击倒，不让后续同段目标恢复结实；友情防守来源被击倒，也不撤销本段已锁定的保护。

多段攻击每段开始重读防御侧来源资格，上一段完成伤害及反应后死亡的气体，不抑制下一段的防御特性。整次进攻派生、支付费用、随机波动、天气和场地快照仍按行动锁定，不中途重算强行或返还魔力。段间若攻击者或锁定承伤者死亡，按多段规则结束，不转打另一目标。

## 必须通过的组合验收

以下是明确预期，尚不是全部已执行测试。

| 场景 | 预期 |
| --- | --- |
| 开场最慢气体、最快日照、一个复制者 | 气体有效；无新晴天，不抽复制结果 |
| 无气体时快日照、慢降雨同时开场 | 最终雨天；按最终天气确定第一轮速度 |
| 原生日照与复制到降雨同批入场 | 原生阶段后复制阶段设置雨天；复制使用自己等级 |
| 两个威吓同批作用于不服输 | 一层威吓，只触发一次实际下降反击 |
| 无气体时再生力换下、气体换入 | 先合法回血，再暂停其他特性 |
| 敌方气体仍在，再生力换下 | 不回血，之后敌方气体死亡也不补回 |
| 最后一个气体换下、日照换入 | 新日照发动；没有重新触发其余留场幻兽 |
| 两个气体只换下一个、日照换入 | 仍被抑制，无新天气 |
| 复制再生力后主动换下 | 先按当前效果回血，再清除复制结果 |
| 气体存在时复制者换入，随后气体退出 | 不补抽；只有下次真实入场才重新判定 |
| 被压制的复制毒疗留场至气体解除 | 恢复同一毒疗，已过去的跳点不补偿 |
| 重放一条成功换宠请求 | 无第二次回血、天气刷新或复制抽选 |
| 复活气体到替补/在场 | 前者不提供来源，后者提供；次数不刷新 |
| 群攻先杀气体、后命中满血结实 | 同一段结实仍暂停，不因遍历顺序保命 |
| 单目标连环刺击倒气体目标，另有敌人存活 | 攻击停止，不跳打另一只；下一次合法攻击读取新来源集合 |
| 同轮第一小队换入气体，第二小队换下再生力 | 第二小队不回血；记录真实服务端执行顺序 |
