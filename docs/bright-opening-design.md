# 晨露村至诺姆：1～10级开篇任务包

## 设计状态与边界

依据[世界观](narrative-design.md)与[故事大纲](main-story-outline.md)，正式开篇包含30项连续任务。`BQ001`～`BQ030`为稳定编号，任务由唯一正式目录`content/quests.json`驱动。当前已实现范围和验证证据见[实现进度](implementation-progress.md)；真人时长尚未验证。

故事从庆典准备开始，玩家主动远行，在学院学习后完成独立调查并取得冒险资格。1～10级是成长投放区间，不要求在每项任务前达到一个指定等级；战斗推荐等级、经验与真实门槛须联合验证，不能把当前15级玩法直接压缩数值便宣称成立。

地点编号以 `opening.json` 为准。出生地使用 `VILLAGE_HOME`，诺姆城使用 `GNOME_CITY`；页面展示“晨露村家门”和“诺姆城”。移动经过相邻道路，不新增传送入口。

## 奖励与进度契约

任务表保留轻1、常2、重3作为工作量参考；逐项整数奖励以[开篇经济预算](bright-opening-economy.md)为准，不在运行时根据玩家缺多少经验临时补足。学院临时战斗不额外产出击杀经验、金币或掉落；课程的一次性任务经验计入同一预算。人物与合格幻兽的经验范围沿正式规则，不给借用个体结算正式经验。四职业连续服务流程已验证，真人节奏尚待试玩。

表中“基础奖励”是本任务一次性经验及金币；30项任务合计22680经验、520金币。教学物品为独立训练库存，课后销毁；真实赠品写入领取收据，不能每次对话重领。前置使用任务完成事实；表内要求的观察、操作与战斗使用服务端事件判据，点开页面不等于已完成动作。失败不抹掉已完成任务；重试不重复奖励。背包满按正式待领规则处理，奖励去向明确，关键任务物品使用任务物品通道。

前三项任务累计发放450经验；BQ004先发250经验，使人物达到3级，再生成3级利爪猫。赠宠初始累计经验700，不再重复领取加入前的任务经验。此后主线不要求稀有物种、隐藏特性或某种培养路线。

人物绑定沿[主要人物](bright-story-cast.md)：特林负责广场筹备与沿途信使联系；BQ017由克林接纳入学、费恩负责实践；米菈作为同期学员在课程前后交流自己的观察，不担任可控战斗同伴。BQ015的旅行商人是普通往来商人，BQ025只提供联系与介绍，不替代店主罗温；罗温的小店重开留给资格取得后的独立诺姆故事，开篇不提前宣布该店已经开张。BQ029由费恩授予冒险资格，BQ030米菈分享自己的测绘计划，避免所有熟人只围绕玩家转。

## 教学与防软锁约束

1. BQ018后课程可按玩家意愿进行，BQ024只汇合实际完成的五项课程；退出课程保留已完成课程，不保存半个战斗动作冒充过课。
2. 真实队伍始终人物加最多两只在场幻兽；参战名单最多四只，含两只替补。携带上限、额外携带者经验与现行规则一致。借用第五只用于说明差异，不能悄悄变成第五个参战单位。
3. 进入训练保存真实状态，临时生命、魔力、技能、装备、金币、库存、个体及捕获结果完全隔离。失败、退出、断线恢复和正常完成均不覆盖正式状态；永久课程技能与任务奖励只在一次性完成事务提交。
4. 学院课程绑定BQ018～BQ023，使用隔离教学单位和物品；人物职业不可更换，课程只授予本职业技能。四职业服务流程与页面操作分别验证。
5. 地图移动经过实际相邻出口。家乡持续开放，完成旅途照护和学院调查后仍可沿正常道路返村。
6. 世界服务实际存在才算可用，不能仅在对白说“去恢复”而没有端点。BQ007赠球耗尽、伙伴倒下、仓库满、人物金币为零须有使用正式低级服务重新取得可战与可捕资源的路线；未核实前标为发行阻断项，不用无限赠品隐藏问题。
7. BQ012与BQ027都是可以正常赢的战斗。叙事退场不代表战斗获胜后玩家必须放弃合法奖励；首领不可捕捉范围须事前按公开规则标记，不能临时剥夺正常可捕个体。

## 正式任务目录

正式任务目录只包含 BQ001～BQ030，所有新角色从 BQ001 开始。地图、场景动作、课程与战斗统一使用这些任务及其行动事实；任务奖励由统一执行器和回执结算。

## 需要验证的事项

- 30项任务前置无环且新号可达；BQ024汇合五课，BQ025先入城后取得资格，取得资格后仍可沿原路返回晨露村。
- 1～10经验权重兑换后的总额、首只加入时机、两只常用伙伴与替补等级、普通野战缺口；课程耗时计入体验但不靠对白和往返凑时长。
- BQ007按不同运气与最低资源状态仍有正式补充路线；随机失败不等于保证某次捕获，不能使用隐藏保底。
- 四职业在可取得的普通装备、公开幻兽与正常技能下完成两场关键战斗；没有只为通过测试而压低野生幻兽物种成长。
- 学院临时状态不会带出、重试不刷真实奖励、断线可安全恢复、重复提交幂等；真实战斗与课程共用规则而非另一套模拟战斗。
- 手机单页信息量、地图实际移动、课程返回、任务未完成反馈、正常下线再登录恢复；不得以静态JSON校验冒充浏览器可玩验证。

30项任务的对白、奖励和前置已接入唯一正式目录，四职业连续服务流程与手机／桌面开篇页面流程已有通过记录。最新改动、待验证范围及对应证据以[实现进度](implementation-progress.md)为准；真人体验时长尚未验证。
