# 装备属性比较参照

[参照表](equipment-stat-reference.csv)只提供人物与幻兽设计比较所需的等级、部位、职业和七维属性。`budget_id`按等级标识一组精良散件预算，不是物品ID或副本ID；不定义名称、掉落、绑定、售价、套装或可获得地点。

每组包含四职业各一件武器及六件通用装备。数值已含精良品质预算，不再乘品质倍率。10级武器对应攻击19；头生命22双防3/3，身生命45双防9/6，手生命10双攻各3，腿生命25双防5/3，脚生命15速度3，饰品魔力12速度1。等级L的属性按`floor(10级对应值×(L+5)/15)`比较，零值保持零。

这是分析输入，不是已实现物品目录，也不证明某等级可获得整套装备。人物、套装、技能、幻兽和敌方数值必须联合验证；不能用本副本毕业装备证明入门通路可行。强化比较沿`floor(原始值×(1+0.05×强化等级))`，不复利、不自动补满生命魔力。

成长与续航工具仅读取该表计算参照值。由旧输入生成的比较报告必须按当前脚本复算才能作为新结论；不得从保留下来的属性数值恢复副本名称、价格或掉落映射。正式1～15级平衡以运行物品、真实来源及可达性为准。
