# 多段攻击与连续攻击特性

本方案为普通技能补充多段直接攻击，特性“连续攻击”使合格招式取配置的最大段数。它不增加人物行动次数、不刷新冷却、不让所有单段技能自动连发。与接触方案合并后为58种效果候选，实际采用范围见[当前差异](design-implementation-gaps.md)，本页候选规模不代表运行开放数量。

## 首个招式与投放

**连环刺**：地属性物理、单个敌人、接触但非拳类，每段威力30，随机2或3段且各50%，耗魔8、冷却0，无附带状态。各段物攻对物防，共用本次攻击的随机波动与攻击侧条件；逐段向下取整，不能先合并威力再算一次伤害。

赤甲蜈蚣及两个进化形态、巨钳幼虫及其进化形态可通过技能书学习；不自动学会，不改变捕获初始技能。赤甲蜈蚣家族A槽由坚岩改为连续攻击，B蜕壳、H守护保留。巨钳家族不额外获得连续攻击，仍在防御与破格间选择。

连环刺书在CITY_SHOP于M110完成后30金币出售，学习等级1；五份同名碎片＋10金币可合成。赤甲蜈蚣普通书池替换为连环刺整书5/1000、碎片25/1000、无970/1000，不另叠旧书池。巨钳幼虫的书池保持原样，玩家可以提前保留该书，但仍须物种学习资格。

“连续攻击”将连环刺段数固定为3，不再抽段数；不修改每段威力与耗魔。原始随机段数和伤害波动在同一次行动确定并保存，断线不重抽。目标已经失效的指令不预先消耗魔力或抽奖。

## 行动与每段的顺序

1. 校验整个行动，支付一次8魔力，锁定原目标、攻击侧条件和本次伤害随机系数；决定2或3段。
2. 保护转移只在首段前选择一次，锁定实际承伤者，消耗一次合法手动保护机会或引雷机会。后续段不再寻找另一名保护者；破阵、破格按各自既定范围生效。
3. 每段开始检查攻击者与锁定承伤者是否仍存活、在场。任何一方已倒下或退出，剩余段取消；不跳回原目标，不重新选择其他敌人。
4. 每段依次处理实际承伤者的免疫、当前防御与减伤、可消费保护、剩余护盾、真实生命损失，再结算该段受击反应。满血减伤和结实逐段检查，护盾额度连续消耗，不每段重新生成。
5. 该段的反射与死亡清理完成后，才能开始下一段。攻击者被反射击倒会停止连击；已经完成的伤害不撤销。目标被击倒后不再打尸体，剩余段不转化为额外资源。
6. 整个行动结束才登记行动完成、击倒成长及战斗结果。费用不按实际段数退款，不为少打一段缩短冷却。最后双方都倒下仍按既定替补资格与失败优先级处理。

群攻同一段的全部份额先结算再反射，与多段招式的“每段之后可停止”不冲突。首批连环刺仅单体，不据此开放多段群攻；若后续添加，必须同时遵守段内完整结算与段间停止规则。

## 逐项特性交互

| 效果 | 多段规则 |
| --- | --- |
| 结实 | 首段前满血可保留1生命，下一段若仍非满血可击倒；不保证吃完整次连击后存活 |
| 多重鳞片、完好防护、明净 | 每段前检查工作生命；前段完全被盾吸收且仍满血，后段继续满足满血条件 |
| 接力守护 | 首个非免疫的有效直接伤害段消费一次，之后不再减免 |
| 储水、蓄电 | 每段合法属性命中独立吸收回复；不会因为首段免疫就停止剩余段。连环刺为地属性，本身不触发水雷吸收 |
| 铁刺 | 整次行动每个持有者对攻击者至多一次；在首个合格接触段后反射，后续段不再反射 |
| 反震 | 首个造成实际物理损血的合格段反射，仍每回合一次；免疫或全盾段不抢占次数 |
| 水脉回流 | 每段按实际损血计算，所有段共用本回合补魔上限；当前连环刺不满足水属性条件 |
| 蜕壳 | 首个满足半血且存活条件的段后触发，双防变化影响后续段；不能把全动作延后反应套到多段上 |
| 破甲 | 首段可消费之前的标记；本次攻击新生成的标记在整个行动结束时登记，不自用来增强后续段 |
| 技术高手 | 按每段原始威力30判断，逐段×1.30；不按三段总威力90拒绝触发 |
| 硬爪、铁拳 | 硬爪逐段生效，铁拳不生效，因为连环刺不是拳类 |
| 自信过度 | 目标只记一次击倒，成长在整个行动结束后生效，不增强同一次连击 |

同一个体只有一个生效特性，因此连续攻击与技术高手不会自身叠加；复制也只取得一个效果。友方光环、护盾和敌方特性仍可构成跨单位组合。

铁刺的去重账本必须以本次行动及持有者身份维护，不能每段调用独立单段函数后重置。运行直接攻击入口为`DirectAttackResolver`，本页候选多段机制应按实际技能配置和对应回归逐项核对，不能由单段验证推定完成。

## 数值基准与风险

基础总威力期望75（60或90），8魔力；连续攻击固定90，8魔力。碎岩击单段80、6魔力，保持更好的魔力效率及非接触优势。两者不是直接上位替代。

技术高手下每段等效39，平均总97.5；硬爪平均总86.25；连续攻击固定90。以上只是未取整的比例参考，不包含逐段最低伤害或护盾。当前共用除法公式没有逐段额外加法常数；实际计算仍必须逐段代入完整公式，不能用总威力比宣称所有等级都恰好增伤20%。

弱点包括容易提前触发反伤、先触发蜕壳改变后段防御，以及过量段数无法重新找目标；优势是能消耗一次保护后继续攻击、突破只保护首个致死段的结实。捕捉仍有误杀风险，不自动停止在1生命，不增加风险提示。

## 交付与验证范围

生成器输出58效果完整槽位、150形态学习池、22技能接触标签、60物种书池及特性交互矩阵。连续攻击可被复制，不被破格忽略；新增书及碎片与已有书籍ID区分。

完整伤害公式逐段预算见下节。单目标结实/护盾/反伤参考已增加9项测试，连同其他局部规则共43项通过；保护者选择、全部58效果的统一状态、多段重连与服务器实现仍待完成，不能据局部参考宣布完整战斗通过。

## 逐段伤害预算


使用相同人物等级与目标防御比较两招，元素中性但保留自身地属性一致加成，护盾前伤害每段最后取整。目标使用极大生命避免过量伤害截断，不作为实际幻兽生命预算；暂不包含反伤、结实、蜕壳或队伍治疗。技术高手与硬爪行是效果敏感性分析，不代表这些物种原生拥有对应槽位，`legal_native`列明确区别。

30级重甲蜈蚣物攻196，对物防170目标，波动1：

| 目标保护 | 护盾 | 随机连环刺期望 | 连续攻击三段 | 碎岩击 |
| --- | ---: | ---: | ---: | ---: |
| 无 | 0 | 362.5 | 435 | 387 |
| 多重鳞片 | 0 | 289.5 | 362 | 193 |
| 接力守护一次 | 0 | 325.5 | 398 | 290 |
| 无 | 180 | — | 255 | 207 |
| 多重鳞片 | 180 | — | 36 | 13 |
| 接力守护一次 | 180 | — | 218 | 110 |

随机连环刺平均少于碎岩击，但有多段特性时单次提高约12.4%；按魔力比较，三段435/8＝54.375，碎岩击387/6＝64.5，后者每魔力伤害仍高。不能只取多重鳞片对局的高收益把连环刺定为常驻最优。

180护盾加多重鳞片时，前三段进入伤害计算前都仍是满血，所以每段145理论伤害都被减到72，逐段耗盾后总计仅损36生命。护盾维持满血就是有效反制；没有盾时首段后失去满血，后两段正常承伤。

极端高防目标还有最低伤害效应：每段最低1，三段至少3，而单段至少1。保留这个既定规则，不为多段偷偷换公式；如果未来首领设计成仅靠1点磨血，就须单独审查多段是否成为唯一可用解法。目前常规预算不依赖此极端情形。

## 段间验收算例

以下保留为段间结算的设计算例，须用当前Java实现逐项验证：

- 满血100的结实目标面对每段126伤害，先损99、再损1，第三段取消；已付8魔力不退款。破格则首段击倒。
- 180盾＋多重鳞片的三段伤害为72、72、72，实际损血0、0、36，与靶场预算一致。
- 攻击者仅50生命时，首段接触1000生命上限的铁刺目标后受到62理论反射，实际损50并停止连击；目标保留该段造成的损失。
- 铁刺整次行动只反射一次，下一次新行动重新获得一次资格；反震共用回合限制，第一段全盾不会提前消费次数。
- 飘浮免疫全部地系段数，保留护盾和接力保护，但不退还施法费用；破格下正常消耗首段接力保护。
- 魔力不足不施放；致死接触仍可反射，双方倒下不会被后续段恢复或撤销。

上述算例不覆盖目标选择、随机抽取、蜕壳双防改变、破甲延后登记、属性吸收、多人群攻、持久化恢复与最终胜负。运行入口为`DirectAttackResolver`；不能据局部算例宣布完整多段候选机制已交付。
