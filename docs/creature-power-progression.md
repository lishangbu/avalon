# 地区推进与幻兽实力

当前地区强度目标以[地图深入后的幻兽成长](regional-pet-growth-design.md)为准：后期同职责输出目标比早期明显提高，旧105～110目标不再采用。下述数据为早先输入的检查说明，不代表最新150形态，也不作为新目标的验收结果。

后期新地图需要有更强、值得培养的伙伴。地区推进允许提高物种能力上限，进化次数则决定成长过程；两者独立，不按三阶段必定强于两阶段排列。早期终阶应保留可用职责，但不要求每一只早期伙伴在所有后期内容里都同样优秀。

本文件确定数值调整的设计方向，八条具体成长改动仍为测试候选。当前120种基础表及副本承伤报告未应用这些改动；150种三阶段方案也仍是独立候选。

[物种七维基础值](species-base-stats.md)将这些系数和魔力成长展开为各形态可公开比较的数据，100对应系数1.00。基础值转换本身不增强或削弱幻兽，后期候选增强另表管理，避免混淆透明化与平衡改动。

## 同级比较口径

比较同等级最终形态，分开检查物理输出、法术输出、承伤、治疗、速度和魔力持续性。初始野外等级不等于物种实力；不能用45级野生幻兽打赢10级伙伴证明后期物种设计更好。所有进化均从基础成长乘绝对倍率后取整，不因多进化一次重复叠乘。

“早期100、后期105～110”仅表达温和上升的目标，不是已经验证的统一评分公式，也不是七项属性全部乘1.1。攻击除以防御的伤害体系中，同时提高生命、防御与攻击会放大实际优势；速度还涉及先手阈值。因此按职责逐项调配，并保留明确弱项，不能用平均属性达标替代战斗核验。

候选优先增强后期物种的主职能力，允许单项增幅超过10%，但不同时抬高所有维度。普通、稀有及隐藏特性也不建立必然强弱阶梯：稀有来源应有值得追求的能力，隐藏特性仍遵循特定场景更合适的既定原则。

## 取得价值与培养节奏

新地图同时提供较高的捕获等级、更有竞争力的物种能力、不同技能组合和新的收集形态。这些收益可以共同吸引玩家更换部分队伍。无需保证每一种新伙伴都替代旧伙伴，也不应只靠新外观支撑后期探索。

三阶段路线优先投放在有足够培养空间的地区，但后期两阶段也可以有更高实力上限。晚期回头捕捉并准备齐材料的玩家允许连续完成两次合法进化；不为强制观看中间形态额外添加等待天数或隐藏熟练度。正常首次推进时的等级、材料、研究站与道路应给中间形态留下使用机会。

## 后续应用与验收


应用前还需逐条比较普通及隐藏槽位、技能伤害与行动轮数、治疗消耗，以及1～4只伙伴组合中的作用。优先比较表中八组早晚期参照，不要求早期伙伴获胜；要求后期优势能观察到、短板实际存在，且普通副本不把更换指定后期物种设为必需条件。

正式采用成长调整时，应同步物种表、进化属性快照、三阶段倍率核对、D12承伤与治疗容量报告，再验证实际战斗。此次不据此改变野外敌人的成长，以免未经核算就提高后段捕获难度；野外实例若与幻兽共用成长，实施时必须一并评估。
