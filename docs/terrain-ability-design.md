# 电气与青草场地

阿瓦隆采用全场魔法环境的适配方式，不新增“接地／离地”分类。人物、普通幻兽、飘浮个体和首领都受同一场地影响，替补不参与；不能按图片有没有翅膀临时判断资格。这里不宣称照搬宝可梦的地面接触规则。

## 两项特性与数值

| 特性 | 普通槽 | 入场效果 |
| --- | --- | --- |
| 电气制造 | 雷蜥家族A，替换坚岩 | 设置电气场地，双方雷属性直接伤害×1.15 |
| 青草制造 | 萤枝灵家族B，替换灵肤 | 设置青草场地，双方木属性直接伤害×1.15，并在回合末恢复在场存活单位生命 |

青草单次基础恢复为`floor(min(目标最大生命/32, 设置者等级))`。设置者等级在设置时保存，实际恢复不超本阶段开始时缺失生命；不复活、不恢复魔力、不触发直接治疗特性，也不按目标首领生命无限放大。

50级来源下，最大生命1000恢复31，最大生命2000及20000均恢复50。等级12来源只能最多恢复12，不能通过低级场地发动者获得满级恢复上限。复制青草制造使用复制者等级，来源死亡或离场不改变当前场地快照。

场地增伤适用于对应元素的物理与魔法直接攻击，包括群体和多段；不放大中毒、反射、沙暴、治疗或吸收。电气场地没有睡眠免疫，因为当前没有睡眠；青草场地不自动减半所有地属性技能，也不净化中毒。后续扩展必须显式修改规则，不能从原作名称隐式继承效果。

## 与天气并存

每场战斗最多一个天气槽和一个场地槽，二者可以并存，三人副本所有小队及敌人共用。晴天＋青草是合法组合，雨天＋电气也合法；两个青草来源不叠加恢复，电气与青草互相覆盖但不覆盖天气。

攻击开始时同时锁定天气和场地快照，整次攻击的全部目标与段数共用；乘数进入完整公式、最终一次取整。天气更改不能影响已经锁定的攻击，场地同理。破格不忽略天气或场地，属性免疫仍优先使对应命中无效。

例如青草场地中木系本系克制攻击的系数为1.20×1.25×1.15＝1.725；雪天再影响物理木攻击乘0.90，魔法木攻击不受这项减免。双方都得到这些变化，不能把阵地当作只服务发动者小队的光环。

## 持续与结算

第R轮设置，至R+4轮结束，含当前轮共五回合。同类型刷新到期时间，不加总剩余回合；不同类型覆盖。来源退场不提前清除，整场结束清除，新一场副本战斗不继承。重复入场事件的回执不能重新续期。

初始入场按已有稳定入场顺序处理原生效果，再处理复制所得效果；同一层最后设置者生效。单个入场事件至多发动自己当前一个特性，不能同时因原生和复制各设一次场地。

青草在设置当轮至到期当轮的回合末状态阶段恢复，顺序与沙暴一致：先锁定阶段开始天气、场地、状态、生命和在场资格，计算各项变化，再统一提交生命，最后清理死亡、判断战斗结果及清除到期环境。

为防止遍历顺序影响结果，本阶段所有恢复来源共用“阶段开始缺失生命”额度，先相加再整体截断，不能每个来源各自按同一缺口重复加满。先确定恢复总额，再合并本阶段伤害，最后截断到0至最大生命。阶段开始满血者恢复额度为0，不将青草当成能抵挡尚未发生沙暴的额外护盾。阶段开始已死者既不参与恢复，也不能靠净变化复活。

例如生命上限2000、当前1990，青草50、毒疗125、沙暴62：两项恢复合计按原缺口截为10，净变化10−62，最后生命1938。不按“先沙暴后治疗”得到满血，也不按单位列表顺序选择结果。

本条把中毒、毒疗与环境统一到同一阶段；运行规则由`BattleEnvironment`与`PoisonPolicy`在战斗回合流程中结算，不能逐个调用独立模块的即时生命写入接口冒充这条规则。持续伤害抗性只修正对应伤害及既定毒疗转换，青草本身不是异常，不受该抗性削弱。

## 交互、来源与展示

电气制造与青草制造均可复制、不被破格忽略。清除来源特性不会倒扣已经设置的场地；未来全场特性压制也须区别“阻止入场发动”与“删除已存在场地”。自然回复、净化术不能清除全场环境。

雷蜥原来源和捕获初始技能不变，玩家用普通A槽选择雷系队伍增伤，B引雷选择保护；萤枝灵B提供共享持续恢复，A滋养、H净羽仍服务于主动治疗。发动场地不需要专用技能书，不改变个人技能学习资格。

UI公共状态区最多显示天气与场地两条，并分别显示到期回合、双方作用及青草恢复说明。来源等级和恢复上限由规则说明提供，不能让玩家误以为首领会每轮恢复1/32且无上限。场地不增设地图移动按钮或新的战斗外设施。
