# 北境与黑棘外围14条培养路线

等级与进化口径以[50级物种投放](creature-level-50-scope.md)、[家族服务候选](evolution-family-services.md)及[地区成长](regional-pet-growth-design.md)为准。以下14条路线首次取得34～49级，全部终阶可在50级内取得。

[28行物种规格](creatures-lategame.csv)覆盖最后14个野外基础种与14个终阶。基线全部表联合为120种：60个野外基础种、60个进化终阶，终阶不进入捕捉池。三阶段扩展另为其他30个家族增加中间形态，合计150种；本批14个家族仍各进化一次。

## 职责与形象

青翼龙提供偏耐久的风法选择，洞穴小鬼提供脆弱但灵活的暗法；岩穴地精与骨爪兽偏物理保护，赤铜幼偶使用物理雷牙，萤枝灵使用光系恢复。深潮幼鳐为水法输出，玄羽鸦以暗攻和减速配合换取较弱物防。

43～49级陆续取得晶角幼龙、熔鳞幼龙、巨钳幼虫、暗潮幼鳗、玄岩灵与雪鬃幼兽。后期伙伴具有明显成长优势，但按角色提高核心维度，不要求七维同时领先：晶角幼龙偏法防辅助，熔鳞幼龙偏火法，巨钳幼虫偏物理主力，暗潮幼鳗增加暗水覆盖，玄岩灵慢速承伤，雪鬃幼兽偏水系支援。具体值读取当前地区成长候选，不能再用较早基线推断强度。幼体与终阶的形象差异仍需正式素材证明。

洞穴小鬼归恶魔族、岩穴地精归类人族，均使用明确的野外物种定义。城镇NPC、劳工、商旅和具名剧情角色不因同族自动成为可捕捉目标；伙伴捕捉资格由内容配置决定，不能按种族批量套用。机械族也只有赤铜幼偶等指定物种进入生态池，不把所有机械居民当作失控幻兽。

青翼龙使用已核实的OL来源语义图片地址。其余13个基础种和本批14个终阶缺图，asset为空；bsymg单体仅作形象候选，不能未经风格核对就宣称它们补齐了缺图。所有已交付文件继续采用语义命名，不把来源编号塞进前端地址。

## 遭遇、等级与捕捉

[E23～E29七个池](encounters-lategame.csv)使用每池100权重、单／双怪有放回抽取，分别绑定已有任务事实。新地区继续投放适合生态的旧物种，旧种高等级个体不占额外图鉴名额。基础捕捉率本批统一30%作为测试基准；稀有程度主要通过投放权重与道路表达，不额外叠加一种未定义的稀有捕捉惩罚。

北境峡谷外洞从M173恢复的横向驿路支线进入，采掘场和外部维修场在对应调查完成后开放。北岸滩林从M242平民接应点走岸线进入；地热晶谷从联军营地进入；敌后渡口石滩与冷泉石谷分别从M261与M269已保护的外围道路进入。它们均不是副本内部或终局独占房间。

最高首次出现为49级雪鬃幼兽，全部终阶在50级内可取得，不要求资料片开放。终局前就可进入对应外围生态点，不要求先完成M300才获得最后一批培养资格。任务事实与人物等级可能有差异，地图应显示实际敌人等级，不能强迫玩家降级来匹配设计区间。

球档每10级覆盖一档，31～40使用IV，41～50使用V，强化球同档；本基础版不投放VI。越档与人物等级差按既定公式处理，不因目标高于人物等级禁止投球，也不添加捕捉误杀提示。五档报价、任务门槛和普通野外掉落见[封印球供应](capture-and-wild-supply.md)。

## 进化与前沿研究

青翼龙39级、洞穴小鬼和岩穴地精40级、骨爪兽41级、赤铜幼偶42级、萤枝灵43级进化；深潮幼鳐46级、玄羽鸦47级、晶角幼龙48级、熔鳞幼龙49级进化，其余四种50级进化。所有路线保留单属性、族群、个体身份、当前技能与槽位；终阶学习池不缩小、不自动赠技能。人物达到50级后，合格伙伴仍按自身等级正常获取经验，不能因人物封顶中断幼体培养。

全部14条路线和专属材料加入[68项家族材料目录](evolution-wild-materials.csv)。39～43级的六条路线在WORKSHOP_RESEARCH兑换，其余八条在FRONTIER_RESEARCH兑换。前沿服务要求研究教学与M246集结核验完成，在联军营地由莱娜主持，学院基础研究接待由机构维持。无需完成研究区救援、领主截击或统帅战即可兑换，不形成进化材料反向依赖终局的循环。

前沿增加R_FRONTIER_ECOLOGY委托：接受后在已开放E27地热晶谷获得6次普通战斗胜利，完成晶谷安全观察点记录，回同站交付1研究凭证。单场双怪仍只计一次；该委托与其他研究采样共享同时一个实例限制，不另加经验、金币或强化石。玩家也可继续做已开放的其他研究委托，共享凭证余额；不靠强迫刷高等级怪才能进化。

全部配方维持通用1＋专属1、18凭证、零附加金币、满足条件必成功。高等级路线没有为了体现稀有额外翻倍材料；实际培养代价还包括幻兽升级、学习和地区到达。研究赠礼始终只有一次，可保留到前沿再选择，不因新站开放重复赠送。

## 全目录边界

120种的数量、基础成长、初始技能、书池、特性、进化目标及配方已经形成候选目录。29个遭遇池覆盖60个基础种，所有60个终阶只从进化获得。未增加繁殖、双属性、随机资质、闪光数值加成或转职系统。

目录覆盖不等于上线完成：缺图、物种之间的实际强弱、新增书和球档来源、普通掉落、进化精英供给、图鉴总奖励与培养耗时仍须核对。十一族是世界分类，不要求每族平均分配幻兽或副本数量，也不以某种族更晚出现就规定它必然更强。
