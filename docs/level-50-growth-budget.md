# 1～50级成长预算

## 可复算模型

每分钟击败一只同级普通怪为效率假设，单只经验为等级×10。主线固定奖励占升级总经验60%，其余40%由战斗提供；支线与首通额外收益抵扣战斗缺口，不能额外加入后仍声称总时间不变。人物及幻兽沿用同一等级门槛，不新增追赶倍率。

控制点表示适度副本路线单级目标小时数：1级0.12、3级0.35、5级0.55、9级1；10级1.2、20级7、30级12、40级16、49级19。两组分别线性插值并归一至5小时和427小时。这里的49级表示49升50，50级不提供下一等级经验储存。

令单级归一时间为H小时，非战斗时间S=12H分钟。10级前野外等值时间U=120H，之后U=160H。门槛=10×等级×U，四舍五入至10经验，再以实际门槛反算U。单人用时S+0.4U；10级后适度副本S+0.3U，持续组队S+0.2U。10级前均按单人计算。

## 首通与敏感性

暂以全部12个副本都在满级前完成首通作为偏快边界，每本20～30分钟，且额外经验能全部抵扣战斗缺口。相对重复路线，持续组队每本节省1.5倍副本预算分钟，12本共6～9小时，剩余约309.13～312.13小时；适度副本每本节省2.25倍，共9～13.5小时，剩余418.50～423.00小时。

具体入口与时长尚待逐本核算；若满级后才首通，其奖励不能缩短此前成长。不能将上述假设替代实际前置路径模拟。熟练队伍若战斗效率提高20%，持续组队基线约279.51小时，扣首通后还会缩短：至少300小时是标准效率下的设计目标，不是对所有玩家的硬性保证，不引入强制等待或经验限额。
