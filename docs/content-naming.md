# 内容命名规则

## 幻兽术语

设计正文与玩家可见文本统一使用“幻兽”；野外个体称“野生幻兽”，结契后的日常对白可称“伙伴”。系统名称采用“幻兽图鉴”“幻兽培养”“幻兽编队”“幻兽仓库”“幻兽中心”。敌对人物仍按士兵、强盗或首领等实际身份称呼，族群不自动决定可捕捉性。

内部类名、接口、配置键、数据库标识与资源路径保持现有标识。既有数据库变更集与玩家存档不做中文批量替换，来源作品和原始资料名称也保持原名。玩家可见地点及任务说明通过更新内容配置生效，已有战报与已保存的物品名称不会自动重写。

普通幻兽优先用简短外形或生态特征命名，种族与属性由独立字段展示。首批物种名称为利爪猫、小岩怪、芽灵、雷蜥、青岚雀、紫炎兔、影尾狐、月光蛾。已有青岚隼、紫焰灵兔等进化形态名称保持。

外部素材文件名不是最终物种名，图像与文件名不符时按实际形象复核，候选见 [幻兽生态与素材](creature-ecology.md)。外部文件保留路径用于追溯，不以“伊利丹”等来源人物名直接创建阿瓦隆角色。

首领采用名字与身份结合：獠牙兽王、黑角先锋、兽栏看守·维克、驯兽师·格鲁恩。裂耳是专名，伤痕巨兽可作为描述中的称号，不将称号强行存为另一物种。名字不改变可捕捉性或战斗类型。

普通装备使用材质与用途：精铁剑、猎手长弓、橡木法杖、白木短杖、旅人兜帽、软皮手套、旅行外衣、轻便长靴、加固护腿与旅人护符。卫兵装备使用卫兵制服、卫兵长靴等一致名称。副本装备为巡林者套装、巡林长剑、驯兽长弓、驯兽法杖、安抚短杖与兽牙护符。

等级、品质与槽位使用专门字段，不拼入名称。首领专属命名装备须先确定真实掉落归属，再添加人物冠名，不因为名字好听就虚构额外掉落。武器模板内部的类别名称允许用于策划说明，玩家显示优先采用职业对应具体名称。

配置中的默认名称与玩家自定义昵称分别处理，不以中文全文替换修改个体身份。任务对白、界面提示和测试期待应与正式命名保持一致。

## 内部ID的调整规则

诺姆城取名自大地精灵Gnome，英文使用Gnome City，设计ID为GNOME_CITY；诺姆研究站使用GNOME_RESEARCH，研究委托使用R_GNOME_ECOLOGY。NOOM不是该元素精灵的标准拼写。中文“诺姆”保持不变，也不因此把城中所有居民设成同一种族。词源参照[大英百科全书Gnomes条目](https://en.wikisource.org/wiki/1911_Encyclop%C3%A6dia_Britannica/Gnomes)。

诺姆城运行编号为GNOME_CITY，内容、代码及测试夹具使用相同编号。研究站与研究委托仍仅为设计ID，不表示地点和任务已开放。

允许改动语义已不符合内容的ID，但不要求中文名每次润色都触发改ID。STONE_GOLEM、THUNDER_LIZARD、CLAW_CAT仍准确，继续保留；正式任务使用O/N/U/S/F/J/E区域前缀与三位编号；副本使用语义标识，不随标题变化。

影尾狐统一使用SHADOWTAIL_FOX，月光蛾统一使用MOONLIGHT_MOTH，设计与运行配置采用相同编号。

林间兽栏装备沿用运行目录中的正式 CRYSTAL_* 编号；配置、奖励、测试夹具和文档使用同一组编号，编号在各目录中统一。

CRYSTAL 是林间兽栏装备的内部编号前缀。套装ID与装备ID分别表达集合和单件物品，不将饰品强行并入套装。内容ID不编码等级、品质或投放版本；数据库实体主键不是这些内容ID，不因命名调整而重新生成。来源图片路径也不随内容ID改动。

实施必须同时核对物种成长、技能池、进化、捕捉、图鉴、任务、掉落、装备套装、制作与市场引用，以及数据库幻兽、库存、待领、任务事实、交易订单和保存战局。测试数据库按正式配置创建。玩家自定义昵称与物种默认名称分别处理，不以中文全文替换修改个体身份。内容ID变更须同步所有引用、测试夹具与文档。
