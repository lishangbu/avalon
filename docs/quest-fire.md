# 沙拉曼达任务

F001至F060包含25主线和35支线。核心入口依赖水域与高地两份成果，调查人类工程装置与总封印的连接。

主线包含清理道路、资源支护、封存工坊、可替代旁路、节点停机与火山副本。战斗和现场机关分别验证，不用交谈代替实际行动。

支线提供资源、制造、捕捉、展示、精英悬赏与封存武库。工道獠牙野猪、遗迹泥岩灵、雷球灵、旧炉小岩怪及武库普通幻兽调查均要求实际捕获，个体保留。影尾狐仍只检查当前拥有，接受仓库、交易等合法来源，不要求新捕捉。F033检查四级球，匹配后续30～33级普通幻兽。

制造产出完整人物装备，特殊图纸与副本奖励并行。武库总镇守后，工匠以冷却渠普通蓝甲蛛的捕获调查作为图纸委托成果，保留捕获伙伴与图纸。

战士已自然完成核心线的材料、战斗两种通路。新增支线及其他职业的验证状态见[实施进度](implementation-progress.md)。
