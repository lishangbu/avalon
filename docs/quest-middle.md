# 温蒂妮与希尔芙任务

两城各60项任务：25主线、35支线。均从N025开放，互不依赖，完成两城核心线后汇合到沙拉曼达。

主线依次处理区域威胁、遗址准备、可替代通路、失控装置、封印室三阶段及节点记录。U/S011允许战斗或交付木材修路，完成前可切换，公共奖励一次。

支线覆盖自动采集与制造、指定捕获、拥有展示、人物装备、悬赏及独立遗物副本。U027准备木钳，用于HERBALISM资源点；工具检查不消耗。浅滩蓝甲蛛、水道沼鳞兽、清泉灵，以及高地獠牙野猪、青喙兽、绒耳妖、旋风灵使用实际捕获目标，个体保留。可选储藏室与废塔入口的调查同样有明确普通幻兽捕获成果。

蓝鳍鱼与白羽鹤用于当前拥有展示，不要求本次捕捉；仓库和其他合法来源均可，也不会收走。它们的可选栖息地在普通幻兽调查后开放。

战士已通过两种城市顺序的完整核心线。新增目标、完整支线和其他职业的验证状态见[实施进度](implementation-progress.md)。正式目标、物种、前置、数量与报酬以内容目录为准。
