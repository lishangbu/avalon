# 化学变化气体与全场特性暂停

玄岩灵家族普通B槽由灵肤改为化学变化气体，A坚岩、H守护保留。其存在价值是暂时拆解特性组合，代价是自己的伙伴也失去特性收益。它不造成毒伤、不新增异常图标或毒属性，不降低物种七维基础成长。

当前40项经典代表条目至此均有本项目适配规则，合并原32项自定义效果为72种候选。这不等于宝可梦所有特性已复刻，也不等于72种已经接入统一执行器或完成平衡验证。

## 抑制范围与多个来源

只要至少一个存活在场的原生气体持有者存在，全场所有其他幻兽、普通幻兽的特性停止生效。双方与多人副本所有队伍共享这一判定；不是只关闭敌方，也不是只关闭持有者所属小队。

气体本身不被气体压制，不被破格忽略，也不能被复制。多个气体来源互不关闭，以来源集合计算，最后一个来源离场或死亡后才解除。禁止按“第一个来源消失就恢复全部”实现。复制者原生复制槽不能临时取得气体，避免靠复制产生来源身份递归。

范围限于当前72项幻兽特性。人物职业技能与被动、首领独有阶段规则、装备效果、药品、技能书资格、种族七维及属性克制均保留。首领若明确使用这份幻兽特性表中的某效果，该效果也被暂停；不能用“首领”身份给同名同效果暗设例外。

## 什么停止，什么保留

| 类型 | 气体期间 | 解除以后 |
| --- | --- | --- |
| 常驻或条件乘数：坚岩、轻盈、硬爪、毅力等 | 不参与本次能力或伤害计算 | 后续读取时重新生效 |
| 免疫、吸收、结实 | 本次命中不提供保护或恢复 | 后续命中正常判定，不返还此前损血 |
| 受击、治疗、击倒、回合末及主动离场触发 | 不产生新反应、层数、充能或恢复 | 只响应解除后的新事件，不补发过去收益 |
| 入场威吓、天气、场地、复制抽选 | 被压制期间入场则不发动 | 恢复不是重新入场，不自动补发动；须真实再次入场 |
| 已生成的外部状态：威吓、破甲、接力保护、天气、场地 | 依原持续时间和消费规则继续 | 不重新续期、不重新赠送 |
| 自身特性运行状态：加速等层数、引火/食草增益、蜕壳修正 | 状态记录保留，来自特性的能力或伤害增益暂停 | 未因离场/死亡清除的状态可继续提供效果 |
| 次数与账本：已用免费施法、接力次数、击倒身份 | 保留，不刷新 | 仍按原额度判定 |

毅力本身没有叠层，解除时读取当前仍存在的异常。加速层数保留但暂停速度收益、期间不新增层数；离场仍清零。蜕壳已触发记录保留，暂停其速度与双防修正；解除后恢复一次派生修正，不重复净化或再次乘算。

已存在的中毒不消失。毒疗暂停期间正常承受毒伤，恢复后仅尚未过去的跳点转治疗；同步暂停期间新增中毒不反馈，解除后也不补反馈。自然回复暂停时换下不能净化，再生力暂停时换下不回血；不能退出战斗或进仓库后补领。

复制已取得的临时效果不抹掉，只暂停。气体解除后恢复同一临时效果，不重新抽敌人；如果个体已离场或死亡，则按复制生命周期清除，不能解除气体时带回旧结果。还没成功复制的原生复制者恢复后保持原状态，直到真正再次入场才抽选。

## 结算时点

初始出战全部单位登记完成后，先确定气体来源集合，再处理其他入场特性，因此同批初始气体能阻止天气、威吓、场地和复制发动。不能先让它们发动一遍再删掉结果。普通野生幻兽也遵循相同步骤，不按玩家方优先。

主动换宠作为一次原子位置变更：换下方的离场触发使用变更前气体状态；位置替换完成后重算来源集合，再检查换入方的入场触发。最后一个气体换下且换入天气宠时，新天气可以发动；气体换入时其他仍在场单位的特性随之暂停，不视为那些单位再次入场。

每个直接攻击段开始时锁定该段的气体抑制集合，供本段全部伤害份额、保护、免疫与反应共用。本段气体来源被击倒后，先完成本段全部份额和按锁定资格产生的反应，再重算集合，供下一段或下一次行动使用。因此群攻杀死气体者不能让同次群攻后处理的目标突然恢复结实；多段后续段则可以根据新的来源集合判定。

一次攻击的进攻侧条件、天气和场地仍沿既定行动快照。气体改变不追溯修改已锁定的进攻增伤或已派生技能，但下一段防御侧资格按新集合读取。实际清除源与下一次命令之间不能插入一段客户端自定的“气体空窗”。

回合末按阶段开始气体集合锁定触发资格，再处理全部中毒、毒疗、环境及其他变化，最后清理死亡与来源。因此来源被沙暴击倒，不会让同一阶段后遍历的毒疗个体突然回血。下一轮正常恢复。复活气体持有者并重新在场后恢复来源，具体复活位置仍依技能规则，不允许仓库或替补死亡个体开全场气体。

## 公共信息与AI

公共战斗区显示“特性受到抑制”及气体来源数量，目标详情保留原生特性说明并标注当前暂停，不把原生槽位改成空值。野生幻兽可据公开气体状态知道免疫类特性暂时不生效，但不因此获得目标隐藏槽位信息。

此前观察到的免疫记录仍保存。气体存在时不依据这些记录排除已知被免疫的属性攻击；气体解除后恢复使用记录。毒疗受益记录同理：被抑制时允许正常施毒，解除后按已观察记录避开。不能因临时暂停删除记忆，导致气体反复开关让AI从零学习。
