# 当前实施状态

本文只记录当前代码与正式配置。内容数量由目录核算，测试覆盖由现有用例说明，不将历史执行耗时、候选表或未实施方案当作交付。

## 正式内容

- 人物职业为战士、游侠、法师、牧师，创建后固定；人物和幻兽共用经验门槛，上限50级。没有职业树、可分配路线点或职业晋级系统。
- 正式任务目录包含300项任务、327个步骤，145项主线、155项支线。开篇、四城、联合终章及主线后任务均在配置中；目录存在不等于完整自然旅程已验收。
- 任务支持显式接取、目标计数、分支选择、现场动作、交付、放弃、追踪和幂等回执。普通捕获目标只记录接取后的真实行为，拥有展示检查当前合法个体。
- 野外战斗、训练、首领、PVP和副本使用正式战斗核心。11个副本见[副本目录](dungeons.md)。
- 幻兽支持捕获、编队、仓库、学习、遗忘、进化与图鉴；实际物种和获取途径以正式内容为准，不再维护另一套候选物种清单。
- 生活系统包含采集、制造、种植和钓鱼；工具、辅料及基础原料有商店来源，见[生活专业](life-professions.md)。
- 装备、强化、玩家市场、好友、私聊、世界聊天及系统通知已有服务端和浏览器实现。

## 验证范围

四职业连续专项位于 `QuestOpeningRuntimeTest`，从开篇推进至N023，经过真实行走、战斗、采购、现场回收和封印副本阶段结算。原开篇包含额外同种伙伴的归属反例和固定成功捕捉种子夹具，因此不能称全程零夹具或自然捕捉概率验收。后续任务有独立专项，不能拼接成完整新号旅程通过结论。

采集恢复、批量采购、目标库存补齐、制造库存与绑定、跨角色供料、E009新制造交付有对应事务和浏览器用例。专业练级及后期经济主要采用离线模型核算；模型保留地图开放、库存、资源或交易等各自假设，不证明完整自然闭环。

完整中后期真人体验、全部支线可达性、长期经济、实体手机操作及生产容量没有完整验收结论。执行入口见[测试流程](testing-workflow.md)，核算与维护脚本见[脚本说明](scripts.md)。
