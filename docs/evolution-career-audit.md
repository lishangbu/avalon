# 进化后幻兽与人物基础输出对照


## 比较条件

每个家族只选该等级已达到数字门槛的最高阶段，未到野外首次投放等级的家族不纳入。此选择假设主线、研究站和材料均已满足，属于能力上界；不宣称玩家到20级就必定拥有所有可进化伙伴。

幻兽从候选学习池中选择对中性目标伤害最高的基础单体技能：当前物理威力80／耗魔6，法术威力100／耗魔12，均冷却0，考虑本系1.2加成。读取当前连续成长候选。假设所选技能已经学会，不忽略技能书取得和遗忘成本。未加入聚炎、猛火、蓄势等特性、克制、随机波动或爆发技能，波动固定为1。

人物使用既有职业系数外推至对应等级，属于后期设计标尺，不表示后期职业数值已最终验证。比较初始装备、同等级可穿的最高档完整副本装备及全套强化7；副本分别为D01、D03、D05、D08、D12，不计套装额外输出。强化逐件属性乘1.35后向下取整，品质已经包含在模板中，不再额外乘品质系数。职业标尺包含初始武器攻击8，更换装备时先减8，再加新装备的实际攻击，不重复计入武器。

人物没有元素属性一致加成，战士／游侠使用威力80的既有基础职业攻击，法师火球与牧师惩击使用当前100威力／12魔力。法师群攻、牧师治疗、战士保护、游侠印记均未计入，此表不能把职业综合价值简化成单体伤害。目标防御使用对应等级中性标尺20＋5L，双方相同。

当前按每个家族首次来源进度连续分配主职属性，基础形态与终阶同时调整；不同职责不统一增加七维。主攻击上升会改变两宠与人物的贡献比例，本表并不能证明完整队伍已经平衡。

## 已暴露的后续问题

- 20级紫焰灵兔、30级烈火灵、40级夜焰小鬼、50级熔甲龙依次形成基础单体输出上界；仍需检查同阶段其他职责与物理伙伴的省魔优势。
- 早期三阶段伙伴已可在20级终阶，数字门槛读取当前家族表；取得材料仍需实际研究委托，不能把可达数字阶段当作全玩家已经养成。
- 后期高魔力伙伴可能减少整场药耗和人物补给动作，但本表不模拟施药、目标死亡、换宠、治疗或行动优先级，不能将其与魔力上限直接相乘当作实际战斗贡献。
- 中段保护预算、D12实际成长承伤及人物与两只出战幻兽的完整回合仍待联合核算。不能把一个幻兽基础技能的比值当作整支队伍输出占比。
