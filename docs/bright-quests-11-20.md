# 诺姆与温蒂妮：11～20级70项任务设计

本包展开[故事编排](bright-story-arcs.md)BS05～BS12，承接[开篇](bright-opening-design.md)BQ030。共70项稳定设计ID：BQ031～BQ100，故事预算依次9、9、8、10、8、9、9、8。BQ031～BQ074已接入正式运行配置；数据库与浏览器验证范围见[当前进度](implementation-progress.md)。BQ075～BQ100尚未接入，不代表已有逐条对白、正式奖励或战斗数值。

## 共同完成契约

- 表内权重1／2／3仅表示经验预算的轻／常／重，不是经验点数。金币、实际经验、补给与装备奖励由整体经济定标后逐项填写；不能直接把权重写入运行奖励。所有任务奖励一次性结算、可重试且防重复领取。
- 观察、比较、交付、战斗和路线验证均须服务端记录实际动作。阅读公开资料不等于自动找到野外证据；同一任务多个观察点只共同构成一个完成判据，不拆成多项凑数。陈述选择错误时允许重看已发现证据，不扣金币、不清空前置。
- 任务物品不占普通背包；教学、庆典和研究用物资来自任务专用库存，不强迫玩家卖装备、消耗稀有材料、献祭已培养幻兽或学习生活技能。无需稀有物种、隐藏特性和固定职业，也不增加饥饿或亲密度门槛。
- 所有指定战斗为普通地图或主线独立遭遇，按正式胜负、损失和恢复规则执行；没有必败、现实时间倒计时或副本通关前置。首领不可捕捉须由公开身份规则明确，不能战后临时取消普通个体的捕捉资格。
- 地方成果按个人进度保存；重复访问显示已修复、已开门或已迁行状态，不重复发奖。任务中途下线不会毁船、杀死幻兽或取消庆典。地图每次移动只跨真实相邻边，不以交付或对话自动传送。
