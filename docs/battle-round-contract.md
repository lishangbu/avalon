# 完整回合调度与结算契约

本契约连接[入场与换宠](ability-entry-exit-contract.md)、[特性行动结算](ability-resolution-contract.md)、[公开观察](wild-immunity-response.md)及[统一回合末](terrain-ability-design.md)。保留现行手动指令、主动换宠先行、同速随机、普通无效目标转移及副本45秒单窗口规则。这里只规定可实现顺序，不表示完整调度器已交付。

## 一轮的固定阶段

| 阶段 | 输入与处理 | 此后不可追溯修改的结果 |
| --- | --- | --- |
| 1. 开放本轮 | 检查上一轮已结束、战斗未结束；发布首领预告与公开状态 | 本轮身份及副本截止时间；刷新不延长 |
| 2. 锁定敌方意图 | 普通野生幻兽根据此前已结束回合观察及此刻公开状态选择；首领按预告脚本 | 招式及原目标，不读取后续玩家提交；固定脚本不因免疫临时换招 |
| 3. 收集玩家指令 | 单窗口接收本人的免费补位与整套指令；提交前可编辑，提交后锁定 | 已接受指令不撤销；同请求重放返回原结果 |
| 4. 登记免费补位 | 收齐或截止后统一检查整批手动补位，登记全部新个体，再执行入场效果 | 死亡个体不发主动离场收益；新个体可保留自己的本轮技能指令 |
| 5. 主动换宠 | 使用此时速度锁定换宠顺序，再逐项原子执行退出、替换、入场 | 当前换宠队列不因前一项的新天气重排；换入者无额外行动 |
| 6. 锁定普通行动队列 | 以补位和换宠全部完成后的有效状态，按技能优先级、最终速度排序 | 同优先级同速度本轮随机一次并保存；后续不重排 |
| 7. 执行行动 | 逐条重查行动资格、合法目标、费用和冷却，执行整次技能及反应 | 无效动作不改选招式；多段与群攻按各自原子范围执行 |
| 8. 回合末状态 | 战斗仍未结束时锁定全场阶段状态，聚合中毒/毒疗、环境及合格恢复 | 统一提交生命与跳点，按初始生命缺口限制恢复，不逐玩家重复结算 |
| 9. 收尾与判定 | 清死亡状态、处理合格成长触发、到期、缺席移出和全场结果 | 下一轮资格或唯一终局结果；终局奖励仅沿已确认参与资格产生 |

开战原生与复制入场在第一轮开放前完成。后续轮次的免费补位发生在整套提交收齐之后；不得新增“先提交补位再重新给45秒”的窗口。玩家可在同一提交中为指定补位幻兽选择技能，服务器只有补位成功后才允许该个体执行。

单人没有选招截止时间；副本未提交单位本轮空过，不自动防御或补位。已提交后断线仍执行原指令，连续缺席沿既定两轮移出规则；移出不是击杀，不提供特性成长或掉落。

## 两次排序的边界

主动换宠本身先于普通防御、保护与攻击。多个换宠先按阶段5开始的有效速度排序，同速使用本轮保存的随机结果，不能以HTTP先到或玩家编号优先；此队列锁定后不改。每次换宠更新气体来源，后一个换下者使用当时状态判断再生力等收益。

全部换宠完成后才为剩余普通指令计算速度。例如先换入降雨，则本轮尚未排序的悠游自如可以获得速度加成；这符合“换宠先结算”。普通行动队列锁定后，攻击附带减速、蜕壳、脚本增援或新天气不再重排本轮，只影响后续实际数值读取或下一轮排序。

原生同批入场的稳定排序与动作同速随机不是一件事。入场效果按其批次规则使用固定位置消除歧义；实际动作同优先级同速度继续随机。两种排序都保存结果，重连不重抽。

换宠命令属于原个体，不能沿位置自动转给换入者。免费补位命令则明确绑定被选入的个体，其正常技能可以进入阶段6。每个个体一轮最多获得一项正常行动，不能同时免费补位后再次作为替补被另一位置调用。

## 行动资格与原目标失效

执行前先检查行动者是否仍存活在场、可行动；眩晕造成的跳过不自动改为防御，不支付原技能费用。费用和冷却不足同样不由服务器改成普攻。野生幻兽使用普攻兜底发生在阶段2的合法选择阶段，不是执行失败后的额外行动。

普通攻击和伤害技能的原目标在执行前已失效，按通用规则转向其他合法敌人，自动备选以固定战斗位置排序取首个；治疗转向生命比例最低的有效友方，同比分别按固定战斗位置打破并列。只调整合法目标，不借此重新选择最克制的招式或读取尚未公开的特性。捕获不自动换目标；执行条件失效时不扣球，本轮不补选。

群攻原目标集合中已失效的名额，按相同合法目标规则补入尚未被选中的目标，最多达到该技能原提交的目标数量；目标不足时缩减，不重复命中同一个体来凑数。可执行目标完全为空则取消且不支付。首领点名或明确锁定机制遵循各自规则，不使用通用重选破坏已公开预告。

完成执行前目标校验及必要重选后，才支付费用并锁定整次攻击上下文。多段技能此后不会因承伤者在段间死亡而转打另一只；已经锁定的群攻份额也不会因某份击倒保护者而退还原目标。无法承受的后续份额不产生额外实际损血。

## 结果判定与回合末

每次完整行动连同附带效果、反应与击倒成长结算后检查全场结果；不能在反射尚未处理时提前胜利。有限阶段增援、双首领存活资格先按对应关卡定义判断，机制物是否决定胜负须显式登记，不默认每个可攻击物都阻止结束。

若敌方已无可继续战斗成员、玩家仍有存活的合格参战成员或健康替补，立即胜利，不再多跳一次毒或沙暴，也不为结算青草、再生力而虚构离场。若双方无任何可继续战斗成员，失败。判断范围是整个副本战场，不是单个玩家的小队。

敌人仍存活而玩家只剩健康替补时，不在本轮中途补位。剩余动作按当前合法性执行，无目标则空过；随后正常处理本轮末，再进入下一轮手动补位窗口。副本窗口截止仍没有任何存活在场成员且无人完成合法补位，按既定失败收束，不靠无限替补等待冻结战斗。

只有行动阶段结束且战斗未终结，才执行一次统一回合末。环境在到期当轮仍结算，之后清除；已经死亡的单位不能因净治疗量复活。阶段内同时死亡按同一结果检查，不因遍历顺序偏向玩家或首领。加速的本轮资格须排除本轮换入、补入、复活与曾离场者，不能仅用回合末仍在场判断。

胜负确定后停止所有后续战斗阶段。副本主动退出或连续缺席的奖励排除仍按当前回合已记录的参与事实处理，不能因终局提前于常规移出步骤而错误发奖。一次胜利回执包含状态、参与资格与奖励事实；重复读取或断线重试不重发。

## 事件恢复与验收

本轮需保留已接受指令、免费补位结果、换宠顺序、普通行动顺序、各次随机抽样、当前执行阶段及已提交事件回执。恢复只继续尚未提交的阶段；不能按当前速度重新排已经锁定的队列，不能按当前生命重算已经完成的攻击。

设计验证至少覆盖以下完整路径：

1. 两名玩家同速换宠，随机顺序保存；先换气体会改变后者离场恢复，但重复执行结果一致。
2. 免费补位气体与天气同批登记，气体阻止天气；主动换宠最后一个气体退出后，换入天气可以发动。
3. 换入降雨后悠游自如参与本轮普通行动排序；攻击阶段新增减速不重排已锁定队列。
4. 免费补位幻兽正常执行一条技能；主动换入幻兽不继承原位置技能或追加行动。
5. 普通攻击执行前原目标死亡可合法转向；连环刺段间目标死亡必须停止。
6. 群攻补足失效目标时不重复命中、不增加提交目标数量、不改变首领固定点名。
7. 最后一敌死于直接攻击但反射同时击倒玩家，按全场和替补资格判断，不先发奖励。
8. 玩家仅余替补时进入下轮补位，未补位超时失败；敌方先全灭则直接胜利，无额外回合末跳点。
9. 回合末多人同时受毒、青草和沙暴，统一生命缺口与气体资格，整场只执行一次。
10. 在提交、补位、换宠、行动和回合末边界恢复，状态及奖励与不中断执行一致。
