# 阿瓦隆游戏设计

## 游戏定位

首发客户端采用 Vue 3、TypeScript、Vite 和 Ionic Vue，统一 iOS 视觉模式，支持浅色、深色及跟随系统。当前仅交付手机与桌面浏览器版本，Android 原生封装暂缓。前后端在
avalon 单仓库管理，frontend-maven-plugin 构建前端，Spring Boot 同源发布。具体边界见 [客户端架构](adr/0002-vue-client.md)。

阿瓦隆是一款面向现代手机浏览器的联网 WAP 文字游戏，保留经典文字网页体验。玩家角色与幻兽共同战斗，以队伍构筑、角色剧情与职业成长、区域冒险和首领机制为设计支柱。

人物与幻兽成长上限已扩展至50级；当前主线为BQ001～BQ066，完整16～50级内容仍待补充。生活系统规则见[正式规格](life-professions.md)。
强化、进化和市场已有系统实现。强化人物门槛30级、市场11级；研究教学人物门槛11级，低级进化配方与材料来源已经接入，不将接口可用等同于内容交付。
实现及待验收范围见 [开发进度](implementation-progress.md)；高等级内容、真人时长与生产性能不因系统测试通过而视为完成。

后端采用 Spring Boot、同步 JDBC、Spring Data JPA 与 Hibernate，使用 Maven 构建；保持模块化单体、服务端权威结算、事务与幂等。
静态内容使用 JSON，经 Schema 和业务校验后只读，不热更。技术约定见 [开发约定](development-constraints.md)。

基础内容规划至50级，后续资料片按实际内容决定是否提高等级上限；提高时每次增加10级，其余扩展区域、剧情、幻兽、副本、装备与收集。不固定最终等级上限，也不将开篇经验与成长公式直接外推到后期。规划内容与实际开放范围分别记录。

主线、野外探索与捕捉不消耗体力，不设每日硬次数；可重复副本按每角色、每副本独立的每日进入次数管理，具体规则见联网战斗部分。核心成长奖励不绑定连续签到，野外练宠保持开放；通过战斗耗时、补给消耗、副本次数与奖励难度共同控制产出，具体产出数值尚待验证。

升级由主线任务、沿途战斗与主动训练共同支撑。主线提供稳定基础经验，野外战斗是重要补充，允许通过捕捉、练宠和探索自然补等级；不再以只领取固定任务经验就能逐节点升级为预算前提。主线困难优先通过战斗表现、队伍准备与资源体现，不突然增加硬性等级门槛；遇到困难时提供练级地点与装备来源。分别验证持续使用教学双宠和换入新宠的成长路径，不假定每个玩家都会花同样时间练宠。

允许高投入玩家更早达到当前版本等级上限、获得更多成熟队伍与装备，不为拖慢高投入玩家而整体抬高升级门槛。投入时间主要扩大收集与构筑选择，不能绕过等级、技能数、特性槽位及强化上限无限提高单队属性；不增加每日经验衰减或体力，副本次数限制不扩展到野外练级和捕捉。长时间在线本身不判定为作弊，自动化作弊另按实际行为处理。

产出验证同时检查经验、金币、装备与材料，按每天 1、3、12、24 小时、一周累计投入比较成长和经济；24
小时为极限压力场景，不是预期健康游玩方式或自动封禁条件。材料绑定不等于经济已经安全，还需检查物品出售、培养成果交易和库存积累等间接流通。当前仅确立验证要求，尚无完整的每小时产出与市场模型。

### 试玩范围与完成标准

- 1～15
  级体验包含11级市场及符合物种门槛的进化；PVP、闪光、圣兽、强化、特性转换、转职及繁殖遗传不纳入前15级体验。未绑定且符合交易规则的物品可以流通。系统并发、事务与恢复已有自动化覆盖；真人操作与长期组合平衡仍待试玩。
- 图鉴收集奖励、改名、技能书回收及仓库扩容已有下表开发默认值，不等同于经过完整经济验证。称号外观、非商店书估价及后续扩容档位仍待明确；未配置部分不视为免费，也不计入现有收益报告。

重复书按同一物品编号的可用库存跨来源合计判断，回收后至少保留一本。绑定书可计入保留数量，但不能出售；待领库存、幻兽已学技能不计入。“同名”仅指同一书目，不按显示名称匹配。玩家在补给商店主动选择数量并确认总金币，服务端重新核验库存、报价及战外／副本外资格；重试不重复扣书或发金币。仅已有商店售价的完整书可回收，非商店书暂不估价，任务书、绑定书及碎片不可出售。

- 任务页可展示推荐等级与练级地点，低于推荐等级不增加主线等级锁。BQ029 不要求先到 15 级；D01 仍要求人物 15 级且完成 BQ029。
- 当前只要求现有八种幻兽配置完整，不新增物种凑数量；配置包含成长、分布、捕捉率、初始技能、学习资格、特性与来源，不要求三个槽位各有不同特性。
- 设计完成标准：任务条件与奖励完整，野外及各首领、职业训练配置完整，成长和资源可复算，核心页面及异常出口明确，文档无关键冲突。数值模拟通过不等于实际试玩通过。

任务的主线／支线分类、多标签、角色级一次性完成、放弃重接、进度归属与追踪规则统一见[任务系统规则](quest-system.md)。引导是可同时用于主线与支线的标签，不另设训练任务分类。规则与实现差距在该文档及开发进度中分别记录。

## 队伍与职业

- 玩家角色亲自参战，幻兽作为战斗成员参与队伍构筑。
- 不纳入最终幻想式的剧情同伴设计，不设置固定同行冒险者；重要NPC按事件与职责参与故事。
- 当前创建角色时选择固定职业，同一角色不能更换职业，四职业均应能通过幻兽搭配完成个人冒险。长期框架支持新增职业和后期转职扩展，开放前仍遵守固定职业；转职条件、原技能保留和装备处理尚未配置，不提供试玩入口。
- 每名玩家的随身容量为 5＋floor (人物等级/10)：初始 5 只，10 级 6 只、20 级 7 只、60 级 11 只。人物每达到 10
  的整数倍等级自动增加一个空位，不赠送幻兽；容量增长不增加参战数。
- 可参战名单最多四只：2 只出战、2 只替补；人物仍与两只幻兽同时行动，其余随身位置为携带位，不能在本场换入。
- 主动换怪消耗被替换幻兽所在位置的本回合行动，角色及另一只幻兽照常行动。
- 主动换怪在普通技能前完成；入场幻兽本回合不能再行动，但会承受随后发生的攻击。
- 幻兽可以补足职业职责，职业保留独特机制，玩家角色应对队伍有实质价值。
- 每个职业有两条可混合投入的成长路线，见下表；可在城镇支付适量游戏货币重置，具体费用尚未确定。
- 开局即可使用基础职业技能；诺姆学院的职业课程解锁首个影响构筑的专属技能。
-
职业技能直接使用熟悉的魔兽世界技能名称；当前开局技能命名为战士「英勇打击」「援护」、法师「火球术」「法力护盾」、牧师「惩击」「治疗术」、游侠「奥术射击」「震荡射击」。名称已确认，回合制效果及数值另行确认与配置，不把名称视为原作全部机制的移植。
-
英勇打击、火球术、惩击、奥术射击在人物本回合行动时直接造成单体伤害，不需要提前蓄力；英勇打击为无属性物理伤害，火球术为火属性法术伤害，惩击为光属性法术伤害，奥术射击见下文。治疗术按人物法攻恢复指定存活友方生命，不能复活。威力、耗魔与冷却使用下文开篇技能表。
- 法力护盾仅保护施法者自身，施放占一次行动，具有持续时间与吸收上限；吸收伤害时消耗魔力，魔力不足时只吸收可支付的部分，剩余伤害正常结算，魔力耗尽护盾消失。开篇测试参数见下文。
- 法力护盾的开篇测试参数：高优先级施放，耗魔 8、冷却 2；吸收上限为施放时法攻 × 2，持续至施放后的第 2 个回合结束，含施放回合共
  3 回合。每吸收 5 点伤害消耗 1 魔力，每次完整攻击的耗魔向上取整，魔力不足时最多吸收剩余魔力 ×
  5。吸收额度耗尽、魔力耗尽或到期时结束，同名护盾不叠加；多段攻击的吸收与扣魔时点仍需明确。
- 奥术射击按游侠物攻计算威力，由目标法防减伤，属于无属性法术伤害；游侠保持物攻成长，奥术不新增元素属性。威力、耗魔与冷却使用下文开篇技能表。
-
援护以高优先级施放，指定自身以外的一名存活友方，持续至本回合结束，接下其下一次可转移的直接攻击伤害后结束，单体攻击与群体攻击均适用。群攻时只转移被保护者的一份伤害，战士仍承受自身那份，两份分别按战士的防御与减伤结算；转移伤害不能再次被援护转移。持续伤害、场地伤害不转移，特殊不可援护攻击需明确预告。未触发也消耗本次行动及施放资源。
-
每次敌方攻击结算前检查援护，战士仍存活便锁定本次转移。同次群攻的自身伤害与代接伤害分别计算，再一起扣除生命；即使战士因此倒下，也不将伤害退回被保护者。后续攻击不能再由倒下的战士援护。护盾及魔力等有限吸收资源共用，不能重复抵扣同一额度，具体吸收顺序待配置。
- 被接下攻击附带的中毒、眩晕等效果随该攻击转移至战士，再按战士的抗性判断。独立施加的全体状态、场地效果及已经存在的持续伤害不转移，战斗预告区分攻击附带效果与独立效果。同次群攻造成重复状态时按该状态的叠加规则处理，具体状态规则待配置。
- 震荡射击造成少量物理伤害，令目标速度降低 20%，影响随后 2
  个完整回合，不改变本回合已排定的行动顺序、不剥夺行动。同名减速不叠加，重复命中刷新持续时间。威力、耗魔与冷却见开篇攻击技能参数；不同减速叠加及首领抗性待配置。
- 基础状态采用有限持续时间并在页面显示剩余回合。减速只影响后续回合的速度排序；持续伤害在回合结算阶段造成伤害；眩晕等硬控制若开放，必须有明确命中率、免疫窗口和首领抗性，不允许无限续控。状态来源、叠加和净化规则按技能单独说明。
-
状态抗性按五组管理：行动控制、速度控制、持续伤害、属性削弱、位移与强制行动。分类按实际效果：降速属于速度控制，降攻防与降治疗属于属性削弱；“诅咒”等名称不固定代表某一组，应按其扣血或削弱等实际效果归类。列出分类不代表当前开放所有状态或新增站位机制；具体结算见待定设计中的整套方案。
- 抗性等级统一为0级无抗性、1级效果降低25%、2级效果降低50%、3级免疫；同组抗性取最高等级，不重复相加。首领面板默认只展开当前战斗涉及的抗性组，详细页再列出具体状态；玩家单位只显示已生效的抗性来源。
- 援护耗魔 6、冷却 1；小岩怪掩护耗魔 4、冷却
  1。掩护同样以高优先级保护自身以外的一名存活友方，当回合有效，触发一次后结束，不能连锁转移，未触发也消耗施放资源；保护者倒下与攻击附带状态转移沿用援护规则，但仅接单体攻击。
- 人物基础技能通过等级、职业导师和职业任务学习，进阶技能可消耗技能书等道具，学会后永久保留，不适用幻兽遗忘规则。
- 重置成长路线不遗忘人物技能；依赖路线投入的技能，在重新满足条件后才能使用。
- 人物每场战斗配置 6 个主动技能，战斗外免费调整；普通攻击、防御、道具和捕捉不占这 6 个位置，路线被动按投入生效。具体学习费用尚未确定。
- 30 级首次职业晋级，通过职业导师的专属任务与个人战斗考验，解锁本职业更深的成长路线及高级技能学习资格；不更换职业、不重置等级、不强制组队。

| 初期职业 | 成长路线一             | 成长路线二                     |
|----------|------------------------|--------------------------------|
| 战士     | 守护：承伤、援护、反击 | 强攻：破甲、重击、压制         |
| 法师     | 元素：属性攻击、爆发   | 奥术：护盾、削弱、魔力管理     |
| 牧师     | 恢复：治疗、净化、复活 | 惩戒：持续伤害、标记、攻守转化 |
| 游侠     | 狙击：标记、弱点攻击   | 陷阱：减速、行动控制           |

所有职业均可完整参与幻兽捕捉，游侠不垄断捕捉能力。

## 生物族群

世界内容采用以下十一族分类。该分类已确认用于后续内容设计，尚未逐只分配现有物种，也不代表当前程序已具备族群字段或相关玩法。

| 族群 | 分类范围 |
|------|----------|
| 兽族 | 兽类及具有相应生命特征的幻想兽。 |
| 羽族 | 鸟类及鸟形幻想生物；不因具有翅膀就归入此族。 |
| 水族 | 鱼类及其他符合设定的水生生命；不等于所有水属性生物。 |
| 虫族 | 昆虫、蛛类与多足生物等。 |
| 植物族 | 植物生命；真菌、孢子类需要按具体设定另行审定。 |
| 龙族 | 具有明确龙类血统的生命。 |
| 元素族 | 由元素力量凝聚的生命。 |
| 亡灵族 | 死后复生的生命、残留灵魂及幽魂。 |
| 恶魔族 | 具有明确恶魔来源的生命；邪恶立场或使用魔法本身不构成归类依据。 |
| 机械族 | 机械生命、机关造物与机械傀儡；纯魔法驱动的石像不强行归入。 |
| 类人族 | 人类及具有相应形态、社会文明的类人种族，具体身份仍可保留人类、矮人等名称。 |

族群与战斗属性、职业、立场分别表达不同含义：会使用火焰的兽类可以属于兽族并具有火属性，德鲁伊或骑士是职业而非族群。
物种归属结合生命构成、来源与世界观逐只审定，不能直接从素材目录、名称或外形推断。族群不自动决定能否捕捉；NPC、敌人与可培养伙伴的身份分别确认。

暂不设置精怪族或软泥族。史莱姆及其他尚无明确归属的素材保留待定，不强行塞入现有分类，也不因为存在素材就默认加入可培养物种。
本节仅确认内容分类，不新增族群被动、克制关系、捕捉方式或数据库字段；单族群／多族群规则、具体剧情来源与物种投放仍待确认。

## 幻兽获取

- 以野外捕捉为主要获取方式。
- 初始幻兽通过剧情获得，少量特殊幻兽通过专属任务结契。
- 开篇领宠后、协助庆典货车开路前，通过捕捉教学获得第二只幻兽；庆典之后、前往小站途中，通过可选捕捉获得首只替补并学习换怪。
- 不同区域拥有不同幻兽生态，寻找新成员推动区域冒险。
- 构筑差异主要来自属性克制、物种特性、技能搭配和战斗职责；普通幻兽采用固定成长，不生成随机个体资质。圣兽之池随机成长仅作为后期扩展，当前不开放。
- 武器配方相关任务可以要求捕捉指定幻兽并上交，将收集与获取装备联系起来。
- 幻兽培养使用冒险材料，不通过吞噬其他幻兽升级；重复捕捉的幻兽可以放归。任务上交是另一个明确允许的去向。
- 上交页面展示符合任务要求的幻兽个体列表，由玩家手动选择并上交具体个体，不自动代选扣除。
- 普通交付任务接受此前已捕捉、包括培养过的合格幻兽，由玩家自行选择；捕捉教学等特殊任务才要求接取后新抓。
- 永久图鉴记录曾经获得的物种，上交或放归不抹除记录；仓库记录当前持有个体。每个物种的首次收集奖励只能领取一次。
- 普通交付任务接受交易获得的合格幻兽；教学或明确要求亲自捕捉的任务除外。
- 交易获得也登记图鉴，另行记录亲自捕捉成就；每物种首次获得奖励仍只能领取一次。
- 上交受锁定、出战及进行中副本名单保护，具体按下文仓库与交付规则；上交不等同于杀死或吞噬幻兽。
- 野外战斗中削弱目标，由玩家角色消耗一次行动和捕捉道具尝试捕捉；低血量及适当异常状态提高成功率，页面显示当前概率。
- 首次野外捕捉与普通捕捉使用同一概率规则，失败继续战斗；学院借用单位的捕捉课程独立于真实幻兽获取。
-
普通野外遭遇按个人生成，允许越级捕捉，目标高于人物等级时应用捕捉衰减。捕获后保留原等级，高于人物等级的幻兽存入仓库，不能编入出战或替补；人物达到对应等级后才可编队。三人副本与剧情首领不能直接捕捉，部分首领对应物种可通过后续野外稀有遭遇或专属任务获得。
- 捕捉成功即归玩家所有，战败不丢失，本场战斗不能立即使用新捕获幻兽。
- 随身与仓库均无合格位置时不能投球，不消耗行动或道具；高于人物等级的捕获个体必须有仓库空位。
- 试玩 1～9 级随身 5 只，10～15 级随身 6 只；仓库独立 30 位且试玩不扩容，随身仅按人物等级增加容量。
- 上架幻兽仍占卖方容量，买入时检查买方空位；不能通过上架腾出捕捉容量。

### 随身、仓库与交付

- 随身容量按 5＋floor (人物等级/10) 增长，固定最多两只出战、两只替补，其余为携带位。初始有一个携带位，10 级有两个；只有两只同时与人物行动。
-
只有出战与替补四只获得相应随身经验，不平分；所有携带位和仓库不获得。副本外可在战外调整分工，每场开战固定可参战名单。进入副本时锁定两只出战、两只替补及其余携带位的分工，整次副本禁止通过编队页面调整，战间及休整点也不能调整；携带位不能调入参战名单，容量增长也不解除副本锁队。
- 副本战斗内的手动换宠和倒下补位继续遵守既有行动规则，但只能使用入本时锁定的四只可参战个体，不引入携带位或仓库成员。每场新战斗及战败重试恢复入本首发与替补分工，具体见副本跨场规则。
- 仓库 30 个位置，试玩不扩容；城镇免费手动存取。等级不高于人物的新捕获个体依次进入空替补位、空携带位、仓库，不自动填出战位、不挤出已有成员；高于人物等级直接入仓。没有合格位置不能投球，不扣行动或球。
- 新捕获个体即使进入空替补位，也不加入本场固定参战名单，不能在本场换入、不领取本场击败经验。战后可手动编队，后续独立任务完成时按实际合格出战／替补名单结算任务经验。BQ007
  仍按捕获、手动编入第二出战位、回报后发任务经验的顺序进行。
- 随身和仓库均无合格位置时不能投球，不扣行动或道具。战斗和副本内不能访问仓库。手动放生需确认具体个体，锁定个体先解锁。
- 上交列表同时列出随身与仓库合格个体，标明位置、等级、属性、特性和技能；玩家手选、确认，直接消耗该个体并结算任务，无需先从仓库取出。
- 锁定、正在出战或属于进行中副本固定名单的个体不能直接上交，需先解除相应状态。交付资格复核、消耗和任务完成同笔记录。
- 重复捕获的同物种个体不自动合并、不互相吞噬，也不提供重复捕获经验；玩家可在队伍或仓库比较等级、属性、特性和技能后保留不同构筑。放归只消耗玩家明确选中的个体，不返还封印球、经验、金币或技能书；图鉴记录、首次获得奖励和已揭示特性记录均保留。
-
单个和批量放归共用保护规则：战斗及副本内禁止操作；出战、替补、锁定、任务提交中及进行中副本名单内个体不能放归。战斗及副本外的未锁定携带位和仓库个体可放归，受保护个体须先解除相应状态。批量必须逐项勾选，确认页列出物种、等级、特性、技能和位置，隐藏个体单独醒目标注；不默认全选。完成后不可撤销，保留操作记录。
- 放归或市场托管后必须至少保留一只等级不高于人物的伙伴。仓库伙伴可免费取出、倒下伙伴可免费恢复，因此可计入保留名单；高于人物等级、已放归或市场托管中的个体不能计入。首次合法野外捕获前，最初结契伙伴不能放归。服务器在角色锁内检查整批操作，不能通过并发操作绕过。
- 任务上交与放归是不同操作：上交个体按任务规则消耗并可能推进奖励，放归不推进任务。上交页面默认隐藏受保护个体，并在确认页再次提示隐藏特性个体；不自动替玩家选择“最低等级”或重复个体。
- 不增加“上交后补队再完成”、额外调整编队弹窗或自动补位。上交仓库或携带位个体不影响四只出战／替补获经验；主动上交替补时，只有剩余合格幻兽获经验。
- 交付确认提示个体将消耗，不默认选中、不自动挑最低级。这不是捕捉风险提示；不恢复误杀警告、伤害预测或锁血。

## 幻兽成长与技能

- 角色与幻兽分别拥有等级，幻兽培养等级不超过角色等级。
- 出战幻兽和随身替补都能获得经验，仓库幻兽不自动获得经验；经验支持按获得者与敌人的等级差加成或衰减。
- 普通幻兽同物种、同形态、同等级且无临时效果时基础属性一致；圣兽之池随机成长不纳入当前版本数值和内容。
- 采用水、火、风、地、雷、木、光、暗八种属性，统一使用单字名称，每只幻兽先设一种属性；木指植物与生命生长，不泛指所有生命。亡灵作为幻兽类别概念，不自动等于暗属性。多重克制关系见战斗规则。
- 属性决定攻防关系，物种特性和技能决定战斗职责；同一属性可有不同职责的幻兽。
- 每只幻兽的主动技能与可学习被动技能合计最多 7 个；另有 1 个独立的物种特性，不计入上限且不会遗忘。
- 首发支持隐藏特性，采用宝可梦式特性槽位：物种配置普通槽 A、普通槽 B、隐藏槽
  H，每只个体在生物生成时确定其中一个槽位，只持有并生效该槽位对应的一个特性，不叠加三个特性。野生幻兽在自身生成时即已确定槽位，不延迟到玩家遭遇或捕捉时抽取；削弱、施加状态、捕捉失败后重试、捕捉成功、刷新页面及重连均不重抽同一个体的槽位。捕捉继承该野生幻兽已有槽位，各来源的生成概率另行配置。隐藏特性提供不同玩法或生效条件，不设计为普通特性的全面升级，不额外增加个体资质或成长。
- 开篇任务即介绍普通与隐藏特性，不等到 15 级才教学。个体生成时按来源配置确定 A／B／H
  槽位，并读取物种对应特性；捕捉成功后才揭示该个体是否为隐藏特性。捕捉前的目标详情不公开实际槽位、隐藏标签或能直接识别槽位的特性名称与效果说明；捕捉后的结果与个体详情展示实际特性及效果。隐藏身份的揭示不触发抽取或重抽，特性仍按生成时结果参与战斗，野生幻兽战报不播报特性名称、槽位或隐藏身份，但保留真实伤害、治疗及行动结果；允许玩家从效果推测，捕获后再明确揭示，不为隐藏身份改变战斗计算。开篇来源概率与教学例外见下文。
- 同一物种的普通槽 A 与普通槽 B 可以配置相同特性，也可以配置不同特性；不要求每个物种设计三种不同效果。当前可先配置一种普通特性供
  A、B 共用，再配置隐藏特性，有明确玩法需要时才区分两个普通槽。隐藏特性在特定场景下略有优势，不追求全面强于普通特性，也不要求另造一套完全不同的玩法。
- 当前采用 A、B、H 三个槽位，不扩充到五个；生成概率独立配置，不通过重复填槽隐式决定概率。框架允许后续扩充，新增槽位须有实际玩法需要，不要求所有物种同步增加。
- 1～15 级普通野外与可捕捉精英统一采用 A 45%、B 45%、H 10%，逐个体独立生成，不设置槽位抽取保底，连续捕捉不累加概率。不可捕捉首领不套用此表。概率在生物生成时使用，不在捕捉后重抽；BQ004
  赠送利爪猫、BQ007 专用教学小岩怪固定普通 A，野外同物种不继承教学限制。不增加隐藏捕捉难度，不将隐藏特性设为主线或副本准入条件。后期可能引入闪光或皮肤作为外观收集方向，当前不纳入
  1～15 级交付范围，具体机制未定。
-
图鉴可公开物种的普通与隐藏候选特性及获取来源，但不揭示当前未捕获个体的槽位。捕获结果和已拥有个体详情显示实际特性及普通／隐藏类别。普通捕捉交付任务不要求隐藏个体，合格列表由玩家手选，隐藏个体明确标注且提交时再次确认；首次获得隐藏类别可登记，不重复发放物种首次收集奖励。
-
后期可通过高难度副本获得特性转换机会，将已有幻兽转换为本物种适用的特性；保留等级与技能，不触发遗忘。不提供付费转换或随时免费切换。转换产物形式、方向、成本与副本开放条件待确认；不再采用普通可重复单人任务积累转换材料的途径。捕捉获得隐藏特性个体仍属于收集途径，开篇普通野外与可捕捉精英均采用下述统一槽位概率，后期新增来源另配。
- 初始幻兽可通过进化与技能学习长期培养；稀有物种不因稀有度而全面胜过初始物种，具体进化名称、阶段和条件另行配置。
- 幻兽技能学习需要消耗技能书等道具，并可能随机遗忘已有技能；人物不适用此规则。
- 学习前根据已有技能数量判定遗忘数量，随机遗忘相应数量的不同旧技能，再加入新技能。新技能必定学会，且不会在本次学习中被遗忘。
- 已有 7 个技能时仍可学习，但必定遗忘至少 1 个旧技能，保证学习后不超过上限。
- 遗忘对象随机决定，玩家不能指定；幻兽没有可免费重新配置的永久已学技能池。
- 学习页面显示遗忘概率及可能失去的旧技能；高技能数量时可能出现学习后技能数量减少。
- 幻兽自带初始技能，等级决定高级技能学习资格；新增与重学均消耗对应技能书，重学同样按当前技能数判定遗忘。
- 初始利爪猫自带水弹（单体水属性法术伤害）和微疗（小幅单体治疗）；教学小岩怪自带碎岩击（单体地属性物理伤害）和掩护（替友方承受可援护的单体攻击，不能接群攻中的伤害）。各自
  2 个自带技能计入 7 技能上限，后续学习时也可能遗忘；独立物种特性见下文。水弹与碎岩击享有 1.2
  倍属性一致加成，治疗与掩护不享有。普攻和防御为通用指令，不占可学习技能名额。
- 利爪猫的普通 A、B 均为「活力」：每次直接攻击伤害结算前，若生命为满值，该次伤害降低 10%；恢复至满生命后可再次生效，多段攻击逐段检查，不减免持续伤害和场地伤害。隐藏
  H 为「回春」：直接治疗生命比例不高于 50% 的目标时，治疗量提高 15%；逐目标在治疗结算前检查，可治疗自身，不作用于药品、持续恢复、护盾或复活，溢出治疗无额外收益。
- 小岩怪的普通 A、B 均为「坚岩」：受到的物理直接攻击伤害降低 10%，包括自身承受与掩护代接的伤害；不减免法术、持续伤害或场地伤害。隐藏
  H 为「守护」：通过掩护代接的直接攻击伤害降低
  15%，物理与法术均适用；仅作用于代接部分，不作用于自身直接受击、持续伤害或场地伤害，不扩大掩护范围或提供额外保护行动。遗忘掩护后暂时无法获得该收益，重学仍遵守技能书与遗忘规则。
- 青岚雀的普通 A、B 均为「轻盈」：速度提高 10%，参与正常排序，不改变指令优先级。隐藏 H 为「乘风」：对受到有效减速影响的目标，风属性直接攻击伤害提高
  15%；本次攻击开始结算时逐目标检查，减速可来自任一友方，被免疫、移除或已到期时不触发，本次攻击新施加的减速不追溯增强本次伤害。
- 紫炎兔的普通 A、B 均为「聚炎」：火属性直接攻击伤害提高 5%。隐藏 H 为「猛火」：自身生命不高于上限三分之一时，火属性直接攻击伤害提高
  15%；本次攻击开始结算时检查，同一次多段攻击沿用该判定。
- 上述普通与隐藏特性互不叠加，不改变基础成长，不占技能名额且不会遗忘。守护与其他减伤相乘；乘风、聚炎、猛火作为独立伤害倍率，与属性一致加成及克制倍率相乘，不增强持续伤害或固定机制伤害。PVE、PVP
  使用相同条件与效果。以上数值已确认为测试基准，尚需联合技能、成长和行动顺序验证，不以隐藏特性作为开篇通关门槛。
- 已掌握的同名技能不能重复学习，也不消耗道具。
- 技能书按物种或类别限制适用范围，另有少量通用技能书；不完全按元素限制，使用前显示适用条件。
- 幻兽可学习符合物种或类别资格的跨属性攻击；初版每个物种的元素伤害技能池覆盖本属性及最多 2
  种其他属性，不要求每个物种都有两种跨属性选择。这是技能池范围限制，不是玩家任意选择两种属性；不改变 7 技能上限，治疗和辅助技能另按学习资格判断。
- 基础技能书由商店和教学任务稳定提供；特色技能书来自区域掉落、捕捉交付与副本；稀有技能书另有累计兑换途径。
- 可以购买高于人物等级的幻兽并存入仓库，但只有等级不高于人物的幻兽才能编入出战或替补；购买前提示使用等级，交易不降低幻兽等级。
- 部分物种具有进化链，达到等级并完成材料或专属任务条件后，由玩家主动进化。
- 进化保留等级与已有技能，不触发随机遗忘；形态、基础能力及物种特性按进化结果变化，确认前显示变化，原有与新形态的图鉴记录均保留。
- 进化保留个体特性槽位，读取新形态同一槽位的特性：A 对应 A、B 对应 B、H 对应
  H，不重新抽取。普通进化后仍为普通，隐藏进化后仍为隐藏；具体名称和效果可随形态改变，不要求继承原特性的名称与效果。
- 1 至 15 级任务与练宠路线：采用每级需求 100L 的开篇测试曲线，必经任务经验合计 6000，基础路线约 48
  次普通有效击败；BQ023 额外 200 经验，可减少约 3
  次击败。详细节点、训练位置、可选精英与新宠训练目标见 [明亮开篇设计](bright-opening-design.md)。训练数量不是硬性任务计数，版本满级按
  15 级封顶且不存经验处理；数值不直接外推到 60 级。
- 经验不按数量分摊，人物与合格出战、替补幻兽分别结算；所有携带位及仓库均不获得经验。
- 人物与幻兽记录累计总经验，升级不清零；界面经验条显示当前等级到下一级的进度。当前等级进度等于累计总经验减去当前等级的累计门槛，分母为下一等级与当前等级门槛之差。具体经验曲线与幻兽等级上限处的存储规则分别配置。
- 不设置相对人物等级的独立追赶加成；战斗经验按获得者与敌人的等级差每级加减 2 个百分点，上下限 50%～150%，取样与封顶见下文。
- 幻兽不能超过人物等级；达到同级后仍可积累本级经验，最多存到下一等级累计门槛减 1，多余舍弃且不形成隐藏经验余额。按开篇测试曲线，人物
  6 级时幻兽最多累计 2099，显示 6 级、599/600；人物升到 7 级不会凭空补经验，幻兽再实际获得 1
  点才升级。该规则针对人物等级限制；版本满级处没有已开放的下一级，按 15 级封顶且不存经验处理。
- 进化不能退化；继承的旧技能继续可用，即使新形态通常不能学习，但遗忘后重学必须满足当前形态的技能书条件，消耗技能书并承担遗忘风险。
- 进化不自动增加主动或可学习被动技能，仅改变形态、基础能力、物种特性与学习资格；新增技能仍通过技能书学习，遵守7个上限及遗忘规则。青岚雀→青岚隼、紫炎兔→紫焰灵兔的正式门槛以进化目录为准。

### 经验结算与封顶

- 试玩人物与幻兽封顶 15 级；升级保留溢出经验并允许连续升级，达到 15 级后不存经验，经验条显示已满级。未来提升上限从 15
  级零进度继续。人物满级不妨碍低级随身合格幻兽成长。基础游戏仍规划至 60 级。
- 战斗经验倍率为 clamp (100% + 2% × (敌人等级 - 获得者等级), 50%, 150%)
  。人物与各合格幻兽分别计算；按进入本场等级确定，不在结算中随升级改变倍率。任务经验及固定通关经验不乘此倍率。
- 同笔奖励先结算人物，再按升级后人物等级限制幻兽。幻兽不能超过人物等级，同级最多存至下一等级门槛减 1，多余舍弃；人物升级不凭空补幻兽经验。版本
  15 级封顶规则优先。

**经验与结算顺序。**
每场对每个获得者，将各有效击败敌人的基础经验乘以各自等级修正后相加，最后向下取整一次；不使用敌方平均等级，零经验不强制加到一。先结算战斗经验，再结算固定通关经验，最后结算同事件完成的固定任务经验，每笔先人物、再合格幻兽；战斗倍率仍使用入场等级。同一结算事件内名单在变更前固定，不给刷新或换宠插入窗口；BQ004
奖励后领猫、BQ007 回报、职业训练入场快照等特例保持。战报分列战斗基础经验、修正结果、固定经验、实际入账及上限舍弃量，金币和掉落另列。每笔只记一次，满级显示已满级；不把舍弃经验存成隐藏余额。例：6
级上限幻兽累计 2000、应得 300，只入账 99、舍弃 201，人物同笔先升级时按其新等级重算幻兽存储上限。

### 技能学习操作

- 每个物种配置独立技能池，表示该物种有资格学习的全部技能，池的容量不受七技能上限限制。初始技能是池内的生成配置；当前已学技能是个体实际持有的集合，最多七个。学习消耗技能书并遵守既定遗忘概率，书不授予池外资格。普通
  A、B 与隐藏 H 共用同物种技能池；普攻、防御和特性不占学习名额。后续扩充技能池不自动给已有个体补技能。
- 普攻、防御始终可用，不占幻兽七个学习技能名额，不会遗忘。特性不进入技能池，A／B／H槽位不受学习影响；人物技能不遗忘。
- 只在战外学习，玩家选幻兽、技能书并确认；展示当前技能、新技能及对应遗忘概率和数量。复核物种资格、未学同名技能、持有书、非战斗状态及技能名单未变化，不合格不扣书。
- 合格后消耗 1 本、抽取旧技能遗忘结果并学会新技能，同次保存。新学技能不参加本次遗忘；原有 7 个时至少遗忘 1 个，总数不超过
  7。概率及 1～3 个数量沿既定表，不新配概率。
- 结果列明新增、遗忘与剩余技能，不能刷新重抽、退款或免费补回。重复提交不二次扣书。
- 基础攻击书 30 金币、微疗／掩护等基础辅助书 60 金币，沿既定开放时点出售；学院和诺姆城承接村庄已开放书目。烈焰冲击与光幕不因遗忘加入普通商店。

### 收集闭环扩展规则

以下规则作为收集系统的统一默认规则：首次获得物种奖励为少量金币、封印球和图鉴记录，不直接奖励强力装备；首次发现隐藏特性登记发现成就，可奖励外观或称号，不增加战斗属性；收集四种和八种分别提供阶段称号、少量资源或外观。图鉴分别记录亲自捕捉、交易获得和任务获得，交易获得登记物种但不计入亲自捕捉成就；图鉴公开物种候选特性、技能池和技能书来源，并支持筛选折叠。

1～15 级仓库固定 30 格，后期用金币或扩容道具每次增加 10
格。市场开放后幻兽允许交易，保留捕获者与当前持有者记录；高于人物等级的交易幻兽只能进仓库。初始伙伴、特殊剧情幻兽、出战、替补、锁定、任务提交中和副本中的幻兽不可交易。放归支持单个及批量逐项勾选和二次确认，不返还封印球、经验、金币或技能书；放归不删除图鉴、首次奖励或特性发现记录。上交和放归严格分开，系统不自动选择最低等级或重复个体；所有不可逆操作保留操作日志，不提供撤销。
普通野外捕获的隐藏特性个体可交易；携带位在战斗及副本外可交易。初期不支持批量交易或直接赠送。幻兽首次改名免费，之后消耗少量金币，具体价格另配。

任务技能书及任务碎片绑定角色；野外、精英、副本掉落的完整书和碎片未绑定，市场开放后可交易。掉落按已配置战利品表决定，不按当前队伍的物种、已学技能或缺书情况筛选；只投放至少有一个开放物种有资格学习的幻兽技能书，不增加定向掉落。已拥有技能时不消耗书；重复书可保留、按已配置卖价出售或在市场开放后交易，不自动转化。当前不支持技能重置、技能锁定、升级自动学技能、繁殖或遗传技能；人物技能体系独立，幻兽技能仍遵守七技能上限和随机遗忘。

封印球沿用已确认售价：普通 I／II 为 8／16 金币，强化 I／II 为 24／48 金币，II 为 I 的两倍；I 档在村庄开放，II
档在学院开放。强化球可来自精英、任务、副本及相应商店，不进入付费商城。普通捕捉失败消耗本次球与人物行动，战斗继续，存活目标可在后续回合再次捕捉，不重抽等级、技能或特性槽位；不设失败保底或连续捕捉次数限制。只有战斗结束才清除遭遇，战败、成功撤退或目标被击败后，下一次主动探索才生成新遭遇；不新增野生幻兽随机逃跑机制。普通球未绑定，任务赠球绑定，交易随市场开放。捕捉页面显示等级、属性、生命状态、可用球、最终概率和固定成长的捕获后属性预估，不显示误杀风险或实际隐藏槽位。

1～15 级。

### 基础属性

人物与幻兽均采用生命、魔力、物攻、法攻、物防、法防、速度七项基础属性。升级按职业或物种自动成长，初版不增加手动分配力量、智力等属性点；构筑通过成长路线、装备和幻兽技能实现。开篇职业与物种成长使用下列表，15
级之后另行配置。

开篇魔力标尺为 MP = 40 + 4 × 等级，1、5、10、15 级分别为
44、60、80、100。这是中性测试基准，职业与物种分别分配预算；人物魔力上限方向为法师、牧师较高，战士较低，游侠居中，具体预算见下文。战斗中不自动回魔，恢复来自道具或明确技能，战后按规则保留剩余魔力。

1 至 15 级人物魔力总量测试目标为：战士 30 + 3L，游侠 40 + 4L，法师与牧师 50 + 5L，L 为人物等级。10 级分别为
60、80、100、100，单独使用耗魔 8 的技能可使用 7、10、12、12 次。该目标含基础装备预算，不能再重复叠加整份基础装备；需与生命、攻防成长和辅助技能消耗联合验证。

治疗术恢复指定存活友方 2 × 施法者法攻的生命，耗魔 12、冷却 0；微疗恢复 1 × 施法者法攻的生命，耗魔 8、冷却
1。两者不能复活，有效恢复不超过目标损失的生命，不受元素克制或属性一致加成影响。以法攻 70 为例，分别恢复 140 和
70；取整及治疗增减益另行配置。

### 开篇幻兽成长与技能

幻兽统一读取各形态的整数七维基础值，公式及例算见[幻兽七维基础值与成长](species-base-stats.md)，运行数据为`species-stats.json`。魔力也属于物种基础值，法术型和物理型的魔力预算与技能消耗分别设计。进化直接使用目标形态七维，不叠加原形态倍率；人物职业成长保持独立。

## 装备成长

### 装备品质

装备采用五档品质，品质与穿戴等级、强化等级分别记录。

| 品质 | 显示颜色 | 主要定位               |
|------|----------|------------------------|
| 普通 | 白色     | 初始装备、基础商店装备 |
| 优秀 | 绿色     | 主线奖励、常规冒险装备 |
| 精良 | 蓝色     | 副本装备、阶段精品     |
| 史诗 | 紫色     | 后期高难内容奖励       |
| 传说 | 橙色     | 后期特殊任务与长期追求 |

同等级高品质装备通常具有更好的属性预算或效果，不要求每项属性都更高；不同穿戴等级仍须比较实际属性。品质不是在已配置属性之外再乘一次的全局增幅，同名装备继续使用固定属性，不增加随机词条或洗练。套装身份与品质独立，不要求所有套装都是高品质；强化不会改变品质。

1 至 15 级只投放普通、优秀、精良三档，初始装备归普通，D01
套装归精良。现有装备数值保留，不因增加品质标识自动增强；其他装备逐件标注品质时沿用其现有预算。装备名称旁同时显示品质文字与颜色，不只靠颜色区分。后期史诗、传说装备的具体投放暂不展开。

### 品质预算与强化平衡

采用以下同等级、同部位属性预算作为后续装备配置的平衡起点，不视为已验证的最终物品数值。

| 品质 | 相对白色装备总预算 |
|------|-------------------:|
| 普通 |               100% |
| 优秀 |               110% |
| 精良 |               120% |
| 史诗 |               130% |
| 传说 |               140% |

预算用于设计整件装备，不是给每条已配置属性再乘品质系数。物攻、法攻、生命、魔力、双防及速度按实际战斗价值分配，不直接把数值相加；速度可改变行动顺序，不能与生命等价计价，具体兑换权重后续配置。强力被动及套装收益须计入相应装备组合的预算，不能无成本叠在最高基础属性上；具体效果成本按触发条件、覆盖范围和实战收益评估，暂不规定统一扣除比例。现有
1 至 15 级装备及 D01 套装不因该预算表重新乘算。

所有品质共用每强化一级增加基础属性 5%、最高 LV7、目标等级成功率 90% 至 30%
的规则。高品质通过自身基础属性获得更大的绝对强化收益，不再额外提高强化倍率、成功率或等级上限。强化继续提升属性，不采用强化节点解锁被动的方案。强化、进化和专属材料按高等级内容计划推进，当前开篇不开放。

仅为展示倍率，假设同等级同部位、无特殊效果的白色武器攻击为 100，且预算全部分给攻击：

| 品质 | 未强化 | LV4 |   LV7 |
|------|-------:|----:|------:|
| 普通 |    100 | 120 |   135 |
| 优秀 |    110 | 132 | 148.5 |
| 精良 |    120 | 144 |   162 |
| 史诗 |    130 | 156 | 175.5 |
| 传说 |    140 | 168 |   189 |

表中小数仅用于倍率比较，实际属性按原始值一次计算后逐项向下取整。高强化低品质装备可跨品质过渡，同强化等级下高品质仍有优势；不能把示例当成所有武器的最终攻击值。

装备等级成长以高强化旧装备可多用一至两个装备批次（约 5 至 10 级）为平衡目标，再反推同部位、同品质的各等级预算；不是承诺每件旧装备必定可用十级，也不要求新一批未强化装备立即超过旧
LV7。比较时同时考虑品质、强化和特殊效果，不独立叠加三个未经校准的成长曲线。

普通主线按未强化装备平衡；高难副本可提高装备要求，但不以全身 LV7 为门槛，因为强化无保底且会掉级。基础属性提升还须结合人物裸装成长与幻兽队伍评估，不把装备属性增加
35% 解释为人物或全队战力提高 35%。此处只确定设计约束，后续实际装备与副本数值在正式开发阶段验证，不继续扩展当前联合验证脚本。

### 更换、套装与强化

- 装备成长采用不断获得和更换新装备的结构，武器也遵循这一方向。
- 1 至 15 级按开篇任务逐步发放装备，15 级以后每 5 级提供一批新装备，分散在任务、制作和掉落中；不要求同时替换全部部位，高强化旧装备可以继续过渡。
- 初版同名装备的属性、数值和特殊效果固定，以不同名称的装备提供进攻、防御和功能方向，不加入随机词条与洗练；重复装备可按绑定规则交易或分解。
- 套装覆盖头部、身体、手部、腿部、脚部 5 个防具部位，同套任意 2 件及 4 件分别激活效果，穿戴 4 件时同时享有两档效果；不设 5 件或
  7 件额外奖励，武器与饰品独立搭配。
- 支持两套各穿 2 件，同时获得各自的 2 件效果，与同套 4 件构成搭配选择；每件装备只属于一个套装，剩余 1 个防具部位自由搭配。
- 不同等级批次的套装分别计件，同主题也不能跨批次凑件；页面明确套装名称及等级批次。每 5 级的新装备不必包含新套装，可以提供散件。
- 仅战斗外允许换装；比较页面显示基础属性、强化后的实际属性，以及换装后激活或失去的套装效果，不用单一战力分数代替效果比较。
- 套装效果强化职业路线及人物与幻兽的配合，不提供完成首领机制必需的独占能力。开篇巡林者套装的生命加成与防御触发护盾见“D01
  装备与奖励”，后期套装另行配置。
- 15 级可选三人副本首次投放套装，首领宝箱掉落成品部件，不按职业定向，试玩不开放材料制作缺件；主线基础装备足以继续冒险，不要求集齐套装才能推进剧情。
- 捕捉交付可以作为获取新武器的任务要求，不默认要求将旧职业武器逐级升级。
- 主线任务提供够用的基础装备；捕捉交付与制作提供可定向追求的装备；副本首领掉落带独特效果的装备。
- 长期设计支持旧装备出售或分解；1 至 15 级出售按“开篇普通装备规格”执行，不开放分解，不投放无用途的制作材料。
- 人物 30 级开放装备强化，消耗金币与强化石等道具，装备强化最高 LV7，未强化为 LV0。
- 强化失败降低 1 个强化等级，最低 LV0，同时消耗本次金币与强化石，装备不消失；不设置保底，每次独立判定，失败次数不提高成功率。
- 按本次目标强化等级 L 计算成功率：p (L) = 100% - L * 10%，适用于 LV1 至 LV7；每级降低 10 个百分点。LV1 至 LV7 依次为
  90%、80%、70%、60%、50%、40%、30%。
- 例如 LV4 冲 LV5 失败后变为 LV3，再冲 LV4 使用目标 LV4 的成功率；LV0 冲 LV1 失败仍为 LV0。已达 LV7 不再进行强化升级。
- 每个强化等级增加装备自身基础战斗属性的 5%，按未强化原始值计算、不复利，LV7 合计增加
  35%；每项属性单独计算并在最后统一向下取整，不逐级保存取整值。例如物攻＋23，LV3 为 floor (23×1.15)=26，LV4 为 floor (23×1.20)
  =27；不增强特殊效果，不改变穿戴等级。
- 强化计算范围是该件装备直接提供的基础数值属性，例如物攻、法攻、物防、法防、生命、魔力与速度；只提升装备原有属性，不凭空增加新属性，也不对人物裸装成长、其他装备或幻兽属性乘算。小数值属性允许多个强化等级实际显示不变，不设置每级最低增加
  1 的保底。
- 套装奖励、触发效果、护盾容量、技能威力、触发概率及控制抗性档位不随装备强化增长。强化页面必须预览成功后的属性与失败掉级后的属性、消耗和成功率；显示实际取整结果。各部位具体强化消耗留到
  30 级内容配置，不纳入 1 至 15 级试玩。
- 不支持强化转移；强化等级属于当前装备，更换装备不会继承旧装备的强化等级。旧装备保留自身强化，强化不提高 NPC 回收价，不返还强化投入；市场由玩家定价。
- 分解按装备等级与品质产出材料，强化等级不增加分解收益，不返还投入的强化石与金币。
- 人物采用 7 个装备部位：武器、头部、身体、手部、腿部、脚部、饰品；保留腿部，不单设腰部，其生命、魔力与抗性需求由防具和饰品承接，减少持续换装与强化负担。
- 开篇主线逐步补齐基础装备，普通冒险不要求全身强化。幻兽初版不穿装备，通过等级、技能、物种特性与进化培养。
- 强化石首版来自 30 级后的委托和副本，可在金币市场交易，不在付费商城出售；装备分解留后续，不计入首版产出预算。目标等级 L 消耗 L 个石头，产出与金币基础费用尚待测算。
- 多人副本采用个人奖励资格，不争抢同一件装备；D01 核心装备仅由发起者宝箱提供，不按职业或缺件定向，队员获得既定参与奖励。其他副本具体掉落另配，不将个人奖励解释为人人必得装备。
- 主线任务物品向符合任务条件的参与者分别发放；具体属性和制作配方尚未确定。

## 世界与叙事

采用明亮奇幻风格：温馨日常为主，偶尔热血史诗。玩家从晨露村普通冒险者成长，通过幻兽伙伴、探索与实际行动影响世界，首次平息灾厄后获得“指引者”称号，不依靠救世血统或开局预言。

长期规划十次世界灾厄，基础1～50级完整平息第一次魔力潮汐失衡。灾厄成因各异，不由同一幕后黑手策划，不要求破坏规模逐次递增；资料片与灾厄不强制一一对应。两次危机之间存在真实的安定生活。

晨露村以庆典准备、结契和主动远行为开篇，诺姆学院提供短实践。四城以贸易、生活、交流与探索联系；主线连续推进并允许回访，不按城市分章。取消妹妹寻亲、人体改造营救、两次袭村与毁村主线。

第一次灾厄由自然周期遭过度取用资源而失衡，地方反派各有目的，一位野心家后期借机扩张。玩家击败利用危机的敌人，再亲自与伙伴进入风暴，与失衡中的古老幻兽交战并恢复自然流转。结局使其清醒回归栖息地，不强制捕捉或击杀。

日常故事有独立成果，不全部是阴谋伏笔。重要NPC有自己的生活和专长，不加入固定人类战斗编队。十一族共同生活，机械族不被刻意突出，族群不决定善恶或可捕捉性。幻兽有性情，封印球承载契约，不额外增加饥饿或服从度系统。

个人主线可独立完成，合作副本不作为结局门槛。公共活动共享，关键剧情与成果按个人进度呈现；组队不能跳过主线，奖励不重复领取。离线或日常探索不触发现实时间的灾难惩罚，普通战败损失沿用玩法规则。

区域采用相邻地点导航，由玩家主动探索或挑战；服务仍依赖建筑、NPC与道路。故事调整不自动更改地图移动、队伍、战斗、培养和存档规则。

### 地图与设施入口

游戏以当前地图为主要界面，建筑、NPC、幻兽踪迹和相邻出口承载地点互动，不采用冒险、队伍、背包、任务、角色五个并列主入口的结构。商店、仓库、职业教学、恢复等地点服务通过所在建筑或
NPC 进入，地图与剧情解锁决定可访问范围；不能通过全局服务按钮绕过地点或副本限制。个人背包、角色、队伍等便捷入口及设施具体落点仍待页面方案配置。

地图交互规则：每次只移动到道路直接连接的相邻地点，即使目的地已探索，也不能一次点击跨过中间地点。非相邻已知地点可查看信息，但不改变当前位置、不调用当地服务；未解锁地点仍受前置限制。地图标记最终任务目标，并突出下一步应走的相邻出口，到达和任务推进后同步更新。删除与地图重复的地点列表，地图下方集中展示当前地点的
NPC、设施与事件操作。游戏内页顶部不保留品牌名和章节名，保留角色及必要状态信息。联网移动与主线任务已实现。

### 战斗页面锁定

只要角色仍处于进行中的战斗，就不能在游戏内切到地图、商店、任务、仓库、个人管理或其他非战斗页面。技能与目标选择、药品、捕捉、换宠、状态详情及战报均在战斗页面内完成，不构成退出战斗。不得通过历史链接、刷新、重新登录或另一标签页执行战外操作；服务端按实际战斗状态校验，恢复游戏时回到最新战局。浏览器本身仍可关闭或离开，不将其视为战斗结束；单人保留战局，多人继续既有
45 秒及缺席规则。

只有按规则结束战斗后才进入结算及对应地图或安全地点。认输、撤退和副本退出仍按原有结算时点生效，不能借页面返回键免费逃离。收到组队匹配通知时也不能切到独立组队页面，战内通知的具体交互归页面待审方案。

## 玩家经济与付费

市场与培养规则按高等级内容计划推进，当前开篇不开放。
人物 16 级完成交易教学后在城镇交易所使用全服市场；不改变当前 1～15 级试玩范围。

- 市场开放后支持普通材料、未绑定技能书及碎片、未绑定装备和普通捕捉幻兽交易。普通及优秀装备在非任务绑定等例外下可交易，穿戴后绑定；副本获得即绑定的装备不可交易，品质本身不解除来源绑定。普通幻兽培养后仍可交易，隐藏特性不是禁止交易的原因。
- 核心补给商店不设每日购买硬上限，资源不足可继续野外练级与收集。NPC
  回收与玩家市场分开：只接受配置了卖价的书、材料和装备，不收购幻兽，不返还放归投入；未配置卖价及明确不可出售的任务物品不能自动回收。
- 交易、放归、上交和强化均有确认步骤并保留操作记录，确认后不可撤销；幻兽管理支持物种、等级、特性、技能和位置筛选及搜索。低网速提交显示等待结果，重复请求返回原结果，不重复扣除或发奖。
- 初始伙伴、特殊剧情幻兽和任务专属物品不可交易。
- 免费进入游戏；付费提供外观、称号装饰和额外编队预设，不直接出售战斗数值、稀有幻兽或遗忘保护。
- 付费货币不能兑换游戏金币，付费商品不可转售。
- 市场采用游戏金币一口价交易，最低整数单价 2 金币；每次成交向卖方收取成交总额的 5%，向上取整。每角色同时最多上架 20 项，每单 48 小时；堆叠商品支持部分购买，不延长期限。取消免费，修改价格需重新上架。
- 初版不开放竞价拍卖和直接赠送；成交记录可查看。购买不新增绑定，禁止自购；培养绑定材料选择与失败绑定按第二阶段规格执行，品质本身不禁止交易。当前一账号一角色，不扩展账号内跨角色流通；交易幻兽等级限制见幻兽成长规则。

## 30 级后委托

- 猎人公会委托参考攻略的 30 级开启、每 10 次一环结构，逐环提高任务要求。
- 进度可保存，暂停或下线不重置，不要求限时连续完成。
- 委托混合捕捉交付、材料收集与首领挑战，奖励随难度分档，不无限递增。
- 可免费主动放弃，回到第一环第一次及最低难度档；已领取奖励保留，已交付材料与幻兽不退回，确认时显示将清空的进度。暂停或下线仍保留进度。
- 完成一环后可挑战更高档或留在当前档，最高档按该档循环；普通档不强制多人副本，组队挑战位于自选高级档。
- 放弃后从最低档重新开始；难度上限和奖励数值尚未确定。

## 战斗与联网

### 状态、抗性与净化（开篇基准）

状态按行动控制、速度控制、持续伤害、属性削弱、位移与强制行动五组归类。抗性 0／1／2／3 级分别表示原效果、效果乘 75%、效果乘
50%、免疫；一次效果只修正概率或强度，不同时缩短持续时间。同组来源取最高等级。

- 减速：速度降低 20%，第 R 回合施加，影响 R+1、R+2 排序，R+2 结束移除；本回合顺序不改变。不同名称只取当前最强，同名强效果覆盖弱效果，同名同强度刷新到期时间。
- 眩晕：PVE 与 PVP 跳过下一完整回合普通行动，基础概率 100%，不能取消已提交行动或已开始的首领预告。命中后 R+2、R+3 为免疫窗口，R+4
  才可再次施加；首领默认行动控制抗性 2 级，预告期间明确免疫。
- 持续伤害：第 R 回合施加，R+1、R+2、R+3 回合结束各结算一次；每跳使用对应攻防比、元素克制与持续伤害抗性，不触发属性一致加成，不受防御指令、坚岩或活力减免，允许取整为
  0。
- 普通减速、持续伤害、眩晕可净化；净化术耗魔 8、冷却 1，指定一个友方的一个状态；群体净化耗魔 18、冷却
  3，每名目标最多移除一个。净化眩晕须在行动检查前完成，不返还已经失去的行动。机制标记、场地效果和免疫窗口不可净化。
- 换宠保留状态与眩晕免疫计时，倒下移除减益但保留防连续控制窗口；战斗结束清除战斗状态。状态日志显示施加、抵抗、免疫和净化，不披露隐藏特性身份。

- 采用回合制；副本全程手动指挥，包括重复挑战，不提供自动战斗或预设托管；普通野外重复战斗的自动规则另行配置。

- 手动模式下，玩家分别指定角色和出战幻兽的技能与目标，一次提交本回合指令。
- 多名玩家同时手动提交指令，再统一结算；副本超时、掉线均不由策略代选技能、目标或替补。

### 属性克制

常规直接伤害采用攻防比公式。1 至 15 级已确认的测试公式为：基础伤害 = (攻击者等级 + 5) × (技能威力 / 10) × 攻击 /
防御。再应用属性一致、克制及适用减伤，乘随机倍率、向下取整，最后结算护盾与生命。物理技能通常使用物攻与物防，法术技能通常使用法攻与法防；奥术射击使用物攻与法防。

直接伤害随机倍率已确认为 15/16 至 17/16，即 93.75% 至 106.25%，区间内均匀随机，取整前平均倍率为
1。适用于人物、幻兽与首领的普通攻击和直接伤害技能，PVE 与 PVP
使用同一规则；治疗、护盾容量、持续伤害和明确标注的固定机制伤害不波动。向下取整后的平均整数伤害不保证恰好等于无波动时的取整结果。

每次完整攻击只抽取一次倍率，同次群攻的所有目标及多段攻击的各段共用该倍率；各份伤害仍独立计算承受者的防御、属性和适用减伤。援护不重新抽取倍率，同次群攻中自身与代接的两份伤害共享该次攻击倍率。无效攻击不因随机波动获得伤害，直接攻击入盾前最低
1 点规则仍适用。

危险攻击预告显示按当前状态估算的伤害范围，战报显示实际结果；状态或护盾变化会更新预估，不把预估范围等同于下一回合一定扣除的生命。随机倍率由服务器在攻击结算时确定并随战斗结果保存，不能通过预览、重复提交、刷新或重连重新抽取。该约束由服务器战局、随机结果和回执持久化实现。

物防和法防分别计算削防下限：削防与忽略防御结算后，计算用防御不低于目标常态对应防御的 50%，且至少为
1。常态值包含等级、装备与常驻成长，不包含临时增减益；具体削防叠加顺序待配置。该规则限制防御降低，不是最终伤害上限。

## 副本难度框架

长期预留普通、英雄、史诗、传奇四档难度；前三档是常规难度框架，第四档传奇预留为最高阶团队挑战，目前不配置具体副本或奖励。

| 难度 | 定位                       | 设计方向                                     |
|------|----------------------------|----------------------------------------------|
| 普通 | 升级冒险、剧情与基础收集   | 展示核心机制，容错较高                       |
| 英雄 | 阶段装备积累、完善队伍构筑 | 强化已有机制与配合要求，改善奖励             |
| 史诗 | 成熟队伍的高难挑战         | 增加关键机制或阶段，检验构筑与资源管理       |
| 传奇 | 预留的最高阶团队挑战       | 更深入的机制决策与团队配合，具体开放方案后定 |

难度差异不能仅由生命和伤害膨胀构成，应提供策略上的变化。同一副本不同难度保持固定组队人数，不强制指定职业或隐藏特性，关键机制应允许多种应对方式。WAP
回合制高难度主要考验构筑、资源管理与决策，不依赖操作速度或长时间在线。

不是每个副本都必须配置全部难度，教学副本可以只有普通。史诗基础上可预留无人倒下通关、隐藏首领等可选挑战条件，以成就、称号和外观为奖励方向，不因此自动增加一档装备成长。挑战条件与传奇的具体内容均留待后期，不引入无限层数。

副本难度与装备品质是独立维度：史诗难度不代表必掉史诗品质，传奇难度也不等同于传说装备。各难度共享同一副本的发起次数，不按难度分别刷新；具体开放等级与奖励表后续配置。

1 至 15 级的 D01 仅开放普通难度，界面不展示未开放难度的选择入口。现行 D01
的人数、机制、奖励及仅扣发起者次数规则继续作为普通难度规格；英雄、史诗、传奇均不纳入本期开发范围。

英雄难度预计在 30 级左右开放，史诗难度预计在 60
级左右开放，传奇作为后期最高阶内容开放；具体等级可随资料片调整。难度由发起者选择并锁定，队员需达到对应最低等级；各难度共享同一副本的发起次数，只扣发起者，不扣其他参与者。高难度优先增加机制、阶段和资源压力，数值提升只作为辅助；后期普通难度允许在其明确配置的掉落表内低概率获得最高品质装备，不代表所有普通副本都投放传说装备，1～15
级仍只投放白、绿、蓝。高难提高品质概率、特殊外观和成就收益，不保证固定品质，不中途改难度。

## 战斗结算与手动提交

**战斗与准备页。**
战斗页按敌方状态与危险预告、己方三单位指令、本轮提交状态、战报排列；多人默认展开自己的人物和两只幻兽，队友状态可展开，不隐藏首领预告。每名玩家一次提交完整合法指令，提交前列出技能、目标及道具；倒下补位也在同一轮完成，不新增第二个倒计时。提交后显示已锁定，不能撤销；超时空过仍按已确认规则。捕捉只显示目标事实、球资格、当前概率与容量，不显示误杀提示或预测伤害。副本准备页显示入本首发／替补、实际生命魔力、等级、连接／准备状态及可用药品数量，锁队原因明确；不允许从该页改编队。

**匹配与个人战斗。** 匹配等待时可继续个人冒险；找到队伍后给 60
秒入队确认窗口，拒绝或超时只放弃本次匹配、不扣副本次数，其他人继续补人。正在个人战斗时，在战斗页内以不遮挡指令的通知确认或拒绝，不跳转组队页；确认可保留位置，但须正常结束当前战斗后才能准备，不能暂停战局进入副本、免费撤退或丢弃战局。确认后最多保留
3 分钟位置，页面显示期限；期间不得新开个人战斗，到期仍未结束则释放位置，本人原战斗保持。队伍正式开本前再次核验三人均无个人战斗、均满足前置且已准备，才扣发起者次数。

**多人保护与护盾顺序。**
同一目标有多个有效援护／掩护时，最先成功施放且仍有效的一份先触发，其他保护保留给本回合后续攻击；依次跳过不适用的保护，例如群攻跳过仅接单体的掩护。同优先级按既有速度与同速随机排序决定施放先后，不由提交快慢决定。被接走的同次伤害不再次转移，互相保护也不形成循环；未触发者仍正常消耗行动、魔力和冷却。

先锁定实际承伤者，再用承伤者的防御、属性、减伤计算并取整，然后消耗承伤者自身护盾。原目标的防御指令和护盾不会转给保护者。现有巡林者护盾仅能加在幻兽身上，法力护盾仅法师自身，当前二者不能落在同一单位；不为了测试叠盾新增技能。后续若出现不同名共存护盾，巡林者直接伤害护盾优先，再按到期更早、施放更早顺序消耗，法力护盾最后消耗并扣魔；同名不相加。

同次群攻包含保护者自己的伤害和代接伤害时，先计算两份入盾伤害，共享该次随机倍率，按自身份额在先、代接份额在后消耗同一护盾／魔力库存，再合计扣生命；不能自身一份致死后把已锁定的代接伤害退回原目标。此处只定单段攻击／群攻，多段逐段死亡、特性和魔力扣款另配，不提前作为本阶段新技能。

例：猫持有 30 巡林者盾，小岩怪掩护它，实际攻击按小岩怪防御结算；猫的 30 盾不抵扣这次攻击，留到本回合后续实际命中猫的攻击或到期。猫自己承受取整后
80 伤害时，先扣 30 盾，再扣 50 生命；护盾后不补最低 1 点伤害。

**倒下补位与全灭。**
回合开始，自己的出战幻兽位为空或幻兽已倒下，可从自己的存活替补中免费补位；该新成员能在本回合正常选招。主动换出仍消耗原位置本回合行动，新入场幻兽不能当回合再行动，两者明确区分。不能选择其他玩家的替补，同一个体不能同时占两位；本场新捕获幻兽仍不能立即入场。

回合中倒下不立即补位，不获得追补行动；本轮其他攻击的无效目标仍按通用规则处理。若全队场上都倒下但至少一名玩家有符合资格的存活替补，本轮不立刻判负，在下轮先补位；没有任何存活出战者或可补位替补时才全灭。人物倒下仍可操作幻兽，不要求先复活人物；替补入场承接自己的状态，不继承旧位置的伤害、护盾或临时效果。

**一轮手动提交。** 多人每轮只有一个 45
秒窗口，包含玩家手动选择倒下补位与人物／幻兽指令。玩家可保存草稿，但必须提交才生效；已提交且合法的整套指令锁定，不因随后断线重抽。全员提交或截止进入结算；同一回合标识的重复提交返回同一结果，截止后到达的旧回合请求拒绝，不补执行一次。

副本不提供自动战斗开关、预设策略、自动治疗、自动攻击、自动防御或自动补位，重复挑战也必须逐轮手动提交。已提交指令可在断线后正常执行，这不是自动接管。重连恢复到最新回合，不能撤销已结算动作；在尚未提交且未截止的当前回合可以恢复操作。下一场仍需全员手动准备。

**超时、断线与退出（）。**
未提交者本轮所有单位不行动，不获得防御减伤、不补位；单位仍可受伤，已有状态按正常回合推进。已提交指令在断线后照常执行。连续两轮未提交，第二轮结算后将该玩家及其随身单位移出本场，清除相关保护关系，本场禁止重新加入，不生成额外死亡或击杀收益；断线者可重连观察，下一场手动准备或当前战败重试时恢复参战，主动退出者仍不得返回同一进度。主动退出在当前回合结算后移出，已锁定指令不撤销；无其他玩家待提交时无需空等截止。

全员缺席只推进到上述两轮缺席收束，随后按本场挑战失败处理，不无限空跑、不自动重试。全队场上倒下但仍有存活替补时，下一轮必须有人手动补位；该轮截止仍无人补位则判本场失败，避免替补令战斗永久悬停。失败保留已完成遭遇进度，可按既有规则休整重试，不额外扣发起次数。

**缺席与奖励资格（）。**
短暂断线且未被移出本场者保留正常胜利奖励资格，但本场至少手动提交过一次合法整套指令。不按伤害或治疗量设门槛，手动防御、操作幻兽均可。整场零提交、主动退出或因连续缺席被移出者不领取该场经验、金币、掉落及相应首领参与奖励／通关奖励；其随身幻兽也不领取该场经验，先前合法取得的奖励保留。首领战不具备资格时不生成发起宝箱，不退已用次数，也不扣掉未实际获得的每日参与奖励资格。有效提交是短暂断线容错，不宣称能阻止所有消极参与行为。

## 战间状态与开战准备

**战间状态。**
每场独立战斗结束时保留实际生命、魔力与倒下状态，清除本场临时增减益、护盾、保护关系、控制、持续伤害及战斗技能冷却。清除持续伤害仅在战斗已经结束时发生，不允许打开页面或暂时离线视为结束；未结束战斗的重连继续原状态。回合战斗冷却不变成现实等待时间，持续伤害也不在战外额外扣血。不同战斗的技能冷却归零不等于恢复魔力。

野外撤退仍消耗原有资源且不自动回血，副本完成一场后仍须走到已解锁休整点才能恢复。副本休整可复活并回满随身队伍，普通换装与升级不会自动恢复。此规则已确认，脚本战间清冷却与之保持一致，不把副本休整混同为每场自动恢复。

**副本准备页面。**
每场开始前展示三名玩家的连接／准备状态、人物与出战幻兽生命魔力、空位和倒下状态、休整点入口。存在倒下成员或生命／魔力不满时显示客观状态，不强制满血满魔、不阻止自愿挑战，不提供捕捉误杀提示。玩家手动休整和准备，全员准备后才能开下一场；首场创建副本才扣发起者次数，后续开战不再扣。

副本入场后的编队调整入口禁用，包括战间重新安排出战、替补和携带位；倒下补位由战斗内既有规则处理。允许的战间换装、用药或休整会使本人已准备状态失效，重新准备才能开战，避免其他人按过期状态开始。准备后断线取消其战间准备；已经锁定开始的战斗不能借断线取消，按手动提交与缺席规则处理。战斗中刷新不清除已提交指令，不代替断线玩家点击下一场准备或消耗道具；战间用药同样遵守本次副本可用库存限制。

战间在线判定采用服务端持久化的二十秒有效期，当前副本页面在前台每五秒显式续期；停止续期后准备到期失效。只读查询不续期，开战持副本锁重新核验有效期。过期后恢复网络只恢复在线，不恢复准备，必须本人再次确认；旧存档缺少在线有效期也按未准备处理。此判定允许短暂网络抖动，不承诺物理断网瞬间即可检测。战斗已开始时不因在线有效期取消锁定指令。

数值脚本中的自动选招仅用于批量模拟，不代表副本提供自动操作功能。真实超时、战局持久化恢复及缺席流程的实现证据见 implementation-progress.md；各项联网规则分别验证，不能把策略模拟或战中恢复验收替代战间失联验收。

## 开篇节奏

正式连续故事的开篇由 BQ001～BQ030 构成：晨露村结契与捕捉、为庆典货车侦察洞旁窄路并击退护巢幻兽、庆典、小站驮兽照护、诺姆学院学习、城郊独立调查与晚餐。洞口观察服务于车队通行，不要求进入巢穴，也不作为灾厄或阴谋的线索。详细步骤和开放条件见 [开篇设计](bright-opening-design.md)。村庄和基础服务始终可返回，不安排毁村、强制战败或救援传送。

开篇按1～10级体验预算设计，4～6小时是待真人验证的目标。30项任务共22680经验，纯任务到8级，野外探索与培养补充经验。成长上限为50级，不代表开篇剧情完成必须达到15级。经验和资源约束见 [开篇经济](bright-opening-economy.md)。

林间兽栏首领使用点名重击、连续扑击与护兽号令预告，人物和幻兽共同通过防御、治疗、援护和集火应对。学院以借用单位教授指令、换位、捕捉、学习、库存与职业能力；训练不消耗真实补给或改变真实队伍资源，真实奖励由任务统一发放。

BQ027清障后可挑战固定8级普通小岩怪；高等级城郊野外在取得冒险资格后开放。D01三人副本是可选培养内容，不阻断独立调查主线，入场仍需满足实际等级及任务要求。
