# 开篇捕捉的资源与操作边界

BQ007使用正常野外捕捉概率。削弱目标可以提高成功率，但不存在半血必抓、指定轮数必成或单球完成承诺。捕获失败继续战斗，后续敌方仍可行动；不能把成功投球的停止攻击效果预先计入生存保障。

玩家可先由人物防御、初始幻兽攻击，观察目标剩余生命后选择继续削弱或投球。投球消耗人物当轮行动；目标死亡后必须重新探索，不退款、不锁血，也不展示误杀风险提示。玩家等级、技能、属性、特性和伤害波动都会改变削弱效果，不能固定承诺“一次水弹”。

正式验证通过实际开战、削弱、投球、登记与幂等重放完成，不直接发放已捕获个体。四职业捕捉及学院路线的当前测试证据见 [当前进度](implementation-progress.md)。单次随机通过不能证明所有随机序列的成本上限。

补给耗尽时沿相邻道路回幻兽中心免费恢复，通过普通野战赚取金币后在商店补球；恢复不重新发任务礼包。零资源恢复测试使用已有攻击技能，纯普攻路线不作为保障。任务赠药和赠球以 [开篇经济](bright-opening-economy.md) 及正式任务目录为准。
