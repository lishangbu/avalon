# 幻兽图片交付

物种设计表的asset直接使用同源地址，例如利爪猫为`/game-assets/creatures/claw-cat.webp`。已有运行JSON的image字段继续使用相同约定。图片位于avalon-ui/public/game-assets下，设计表不能把OL_016当成可请求URL。

OL编号仅保留在[来源清单](creature-assets.csv)，通过public_path关联交付文件；清单同时记录原始路径、原始SHA256、交付SHA256、交付字节数及asset_status。没有图片的物种asset留空，不发送UNMAPPED或OL编号给浏览器。原始素材不改名、不删除。

所有交付文件采用内容语义名称，包括暂未绑定物种的图片，例如redplate-centipede、blackhorn-vanguard和woodland-wanderer；不使用ol-xxx或OL_xxx作为交付文件名。文件名不自动创建同名物种ID，正式绑定仍以内容配置为准。

本批核实47个源文件哈希，交付43张可用图片：全部为无损WebP，原图共34985字节，交付30626字节。逐张检查尺寸、透明度以及在黑白背景合成后的像素一致性。游戏图片统一交付WebP；蓝背飞豚为588字节，比源PNG增加17字节，尺寸和RGBA像素完全一致。

利爪猫原图为50×50的索引色PNG，通过透明索引支持透明背景；网页WebP为474字节，原PNG为578字节。两个版本的透明度与可见像素一致，没有串图或转换损坏。之前清单误将46张索引色透明图标为不透明，现按实际解码后的透明像素判断alpha_channel，不再仅检查颜色模式是否为RGBA。

以下4张暂不绑定：OL_017的绒耳妖外形归类不可靠，OL_034的梦翼兽仍需核对主体，OL_035只有黑色剪影，OL_042不能仅凭装甲认定机械族。它们的public_path为空、asset_status为REVIEW_REQUIRED，不能为了覆盖率强行配给物种。绒耳妖在物种表暂为空图。

前20级30个形态中20个已有本地交付地址，10个仍缺图。古木卫有树人素材候选，适用于古木卫的进化规格，但材料与路线实现尚未完成。其余已交付资源可供后段物种、首领或NPC正式绑定；文件就绪不等于幻兽已经加入运行遭遇池。

渲染按像素图使用原始尺寸或整数倍放大，不把50像素头像当成高清全屏立绘。部署时由前端构建携带public资源，后端提供JSON中的地址；本轮未重建或重启8080上的应用，因此既有运行页面不会自动出现尚未配置的新物种。

按[当前150形态选表](current-creature-design.md)统计，38种绑定有效图片、112种仍缺图。43张交付素材并非全部已绑定可培养物种，其中还包括敌人与NPC候选；不能直接用交付文件数减去物种数推算缺图。
