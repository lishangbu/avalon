# 幻兽图片资源

正式物种与进化配置的image字段使用同源资源地址，例如 `/game-assets/creatures/claw-cat.webp`；实际文件位于 `avalon-ui/public/game-assets/`，随前端构建发布。没有图片的条目按前端缺图处理，不把来源编号当URL。

[资源来源清单](creature-assets.csv)保存已交付文件的来源路径、原始与交付哈希及尺寸。文件存在只证明图片可用，不代表某物种已经注册、可以捕获或已经完成进化路线。

资源采用语义名称和WebP格式。浏览器绑定以正式JSON为准，不能根据图片名称创建物种或推断属性。源素材路径用于追溯，不要求运行机器具有旧工作站的资源目录。
