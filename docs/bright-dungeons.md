# 十二副本的地方故事与首领机制

本表落实[故事大纲](main-story-outline.md)的十二个题材，为新剧情设计基准，不代表当前单副本运行配置已扩展。编号 BD01～BD12 为新设计索引，正式接入时映射内容ID；不得据索引直接覆盖存档中的D01。

## 通用边界

- 三人合作、手动提交行动；人物与两只在场幻兽行动，另外两只为已锁定替补。入场固定参战名单，不能战间换入其他随身幻兽。
- 不依赖打断机制，不要求指定职业、物种或隐藏特性。预告必须说明目标、结算时点和有效应对；不同职业通过防御、集火、替补、治疗和场景动作组合应对。
- 场景动作占行动，不能成为免费按钮。具体由人物还是指定成员执行将在战斗规格中固定，客户端不能自行决定免行动成本。
- 下列“下一轮”指下一次全队指令提交与结算；按已预告目标结算，速度变化不偷偷切换目标。离线不阻止既定超时托管规则，也不把手动副本改为挂机。
- 主线不要求副本通关。副本讲自己的地方故事，不重复击杀已拘捕的塞维恩，不要求击杀岚潮龙。
- 普通难度先制作与验证；既有多档难度规划保留，未给出不同难度数值前不宣称四档均已完成。

## 战斗结果与可重复性

每场最多一个明确主要场景交互目标，优先使用可选择目标或现有技能入口，避免手机战斗页堆积独立按钮。场景动作规则仍需实现，不能只写文案判定成功。

主线生态恢复、地方通路开放与个人首通事实只生效一次。重复副本是玩法重挑战，不在故事中声称同一批幼兽再次被抓或同一人物无限复活。掉落按正式副本规则结算，环境目标与有限增援不额外生成可循环刷取的奖励。

原有发起者次数、帮助者收益、难度与补给边界继续作为通用约束，但经验绝对值、材料和装备来源需用新十二副本统一预算。当前入口等级仅是排布基准，不是可直接导入运行的数值承诺。

## 经验定标规则

正常组队重复通关的单位时间经验目标为同级野外的2倍；每角色每副本首次完整通关含一次性探索奖励，合计目标为5倍。按每名合格参与者比较，不把三人总经验与单人野外收益比较；发起者和队员采用相同经验规则。金币、装备、技能书和药品不随经验一起乘倍。

对照使用相同等级、装备与培养水平，野外计入正常遭遇、操作、战斗及必要恢复；副本计入入场至结算的行进、准备和恢复。首次阅读与排队时间另行记录，不以刻意低效的野外路线降低基准，也不以最快职业组合代表所有玩家。

首次探索资格按角色与副本记录一次，不因跨日、换发起者、难度或重复结算重置；须完整参与全部场次。补入者领取实际参与奖励，不消耗其尚未满足的首次完整通关资格。人物与合格幻兽沿正式经验规则结算，不为每只幻兽另建首次资格。2倍与5倍是实测效率目标，不是对现行奖励直接乘倍率。
