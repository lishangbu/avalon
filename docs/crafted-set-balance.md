## 目前能证明的数值

铁／银／金套装基础生命分别为60／80／100，配套武器额外7／9／12；套装数值自身提高11.67%／11.25%／12%。防御触发的伙伴护盾容量对应67／89／112，同样相对本档基础护盾提高上述比例。护盾只在人物防御时给本人当前出战、生命比例最低的伙伴，本轮结束清除，不能算成所有队员永久减伤。

把真实单件装备和职业成长加入后，配套武器贡献仅占人物生命上限约0.43%～0.60%。测试以相同武器属性、去掉套装资格的反事实隔离这部分收益，不额外减少武器单件属性；物攻、法攻、物防、法防均未因套装变化。生命比例仍不是整套战斗收益。

## 现有副本的真实对照

当前仅有15级普通副本装备。技能3级制造的九件装备与对应副本单件基础属性相同，但15级制造没有套装；五件副本防具有30生命和30点防御触发护盾。因此，15级完整制造装比同部位副本装少30生命及该护盾，不能把单件对齐误称整套等价。这不违反“更高级制造靠套装超越”的方向，但应在平衡验收中明确。

30／40／50级不存在同级普通副本模板，报告将其副本对照保留为空。没有新增高级副本，也没有将15级副本属性线性放大后冒称实际掉落。

## 同级套装预算验收

按用户“套装效果超过而不是装备超过”及后续“全部按照你的建议来”的确认，采用此前推荐的同级套装预算对照，不新增高级副本。此前规格中“同级整体收益高10%～15%”将套装效果扩大成整体战力，现予以纠正。整体战斗收益不作为该比例的含义，真实同级高级副本对照仍不存在。

普通套装预算锚定正式15级巡林者：30生命及每级2点护盾。将参考等级提升至30／40／50级时，生命预算按等级比例为60／80／100，护盾每级系数保持2，对应60／80／100容量。预算是未来同级普通套装的设计约束，不是已存在装备；现有巡林者的15级护盾上限不变。

完整制造套装为67／89／112生命及同容量护盾，相对上述普通预算分别提高11.67%／11.25%／12%，四职业均一致。缺少配套武器时只保留普通预算的基础效果。所有90件制造单件的属性种类与对应普通副本单件一致，数值按穿戴等级比例向下取整、最低1点，没有额外属性溢价。

`CraftedSetTest` 从普通套装目录独立构造预算并验证三档×四种武器，另检查90件单件属性；生成[套装预算报告](../outputs/life/crafted-set-budget.json)。真实战斗接入仍由前述穿戴／防御测试覆盖。此验收证明的是套装设计预算与实现一致，不是高级副本实际掉落对比，也不替代整个经济和成长节奏的验收。
